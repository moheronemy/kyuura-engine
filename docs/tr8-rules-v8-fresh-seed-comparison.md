## 0. 結論

- 8 組・16 局をすべて実行し、16 局とも `game_over` で完走しました（rules-v7 8／8、rules-v8 8／8）。両側完走が 8 組です。勝者はすべての組で同じでした。
- ［エナジートランス］が使われた組は 2 組だけで、残りの 6 組は能力が一度も使われず、両方策の局は送信の列まで同じでした。
- 違いが出たのは 1 組（9077）だけです。
  - 局全体の総操作は 266 から 136 に、［エナジートランス］の受理は 80 から 3 に、1 番の最多は 53 から 2 に、往復の検出は 16 から 0 になりました。
  - ただし分岐のあと、rules-v8 は rules-v7 の局面に一度も戻っていません（15 観測のうち 0）。同じ区間の短縮とは扱いません。
- もう 1 組（9076）では、rules-v8 が優先 1 に絞りましたが、rules-v7 も同じ組を選んでいて、局は同じでした。
- 必要な移動と、そのあとの操作は保たれていました。
  - 9076: 2 回の移動で「にげる」とワザの費用を満たし、ワザが受理されました（両方策で同じ）。
  - 9077 の分岐した番: rules-v8 は 1 回の移動でワザの費用を満たし、ワザが受理されました（その番の操作 3）。rules-v7 は 8 回移動したあと「にげる」で入れ替え、さらに 8 回移動してから、入れ替えたバトル場でワザを使いました（その番の操作 26）。
- D4 が選択の対象を変えた例は 0 回です。rules-v7 が払える「にげる」の費用を崩した移動は、保存記録からの再構成で 6 回ありました。しかし、どれも rules-v8 の D4 と同じ局面ではありません。D4 の防止効果は未確認です。
- どちらの費用にも届かない局面（到達不能）は、rules-v8 の評価 4 回の中に 0 回でした。評価できずに従来の選び方へ戻った回数も 0 回です。
- この 8 組は能力がほとんど使われないため、操作数の削減が一般に見られるとは言えません。既定化や、全デッキの完走率の判断には使いません。

## 1. 固定条件

- 0.198.0・TR8@1・C2 の固定デッキ v2（席 0 hitmonchan-dewgong-v2、席 1 venusaur-parasect-v2）・`deep`・観測と prestop を有効・変異なし。
- 両計画の各局を、同じ方式の保存済みの C2 計画（`vai-batch-tr8v8-v7`・`-v8` の 9056 の局）と比べました。違いは、計画の識別・上限・局の識別・seed（と seed から導く方策の種・比較の組の名前の seed の部分）だけです。
- 同じ seed の rules-v7 と rules-v8 の局の違いは、方式・rules_version・方策の版・分布・方策の記録の `energy_trans_progress` だけです。
- TR8@1 のダイジェスト、実装の識別、計画と完了の形式は、前の単位（`vai-tr8v8-run`）と同じでした。
- pyc キャッシュは、前の単位で準備した checked-hash のキャッシュ（185 ファイル）を使う前に照合し、変わっていないことを確かめました。dry-run では、両計画とも `use_cache` が真で、未着手でした。

### 1.1 seed の選定

保存済み・進行中のすべての計画（166）と局ヘッダー（600）を、30 の保存先から集めました。9075 以上には使用済みの seed がなく、最初の連続 8 値は 9075〜9082 です。

### 1.2 実行と予算

- 順序: seed の昇順で、各 seed を rules-v7 → rules-v8 の順に実行しました（16 回）。
- 結果: 16 回とも終了コード 0 でした。局ごとの照合（開始の判定・完了・ハッシュ・観測・prestop・judge・最終状態の replay・キャッシュ不変）はすべて成立しています。
- 停止方針の発動・異常・予算の不足は 0 回、未完了 0 局、未着手 0 局です。再試行・seed の差し替え・追加局・停止の解除・予算の延長はしていません。

## 5. D4（払える費用の維持）

- 実測: rules-v8 で D4 が選択の対象を変えた（`kept`）例は 0 回です。9077 の最初の分岐では、払える「にげる」を保つ組と、優先 1 の組が一致していました（`all_keep`）。そのため D4 による絞り込みは起きていません。費用を崩しうる組と保つ組の両方が残り、D4 が選んだという場面は、この 8 組にはありませんでした。
- 再構成（保存記録からの評価で、実測ではない）: rules-v7 の 9077 では、払える「にげる」の費用を崩した移動が 6 回ありました。バトル場から草を外し、そのあと払えなくなっています。しかし、どれも rules-v8 の D4 の例と同じ局面（観測と inputs）ではありません。
- したがって、D4 による防止の効果は未確認です。

## 6. どちらの費用にも届かない局面

rules-v8 の評価 4 回の中に、到達不能の局面はありませんでした。評価できずに従来の選び方へ戻った回数も 0 回です。前の単位の E5（構築盤面）のとおり、到達不能のあとは rules-v7 と同じ選び方で、操作は減らないと見込みます。この比較では確かめられていません。候補の順位・回数の上限は変えていません。

## 7. 分けて結論づけること

- 操作数: 減ったのは 1 組（9077）だけで、その組でも分岐のあとは別の経路です。6 組は能力を使わず、1 組は同じ選択で、どちらも差は 0 でした。
- 後続の操作: 評価が働いた 2 組で、費用を満たした番の後続のワザは受理されました。rules-v8 で失われた後続の操作は見つかっていません。
- 完走: 両方策とも 8／8 です。この比較からは、完走への影響の差は分かりません。
