# v0.76: 持続する効果・ワザの使用の制限を中心とするポケモン 24 枚（ワザ 48）

kyuura の data/engine_targets.json（7d3f4ca）の `new_effect_needed` のうち、持続する効果とワザの使用の制限を中心とするポケモン 24 枚を、kyuura データの採用で登録しました。
どのカードも、どのワザも登録した状態で対戦に使えます。必要な共通の処理を少しだけ広げ、v0.75 の文書の誤り 2 点を直しました（12 章）。

- 写しの元・研究の基準: kyuura `7d3f4ca76c084774efb4ac6a1d3a943387e183c3`（変えていない）。
- 採用したデータ: kyuura の `data/cards.json`（写しの組 `pool_v0_76`）。処理に使う文面は kyuura の印刷の文面（どのワザも kyuura に最新の説明・エラッタ・裁定の記録がない）。
- ガイドブック（『オフィシャルブック2000』）のキャプチャ・OCR・読み直しは行っていません。24 枚の日本語は pcg-search.com の転記（kyuura の `ja_text_source`）なので、同じサイトでの日本語の欄の
  照合は独立した照合にならず、外部照合はしていません（カードの画像も読んでいない）。
- 研究の基準のコミットで、24 の id と旧 pcg-search のページの id（`1stex1007` など）を指す kyuura の LD-・CC-・CR-・UQ-・訂正の記録はありません（あるのは収録の記録
  `data/curation/other_products.json` と同じカードの組 `data/same_card_groups.json` だけ）。採用の記録の `kyuura_records` は空です。欠けている記録を作ったことにしていません。
- 英語の欄・現代のルール・後年の裁定・2002 年の分類で日本語を補っていません。発売が 2000.02.14 版より後のカード（プロモ neo・プレミアムファイル）も、発売日を記録したうえで
  2000.02.14 版で処理します。

意味を確かめた書き方だけを、登録の値と結びつけて 1 通りずつ加えました。句読点の一律の除去・あいまいな正規化はしていません（`test_text_variants_are_narrow`）。

## 4. 共通の処理

### A. 指定したワザの 2 倍・3 倍（6 枚）

v0.35 の `MultiplyNextTurnAttackDamage` と同じ持続する効果 `NextTurnAttackDamage`（`NEXT_TURN_MULTIPLY`。種類 `next_turn_attack_damage_multiplier`）です。

- はたらくのは次の自分の番（与えた番 + 2）の、登録の位置のワザのダメージだけで、p.321 の 2 段階で数をかけます（GR-2000-P321-DAMAGE-ORDER）。弱点・抵抗力・プラスパワーは
  そのあとの段階です（ゼニガメのはたく 10 × 3 = 30 → プラスパワーで 40）。「その数にする」（SET）・最終ダメージの倍数とは別の計算です。
- 作った番・あいだの相手の番にははたらかず、次の自分の番の終わりに消えます。ベンチにもどる・進化・きぜつで消えます（GR-2000-P322-PERSISTENT-EFFECTS。v0.27 と同じ消える契機）。
- ニドラン♂のつのでとっしんは、既存の `FailOnTailsDamage(1)` のコインと失敗のままです。強化されていても「うら」なら失敗し、80 は出ません。
- 説明に自分へのダメージを 2 倍にする文はないので、`includes_self_damage` は偽です（マチスのラッタの設定を流用していない）。

### B. 次の自分の番の指定したワザを「30」にする（マリル）

v0.27 の `SetNextTurnAttackDamage`（持続する効果 `NextTurnAttackDamage` の「その数にする」）です。v0.75 までの `card_problems` は、変わるワザを「説明のない、ダメージの目安の
数字だけのワザ」に限っていて、説明（マヒのコイン）のある「とびのる」を拒否していました。

- 登録に `target_text`（変わるワザの説明）を加えました。値があるときは、変わるワザの説明がその文と同じで、ダメージの目安が数字だけ（「+」「×」「−」なし）でなければならず、
  このワザ自身の説明も「次の自分の番、このカードが使う「<名前>」のダメージは「<数>」になる。」でなければなりません。`target_text` が None のとき（ストライク）は v0.27 のままです。
  `card_problems` を空にしたり、ほかの計算の書き方を受け付けたりはしていません（位置・名前・説明・数の違う登録は拒否する）。
- 「30」にするのは 2 段階のダメージだけです。とびのるのマヒのコインと効果は、とびのるの登録（`ParalyzeOnHeads`）のまま処理し、コインを足したり消したりしません。10 を 3 倍に
  することとは別の計算です（ヒトカゲへの 30 は弱点で 60）。同じ段階にほかの効果が重なれば、既存の順番の決定（`damage_step_order`）を使います。

### C. なきごえ（8 枚）

相手に与える持続する効果です。受けた相手の対戦ポケモンが、次の相手の番に、このカード（ワザを使ったポケモン）へワザでダメージを与えるとき、p.321 の 2 段階（ワザを使うポケモン、
つまり受けた相手の持っている「ダメージを変更する効果」）で 10 減らします。受け手の 8 段階の軽減ではありません（ゼニガメのはたく 10 → 2 段階で 0 → 弱点 2 倍で 0。受け手の軽減なら 10）。

- 状態は `state.ReducedDamageToSourceNextTurn`（v0.34 の「なきつく」の `ReducedDamageToSource` の部分型。種類 `reduced_damage_to_source_next_turn`）。要素は v0.34 と同じ
  `OpponentReducedDamage`（`until_turn_end`）です。
- 違うのは期限だけです。説明は「次の相手の番」なので、はたらく番の終わり（`persistent.remove_expired_persistent_effects`）に消えます。v0.34 のなきつく・v0.37 のかみつくの
  「この状態は次の自分の番の始めに消える」（`expires_at_turn_start`）は、文面の受け付けを広げて当てはめず、型と種類を分けました（なきつくの期限・書き出しは変えていない）。
  番の終わりとポケモンチェック・次の番の始めをまたいで、なきごえは turn_end の前に消え、なきつくは次の番の始めまで残ることをテストで確かめました。
- 相手に与える効果なので、「とうめい」・「ワザをうけない」状態を評価します。「ダメージを受けない」状態は効果を止めません（ダメージ以外の効果）。
- 受けたポケモンがベンチにもどる・進化・きぜつすると消えます（v0.34 と同じ）。同じポケモンが 2 つの効果を受けるのは、ワザは 1 番に 1 回なので起こりません。
- 効果を与えたポケモンが控えにいるとき、その控えへのダメージに当てはめるかは、v0.34 の NK5（`UNRESOLVED_REDUCED_DAMAGE_BENCH_TARGET`）と同じ確かめで止めます。説明の書き方は
  なきつく（「このカードにワザを使う時」）と違い「このカードにダメージを与える時」ですが、控えのこのカードへのダメージに当てはめるかは記録で決まらないので、同じ問いとしました
  （新しいコードにしていない）。理由の文は v0.75 までのなきつくの文のままにし（固定した版との比較の文を変えない）、補足に「「なきごえ」（…「-10」）の効果。」と書きます。
- 説明は「ダメージを与える時」でワザに限りませんが、受けたポケモンがはたらく番（持ち主の番）にこのカードへ与えうる特殊能力のダメージ（はんげき・わるいねぞう・ファイナルビームは
  相手のワザのダメージ、こっそりかみつくは進化で効果が消える）は、今の対応カードでは起こりません。黙って減らさずに続けないよう、`effects.received_power_damage` が
  エンジンの不具合（`RuntimeError`）として止めます。
- もう一方のワザは、それぞれ説明のないダメージか、既存のコインのマヒです（数と必要なエネルギーは写しのまま）。

### D. ドわすれ・かなしばり（2 枚）

v0.35 の `LockOpponentAttack`・`OpponentAttackLock`・`CannotUseAttack` と、v0.49 の `held_attack_keys`（相手の対戦ポケモンが今持つワザと出どころ）を使います。

- ヤドン PR1-006 のドわすれは `LockOpponentAttack`（書き方は 3 章）。
- コンパン ES3-004 のかなしばりは `LockOpponentAttackOnHeads`（要素 `OpponentAttackLock(local_coin=HEADS)`）。コインは選ぶ前で、「おもて」のときだけ決定を出します。「うら」なら
  決定を出さず、効果も与えません（ワザの失敗ではない）。決定のあとは `resume` だけで、コインを投げ直しません。
- 選ぶのはワザを使ったプレイヤーです（相手に答えさせない。相手の答え・選べるものにない答えは拒否し、状態・乱数・ログ・決定は変わらない）。使えなくなるのは選んだワザだけで、
  ほかのワザ・にげる・特殊能力は止めません。
- 選べるものは相手の対戦ポケモンが今持つワザ（［サイコリンク］で持つワザを含む。出どころのカード id と位置。`target_attack_card`）です。ワザが 1 つでも決定を出します
  （v0.35 と同じ実装上の仮定）。ワザを持たない相手（ポケモンとして出したなにかの化石）には、選ぶワザがないので、かなしばりのコインも投げません（p.309）。
- 効果だけを決めるコインなので、前の要素の「とうめい」で受けないと決まった相手には T19b、「ワザをうけない」相手には HC3（`UNRESOLVED_PREVENTED_EFFECT_COIN`）で止め、
  「ダメージを受けない」相手には投げます（v0.36 の `OpponentAttackCheck` と同じ順番。`programs.effect_coin_questions`）。「とうめい」の相手は、かなしばりのコイン → 「とうめい」の
  コインの順です。

### E. きあいいっぱつ（ワンリキー 2 枚）

`CoinNextTurnMultiplyElseLockAttack` の要素の並びは `Coin("coin")` → `SelfNextTurnAttackDamage(…, gate=("coin", HEADS))` → `SelfAttackLock(local_coin=None, target_attack_index=1,
gate=("coin", TAILS))` です。コインは 1 枚だけで、同じ結果でどちらか一方だけを与えます（要素ごとに投げ直さない）。

- 「おもて」: 次の自分の番の「どつく」30 を 2 段階で 2 倍（60）。
- 「うら」: 次の自分の番の「どつく」だけを使えない（`CannotUseOwnAttack` の `target_attack_index` 1。`ATTACK_LOCKED`）。使ったワザ「きあいいっぱつ」は使え、ワザの失敗でもありません。
- `SelfAttackLock` に、使えなくなるワザの位置（`target_attack_index`。None ならこのワザ自身）とワザ全体のコインの面（`gate`）を加えました。v0.35 のあわあわ・v0.41 のきあいずつきは
  None のままで、使ったワザ自身が使えなくなります。`SelfNextTurnAttackDamage` にも `gate` を加えました。
- 不変条件（`engine._attack_lock_problems`）は、`CannotUseOwnAttack` の使えなくなるワザを、登録の `attack_lock_terms()` の位置（None なら効果を与えたワザ）と照らします。
  `next_turn_terms()` は「おもて」の効果を照らします。ログの監査（`tests/log_audit.coin_gated_effect_problems`）は、コインが 1 枚で、「おもて」なら「数をかける」効果、「うら」なら
  登録の位置のワザを使えない効果をちょうど 1 つ与えたこと（両方を与えない）を確かめます。
- どちらも、あいだの相手の番にははたらかず、次の自分の番の終わりに消えます。次の自分の番にもう一度使うと、前の効果（その番にはたらく）と新しい効果（次の自分の番にはたらく）は
  別で、前の効果はその番の終わりに消えます。

### F. コインと、発生源がバトル場にいる間だけのワザの禁止（4 枚）

v0.40 の「すごむ」の要素 `OpponentAttackLockWhileSourceActive`・持続する効果 `CannotAttackWhileSourceActive` を使います。

- 「すごむ」の要素は「相手の最大HPが50以下」の条件つきでした。今回の説明に最大HPの条件はなく、コインの条件があるので、`max_hp` を None（条件なし）にし、この要素のコイン
  `local_coin` を加えました（`AttackLockWhileSourceActiveOnHeads`）。50 の上限は引き継がず、どの最大HPの相手にも同じ条件で作用します。
- 「おもて」なら、受けた相手の対戦ポケモンだけが、次の相手の番、効果を与えたポケモンがバトル場にいる間ワザを使えません（`ATTACK_PREVENTED`）。相手のプレイヤー全体・別のポケモンは
  止めません。「うら」なら効果を与えません（ワザの失敗ではない）。
- 効果を与えたポケモンがベンチにいる間は、受けたポケモンはワザを使えます。受けたポケモンがベンチにもどる・進化すると効果は消えます（v0.40 と同じ）。
- 同じ番に効果を与えたポケモンがバトル場にもどる場合は、既存の SG1（`UNRESOLVED_ATTACK_LOCK_SOURCE_RETURNED`。突風・かおりのわな・ワープポイントの選択）がそのまま止めます
  （型で探すので、新しいカードも同じ）。SG1 は解決していません。新しい相違は見つかりませんでした。
- 効果だけを決めるコインなので、「とうめい」で受けないと決まった相手は T19b、「ワザをうけない」相手は HC3 です（D と同じ `effect_coin_questions`）。
- 不変条件の `conditional_lock_terms()` は (型, None)（最大HPの上限なし）。
- スピードスター（PF1-004）は既存の `DamageIgnoringDefenderEffects` と全文が同じで、SS1 などの既存の境界を保ちます。みずでっぽう（PRN-003）は必要なエネルギーが「水」1 つだけ
