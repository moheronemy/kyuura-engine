## 2. 文面の違いの扱い

写し・採用した印刷の文面は変えていません。型の `check` が受け付ける説明の一覧（ホワイトリスト）に、意味が同じとわかる書き方だけを加えました。意味の違う
書き方は今までどおり受け付けません（tests/test_fifteen_reused_effects_v0_37.py の `TextVariantTest` が、受け付ける書き方と受け付けない書き方を確かめる）。

## 3. 共通の処理

### 3.1 新しく加えた型（要素は既存のものだけ）

| 型 | ワザ | 要素の並び（`programs.BUILDERS`） | 区別したこと |
|---|---|---|---|
| `PoisonOnHeadsWithoutDamage` | どくえき | `Status(POISON, local_coin=HEADS)` | ダメージのある `PoisonOnHeads`（どくばり）とは別。ダメージの要素・`damage` のログがない |
| `ParalyzeOnHeadsWithoutDamage` | うなりごえ | `Status(PARALYSIS, local_coin=HEADS, reparalysis_check=True)` | ダメージのある `ParalyzeOnHeads`（まきつく・ベトベト）とは別。同じ説明の文面でもダメージの有無で型を分ける |
| `DamageThenDrawOnHeads(count)` | ねこにこばん | `Damage(OPP)` → `Coin` → `Draw(count, gate=heads)` | ダメージだけ・引くだけのワザとは別。ダメージ → コイン → 引くの順番 |
| `DrawOnHeads(count)` | つるでさがす | `Coin` → `Draw(count, gate=heads)` | ダメージなし。山札が足りなければ引けるだけ（p.312） |
| `SelfBarrierOnHeads` | しんだふり | `SelfPersistent(AttackBarrier, local_coin=HEADS)` | ダメージなし。ダメージも効果も受けない（バリアー）。ダメージだけを受けない「かたまる」（`PreventDamage`）とは別 |
| `DamageThenReduceDamageToSelf(amount)` | かみつく | `Damage(OPP)` → `OpponentReducedDamage(amount)` | ダメージのない `ReduceDamageToSelf`（なきつく）とは別。効果はなきつくと同じ `ReducedDamageToSource`（p.321 の 2 段階・次の自分の番の始めに消える・NK5） |

引くのは自分の効果なので、相手が「ワザをうけない」状態でもコインを投げて引き（コインが決める要素に有効なものがある。v0.34 の `void_coin_question`）、相手が
このワザのダメージで HP 以上になっても引きます。どくえき・うなりごえのコインは相手への効果だけを決めるので、「ワザをうけない」相手には HC3
（`UNRESOLVED_PREVENTED_EFFECT_COIN`）で止め、「ダメージを受けない」相手（かたまる）にはコインを投げて特殊状態にします（p.321。効果の要素は有効）。

### 3.2 JS1 のための変更

`programs.BenchDamage` の `weakness_resistance` に None（説明が弱点・抵抗力について書かない）を加え、None のときだけ、控えのポケモンごとに 2 つの読み方
（計算する・しない）の最終ダメージを `kernel.weakness_resistance_matters` で比べ、違えば問い `bench_damage_weakness_resistance` で止めます（4 章）。v0.33 の
ミニじしん（`weakness_resistance=False`）・v0.31 のもえひろがるなどの既存の控えへのダメージの処理は変えていません。

### 3.3 再利用したもの

`CannotAttackOnHeads`（v0.31）・`ParalyzeOnHeads`（v0.3b）・`ReduceDamageNextTurn`（v0.31）・`DamageThenAttackCoinCheck`・`DamageThenRetreatLock`（v0.36）・
`DamageThenSelfBarrierOnHeads`（v0.34）・`SelfDamageOnTails`（v0.2f）・`DamageAndOwnBenchDamage`（v0.33）・`LockOpponentAttack`（v0.35）・`CoinFlipDamage`（v0.2d）・
`ExtraEnergyDamageMixed`（v0.31。HC4 を同じコードで使う。新しいコードにしていない）・`DamageThenDiscardOpponentEnergy`（v0.33）・`SleepOpponent`（v0.9）・
`DamageOnly`。持続する効果の型・書き出しの形式・ログのイベント・決定の種類は増やしていません。

### 3.4 変えたもの

- `DamageThenSelfBarrierOnHeads`・`LockOpponentAttack`・`DamageThenReduceDamageToSelf`（新）・`DamageAndOwnBenchDamage`: 受け付ける説明の一覧（2 章）

- 問いの表（`resolution/questions.py`）に JS1 の問いを加えた
- 写しの元を抜き出す道具（`scripts/extract_kyuura_cards.py`）に `POOL_V0_37` を加え、化石の秘密のベトベターを参照カードの一覧から外した
