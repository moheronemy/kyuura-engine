# v0.129: カツラのクイズ その1と、公式図鑑の種族の身長の参照値

v0.129（版 0.129.0）は、カツラのクイズ その1（GD5-016）を登録する版です。説明の「その身長」の正解には、kyuura が集めた公式図鑑の種族の身長（全国図鑑 No.001〜251・通常の
姿）を使います。**これは利用者の指定です**（3 章）。出題したカードの印刷の身長を確かめた値ではなく、印刷の訂正・公式の裁定・最新の説明・エラッタとしては記録しません。
`engine.py`・`resolution/` にカードの id による分岐は加えていません。

## 3. 利用者が指定した参照値（USER-QUIZ-HEIGHT-OFFICIAL-ZUKAN）

利用者の指定（2026-11-01）は「クイズの正解には、今回収集した全国図鑑No.001〜251の通常の姿の公式図鑑値を採用します。」です。

- 当てはめるのは、カツラのクイズ その1の「その身長を答えてもらう」「正解なら」の正解だけです。置いたカードの全国図鑑番号の種族の身長（整数 cm）を正解とし、答えの整数 cm と完全に
  同じなら正解です。処理に使う文面は kyuura の印刷の文面のまま（簡略化・訂正していない）です。
- 出題したカードの印刷の身長を確かめた値ではありません。カードの時期（1996〜2001年）の図鑑の値と今の公式ずかんの値が同じとも確かめていません（kyuura の引き継ぎの 3 章の事項）。
  印刷の訂正・公式の裁定・最新の説明・エラッタとしては記録しません。
- 記録: 対象ごとの記録 `effects.USER_SPECIFIED_REFERENCES`（`UserSpecifiedReference`。対象 `GD5-016/trainer`・種類 `USER-QUIZ-HEIGHT-OFFICIAL-ZUKAN`・印刷の文面・当てはめる部分・

  記録・別の種類で、両方に入る対象はありません。
- 採用の記録（`card_sources.json`）: `play_text` の根拠は `kyuura_printed_text`（文面は印刷のまま）で、参照値は別の欄 `user_specified_reference`（`trainer` →

- 研究の対応表（`research_links.json`）: 新しい区分 `latest_descriptions.user_specified_references`（`GD5-016/trainer` → 同じ出典）。`adopted_printed_text`（印刷の文面の採用。
  1,390 のまま。もともとワザ・特殊能力の区分でトレーナーは入らない）・`user_simplified_text`（v0.127）には入れていません。
- 検査: `scripts/check_card_sources.py` は、記録のあるカードには `user_specified_reference` が必ずあり、ないカードには書けないこと、処理に使う文面の根拠が印刷の文面のままで、登録の

  指定の文がこの文書の引用（「」）にあること、研究の対応表の区分にあることを照らします。`scripts/check_research_links.py` は、区分の一覧が記録とちょうど同じで、文面の区分に入らず、

## 4. カードの処理

印刷の文面（kyuura `71d1728`。写しの文面と同じ）: 「あなたの手札から「ポケモン」のカードを1枚選び、おもてを下にして、置く。相手プレイヤーにそのポケモンの名前を伝え、その身長を答えて
もらう。その後、置いたカードをおもてにして、正解なら、相手プレイヤーは山札からカードを2枚引く。正解でないなら、あなたは山札からカードを2枚引く。(置いたカードは、手札にもどす)」

登録は `BlainesHeightQuiz`（`effects.py`。写しの組 `pool_v0_129`）。v0.63 のカツラのクイズ その3（`BlainesQuiz`）・v0.80 のその2（`SetAsideGuessKindQuiz`）と、置く場所
（`zones.set_aside_quiz_card`・`SET_ASIDE_QUIZ`）・手札にもどす処理（`zones.return_set_aside`）・引く処理（`_draw_up_to`）・置いたカードのまとまりの探し方（`_quiz_group`）を共有します。

1. 使ったプレイヤーが、手札の「ポケモン」のカード（手札にある間の印刷の分類。たね・1 進化・2 進化・ベイビィ。ワザの有無は問わない。なにかの化石・ピッピ人形はトレーナーカード）を
   1 枚選び、おもてを下にして置く（決定 `QUIZ_CARD`。置いたカードは使ったプレイヤーだけが見る）。
2. 相手プレイヤーに、置いたカードの名前を伝える（ログ `quiz_name_hint` は名前だけ。カードの名前のまま伝える: 「エリカのフシギダネ」「ポリゴン2」）。カードの id・uid・収録・図鑑番号・
   身長は伝えません。
3. 相手プレイヤーが身長を答える（決定 `QUIZ_HEIGHT_ANSWER`。値で答える決定で、答えは整数 cm。5 章）。
4. 置いたカードをおもてにして正誤を判定する（ログ `quiz_height_answer`（答え）・`quiz_height_reveal`（カード・名前・図鑑番号・身長の参照値・正解か））。正解の値は、答えのあとに置いた
   カードの図鑑番号から引きます（決定の続きの情報に入れない）。
5. 正解なら相手プレイヤーが、正解でないなら使ったプレイヤーが、山札から 2 枚引く（効果で引く。山札が足りなければ引けるだけで、0 枚でも負けではない。p.312。v0.63 のその3 と同じ規定）。
6. 置いたカードを手札にもどす（ログ `set_aside_returned` の `reason` `quiz`。表にしたので全員に見せる）。順番は説明の文の順（おもてにする → 引く → もどす）。

相手の答えを、使ったプレイヤーが選ぶ「正解／不正解」には置き換えていません（答えるのは相手プレイヤーで、正誤はエンジンが判定する）。

## 5. 答えの表現（値で答える決定）

- エンジンの API が受け付ける答えは **整数 cm** です（`ResolveDecision(相手, 決定の番号, (cm,))`）。単位の換算はエンジンの外の層の責任で、人向けの入力には
  `heights.height_answer_cm`（「0.4m」「0.4 m」「40cm」→ 40。全角は NFKC で半角にそろえる。十進数のまま換算し、浮動小数点の丸めで正誤が変わらない）を用意しました。単位のない数
  （「40」「0.4」）・整数 cm にならない値（「0.405m」）・0 以下は `ValueError` で、m か cm かを推測しません。
- 既存の決定は選べるものの有限の並び（`options`）から選ぶ形でした。身長の答えを正解の値の集合（251 種族の値）に絞ると、選べるものから正解が漏れ、参照値にない誤った答えを表せません。
  そこで共通の決定に **値で答える決定** を加えました（`decisions.VALUE_RANGE`）。`context` の `"value_range"`（(下限, 上限)）を持つ決定は、選べるものを並べず（`options` は空・選ぶ数 1）、
  その範囲の整数 1 つを答えにします（`decisions.check_choices`）。その1 の範囲は 1〜2^53 − 1（`VALUE_ANSWER_MAX`）です。上限は、書き出し・ログ・観測の JSON で整数を誤差なく表せる
  表現の上限で、答えの候補を絞るための値ではありません。
- 不正な答え（範囲の外・0・負・bool・整数でない値・2 つ以上・0 個・答えるプレイヤーでない）は、状態・乱数・ログを変えずに拒否します（`INVALID_CHOICE`・`INVALID_CHOICE_COUNT`・
  コマンドの形の `BAD_COMMAND`）。拒否の文に置いたカード・正解は書きません（範囲だけ）。
- 共通の処理の変更（カード id によらない）: 答えの並び（`programs.iter_answers` は範囲の整数を小さい順に 1 つずつ、`answer_count` は範囲の数、`all_answers` は並べられないので
  `ValueError`）、決定の不変条件（範囲の形・選べるものなし・選ぶ数 1・止める選択なし）、観測（値で答える決定は選べるものを並べず、範囲と単位 cm・伝えた名前を全員に見せる）。答えの
  続きを試す確かめ（`_trainer_dead_end`・`_decision_has_unstopped_answer`）は、答えの数が上限（256）を超えるので、既存の扱いのとおり続きがあるとみなします（その1 はどの答えも受け付ける）。
- 道具: `tools/existing_effect_games.py` の方策は 8 章。`tools/compat_driver.py`（lockstep・前の版との比べの駆動）は変えていません。駆動の指紋が過去の版から作った比べ用の参照データ
  （`tests/fixtures/compat_base_4bd97bf.json`）に記録されていて、変えると参照データを基準の版から作り直すことになるためです。その駆動の組（`tools/stress_engine.py` の決まったデッキ）に
  その1 は入らないので、値で答える決定には届きません。

## 6. 図鑑番号・身長がないカード、手札にポケモンがない、ほかの経路

- **図鑑番号・身長がないカード（エンジンの未対応。研究上の未解決ではない）**: 印刷上は選べるので、選べるもの（`QUIZ_CARD` の `options`）から除きません。選んだ時点で、状態・乱数・
  ログを変えずに `UNSUPPORTED_QUIZ_HEIGHT_WITHOUT_DEX`（図鑑番号がない）・`UNSUPPORTED_QUIZ_HEIGHT_NOT_AVAILABLE`（図鑑番号の種族に確定した値がない・図鑑番号が 2 つ以上ある）で
  止めます（既存の選ぶと止める選択 `unresolved_choices`・選択ごとの理由 `unresolved_detail`。決定は待ったまま、ほかのカードを選べる）。手札の選べるカードがどれもそうなら、使う前に
  そのコードで止めます（手札全体を必要以上に拒否しない。1 枚でも参照値のあるカードがあれば使える）。選ぶ決定の観測は、決めるプレイヤーでない人には種類と決めるプレイヤーだけです
  （v0.63 の `HIDDEN_COUNT_KINDS`。止めるカードの有無・選べる数を見せない）。止めるコードは研究の対応表の停止コードに入れていません（`UNSUPPORTED_`。v0.18e の数え方）。
- **QZ1 の再利用**（`UNRESOLVED_BLAINES_QUIZ_WITHOUT_POKEMON`。kyuura UQ-CARD-USE-WITHOUT-TARGET）: 使ったカードを除く手札に「ポケモン」のカードがないとき（手札がない・トレーナー・
  エネルギーだけ・なにかの化石だけ）、使う前に止めます。その3 と同じ「手札から「ポケモン」のカードを1枚選び」で、選べるカードがないときに使えるかを説明が書いていない問いです。
  新しい問いにしていません（研究の対応表の QZ1 に v0.129 の当てはめを加えた。停止コードの数は 313 のまま）。図鑑番号の欠けとは別のコード・別の扱いです。
- **山札が足りない**: 引けるだけ（v0.63 のその3 と同じ。p.312）。新しい問いにしていません。
- **錯乱ジム**: 相手が借りて使うと、「あなた」は借りたプレイヤーで、借りたプレイヤーの手札から置き、使ったプレイヤーの相手（番のプレイヤー）が答え、正解でないなら借りたプレイヤーが
  引きます。説明に使ったプレイヤーの番を書かないので CH1 ではありません（その3 と同じ）。
- **おもてのカードのある山札（v0.126。フラッシュ）**: 引くのは答えの正誤で決まるので、答えを拒否すると、拒否の有無から正誤（置いたカード）が漏れます。そこで、使う前に、正解・正解でない
  のどちらの引き方も状態の複製の上で試し、どちらかが既存のおもての山札の止め方（`faceup.command_problem`。FU3 など）に当たるなら、使う前にそのコードで止めます
