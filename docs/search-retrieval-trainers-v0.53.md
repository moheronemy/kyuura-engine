# v0.53: 山札・トラッシュからカードを選ぶトレーナー 10 枚

v0.52 の最終コミット `adc5448` から、ブランチ `claude/v0.53-search-retrieval-trainers` で作業しました（版 0.53.0）。山札をさがして手札に加える・トラッシュから手札・山札に
もどす・手札を山札にもどして引くトレーナー 10 枚を 1 つのバッチとして加え、共通の処理（選べるカードの種類・枚数・見せるか・行き先・使うための条件・コイン）を整えました。

## 2. 再利用した処理と新しく加えた処理

再利用（動き・ログは v0.52 と同じ）: トレーナーの使用（`engine._play_trainer`。トレーナーの使用の禁止 `TRAINER_PREVENTED` の確かめ → `check_playable` → 手札から出す →
`resolve`）・使用中のカード（`trainer_in_use`）・決定と再開（`push_trainer_decision`・再開先 `"trainer"`・`_resume_trainer`）・使い終えたらトラッシュして同じ番の `MAIN`
（`_finish_trainer`。10 枚とも `may_knock_out`・`empties_active` は偽で、きぜつ・バトル場に出す処理はしない）、ゾーンの関数 `discard_from_hand`（パソコン通信・エネルギー回収と
同じ公開のログ）・`search_deck_to_hand`（パソコン通信と同じ見せないログ）・`reveal_deck_to_hand`（ポケモン交換おじさんと同じ見せるログ）・`return_discard_to_hand`・
`shuffle_deck`・`draw_cards`、決定の種類 `discard_from_hand`・`search_deck`・`hand_to_deck`・`recover_trainer`・`discard_to_deck_top`、コイン `flip_coins`（1 枚 1 回）。

共通にしたもの（本当に共通の部分だけを引数にした。カードごとの複製・汎用の条件の書き方にしていない）:

- `effects.CardFilter`: 選べるカードの種類。説明の言葉と 1 対 1 の決まった種類（`any`・`trainer`・`basic_energy`（タイプ指定あり）・`pokemon`（進化カードだけ）・
  `pokemon_or_basic_energy`）と名前の始まり（「わるい」「タケシの」「エリカの」）。カード id の一覧で決めない。
- `effects.SearchDeckTrainer`（山札をさがす 6 枚）: 引数は文面・種類・最大の枚数・選ばなくてよいか（「てよい」「ことができる」）・見せるか・コイン・使うための条件
  （トラッシュする枚数・山札にもどす枚数）。`check` が、登録の値と文面の言葉（見せ・てよい／ことができる・コイン・最大の枚数・条件の文）が合うかを確かめる（登録の誤りを
  見つける）。
- `effects.TakeFromDiscardTrainer`（トラッシュから選ぶ 3 枚）: 引数は文面・種類・最大の枚数・行き先（`TO_HAND`・`TO_DECK_TOP`・`TO_DECK`）・選ばなくてよいか・0 枚の扱いが
  決まらないか（NG1）・コイン・使うための条件（すてる枚数）。
- `effects.ReturnHandToDeckThenDraw`（メンテナンス）。

新しく加えたもの:

- `zones.return_discard_to_deck`（自分のトラッシュのカードを、見せて山札の一番下にもどす。ログ `discard_to_deck` は公開。夜の廃品回収）。
- `zones.return_hand_cards_to_deck`（v0.44。ワザ）・`zones.put_discard_on_deck_top`（v0.44。ワザ）に、トレーナーの出どころ `trainer`（ログの `trainer_card`）を加えた
  （ワザの `effect` とちょうど一方。ワザのログの形・項目の順番は v0.52 と同じ）。
- 決定の種類 `discard_to_deck`（夜の廃品回収。選べるものはトラッシュのカード。観測の意味は `card`）。
- ログのイベント `retrieve_trainer`（ダウジングマシーン。公開）・`discard_to_deck`（公開）・`trainer_take_none`（選ばずに終わった。理由 `reason` は使ったプレイヤーだけが見る）。
- トレーナーのコイン: `coin_flip` の `source` は `"trainer"`、`effect` はカード id、`card` は使っているトレーナーのカード。

## 3. 条件・選べるもの・見せるか・順番

### 3.1 使うための条件（手札から出す前）

- カスミのなみだ（「…トラッシュしなければ、このカードは使えない」）・エリカのお付き（「…それができない時、このカードは使えない」）: このカードを除く手札が 1 枚・2 枚より少なければ
  `IllegalActionError("INSUFFICIENT_CARDS_IN_HAND")`（パソコン通信・エネルギー回収と同じ）。どの種類のカードでもよい。使っているこのカードは数えない（手札に別の同じ名前の
  カードがあれば、それは手札のカード）。
- ダウジングマシーン（「手札からカードを2枚すてることによって、…ことができる」）: 「…ことによって」は、すてることで手札に加えられるという条件の言い回しと読み、このカードを
  除く手札が 2 枚より少なければ同じ `INSUFFICIENT_CARDS_IN_HAND`（実装上の読み方。すてずに使うことはない。DM1）。
- メンテナンス（「手札から2枚のカードを選び山札に戻す。」）: 印刷の文面に「使えない」はないので、使うための条件にしない。このカードを除く手札が 2 枚より少ない場面は、v0.44 の
  ラッキーたまご（「自分の手札からカードを2枚選び、山札にもどして」）と同じ問い FC1（`UNRESOLVED_STATED_CARDS_SHORT`。説明が決まった枚数のカードを選ばせるとき、選べるカードが
  足りない場合）で、手札から出す前に止める（6 章）。
- 使うための条件のカードは、条件の決定（`discard_from_hand`・`hand_to_deck`。ちょうどその枚数）で選ぶ。すんだ条件は、そのあとの不正な答えで取り消さない（パソコン通信と同じ）。

### 3.2 選べるもの

- 種類は、その場所のカードの印刷の定義で決める（`GameState.card_def`。山札・トラッシュではなにかの化石・ピッピ人形はトレーナーカード）。モンスターボール・タケシの育て方・
  エリカのお付き・夜の廃品回収の「ポケモン（のカード）」に、なにかの化石・ピッピ人形は入らない（ダウジングマシーンの「トレーナーカード」には入る）。
- エネルギー転送の「エネルギーカード（特殊なエネルギーカードは選べない）」は基本エネルギーカード、カスミのなみだの「「水」エネルギーカード」は「水」の基本エネルギーカード
  （ほかの色として使えるエネルギーを数えない。今の写しに特殊エネルギーのカードはない）。夜の廃品回収の「エネルギーカード(特殊エネルギーカード以外)」も基本エネルギーカード。
- ボスのやりかたの「わるいポケモンへの「進化カード」」は、進化カード自身の名前が「わるい」で始まるもの（わるいポケモンの進化元が「わるい」だと仮定しない。ロケット団のズバットは
  選べない）。タケシの育て方の「「タケシのポケモン」(たねポケモンカードまたは進化カード)」・エリカのお付きの「「エリカのポケモン」」は、名前が「タケシの」「エリカの」で始まる
  たねポケモンのカード・進化カード（v0.45 のたすけをよぶの「タケシの」と同じ、名前の始まりの判定）。
- 山札の選べるものは uid の小さい順（山札の並びを写さない）、トラッシュの選べるものはトラッシュの並び。同じ名前の別のカードはどれも選べる。同じカード（uid）を 2 回選ぶ答えは
  決定の確認が `DUPLICATE_CHOICE` で拒否する。
- 前の段階で動いたカードは、次の段階の選べるものに入る: エリカのお付きでもどしたカードは山札にあるので選べる（使う前の山札にエリカのポケモンがなくても使える）。ダウジング
  マシーンですてたカードは、トラッシュのトレーナーカードなら選べる（説明に、エネルギー回収の「ただし、このカードを使うためにトラッシュしたカードを選ぶことはできない。」が
  ない。DM2）。選べるものは条件のあとに求める。
- 使っている最中のトレーナーはまだトラッシュにない（使い終えてからトラッシュする）ので、ダウジングマシーン・リサイクルで選べない。トラッシュにある別のダウジングマシーンは選べる。
- ダウジングマシーンの「トラッシュ」は自分のトラッシュ（相手のトラッシュ・場のトレーナーは選べない。カードを相手の手札に移すことはないので、自分のトラッシュと読む。DM3）。
  リサイクル・夜の廃品回収は説明に「自分の」「あなたの」がある。

### 3.3 選ぶ枚数（対象がない・選ばない）

- 「てよい」（カスミのなみだ・エリカのお付き）・「ことができる」（モンスターボール・ダウジングマシーン）: 0〜min(最大, 選べるもの) 枚。0 枚は選ばないこと（v0.50 の退化スプレー・
  v0.51 の元気のかけらの「ことができる」と同じ読み方）。選べるカードがなければ決定を出さずに選ばずに終わる（ログ `trainer_take_none`）。どちらの場合も、そのあと山札を切る
  （山札をさがす 4 枚。説明の「その後」は山札をさがしたあと）。
- 選ばなくてよいと書かれていない 1 枚（エネルギー転送・ボスのやりかた・タケシの育て方・リサイクル）: ちょうど 1 枚（0 枚の答えは `INVALID_CHOICE_COUNT`）。選べるカードがない
  場面は ST1 で使う前に止める（6 章）。
- 夜の廃品回収の「最大3枚選び」: 0〜min(3, 選べるもの) 枚で決定を出し、0 枚の答えは NG1 で止める（決定は待ったまま。1 枚以上を選び直せる）。選べるカードがなければ使う前に
  NG1 で止める（選べるのは 0 枚しかないので、同じ問い）。

### 3.4 見せるか

| 動き | ログ | 見える範囲（観測） |
| --- | --- | --- |
| 山札から見せて手札に加える（「相手プレイヤーに見せてから」「選んだカードは相手に見せる」） | `reveal_from_deck` | 公開 |
| 山札から見せずに手札に加える（エネルギー転送。見せる指示がない） | `search_deck` | `card` は使ったプレイヤーだけ（v0.22 の CS14 と同じ） |
| 手札から見せずに山札にもどす（エリカのお付き・メンテナンス。見せる指示がない） | `hand_to_deck` | `cards` は使ったプレイヤーだけ（枚数は見える） |
| 引く（メンテナンス） | `draw` | `cards` は使ったプレイヤーだけ |
| 手札をトラッシュする（カスミのなみだ・ダウジングマシーン） | `discard_from_hand` | 公開（トラッシュは公開の情報） |
| トラッシュから手札に加える（ダウジングマシーン） | `retrieve_trainer` | 公開（公開のトラッシュから動いた） |
| トラッシュから山札の一番上に置く（リサイクル） | `put_discard_on_deck_top` | 公開（置いたカードはどちらも知る。山札のほかのカードは見えないまま。観測の山札は枚数だけ） |
| トラッシュから見せて山札にもどす（夜の廃品回収） | `discard_to_deck` | 公開 |
| 選ばずに終わった | `trainer_take_none` | `reason`（`no_target`・`declined`）は使ったプレイヤーだけ（山札をさがして選べるカードがなかったかは山札の中身の情報） |

山札の選べるもの（決定の `options`）は、決めるプレイヤーにだけ観測で見える（v0.47 の `DECK_REVEALING_KINDS` の `search_deck`）。ログに山札の選べるもの・手札のほかのカードは
書かない。

### 3.5 順番

- 山札をさがす: 使うための条件 → （コイン）→ 選ぶ → 選んだカードを uid の小さい順に手札に加える → 山札を 1 回切る。
- モンスターボール・リサイクルのコインは使うための確かめのあと・カードを見る前に 1 枚だけ投げる（投げ直さない）。「うら」なら何もしない（山札を見ず、切らない。モンスター
  ボールの「その後、自分の山札をよくきる」は「おもて」のときの山札をさがす処理のあと。v0.44 のおつかい・v0.45 のたすけをよぶと同じ読み方。MB1）。
- メンテナンス: もどす → 切る → 1 枚引く（説明の「その後で山札をよくきってから1枚ひいて」。切る前に引かない）。もどしたあとの山札は 2 枚以上なので、引けないことはない。
- リサイクル: 山札の一番上に置き、切らない（説明にない）。置いたカードは、次に引くカード（tests の対戦で、置いたカードをあとの番の最初に引いたことを数えた）。

## 4. トレーナーの進行・原子性

- どの拒否（`INSUFFICIENT_CARDS_IN_HAND`・ST1・NG1・FC1・`TRAINER_PREVENTED`）も手札から出す前で、状態・ログ・乱数は変わらない（リサイクルの ST1 はコインの前）。
  トレーナーの使用の禁止（［アレルギーかふん］・ずつう・こうしゅうは）は、ST1 などより先に確かめる（エンジンの共通の順番）。
- 決定への不正な答え（枚数・重複・選べないもの・NG1 の 0 枚）は決定の確認が拒否し、決定は待ったまま（すんだ使うための条件・コインは取り消さない）。答えのない決定を出さない
  （選べるカードがなければ決定を出さない。NG1 は 1 枚以上の答えがある）。使用中のカードを残して止まらない。
- 使い終えたらカードをトラッシュし、同じ番の `MAIN` にもどる。場を変えないので、きぜつ・バトル場に出す処理（`resolution.after_trainer`）はしない。

ST1 は、使う前に山札の中身（見えない情報）で止める。止まったことは使ったプレイヤーにだけ分かる（使ったプレイヤーの山札の情報。相手には何も起こらない）。山札が 0 枚の
モンスターボールの「おもて」・カスミのなみだ（「てよい」）は止めない（選ばずに終わって切る）。

技術的な制限: なし（どの場面も、状態を変える前に止めるか、決まった処理をする）。
