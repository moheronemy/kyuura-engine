## 2. 特殊能力を止める効果（まきちらせ!ベトベトガス・ショックアイ）

kyuura の研究の基準のコミットの記録を、エンジンの番号 PS-R1〜PS-R3 で再利用しました（研究の対応表の `applied_rule_records`。記録の文面は写していない）。

| 番号 | kyuura の記録 | 使い方 |
| --- | --- | --- |
| PS-R1 | CR-CHEMICAL-GAS-USE-VS-POWER（SUPPORTED） | 「特殊能力を使うことができず」は宣言して使う特殊能力の使用を、「その力も消える」は常にはたらく・自動的にはたらく特殊能力の力を止める。まきちらせ!ベトベトガスは両方、ショックアイ（「使うことができない」だけ）は使用だけ |
| PS-R2 | CR-CHEMICAL-GAS-ALL-POWERS（CONFIRMED） | 「すべての特殊能力」は宣言して使う・常にはたらく・自動的にはたらく特殊能力のすべて |
| PS-R3 | CR-POWER-BACK-AFTER-RECOVERY（SUPPORTED） | p.265 のまきちらせ!ベトベトガスの解説「［かがくへんかガス］の力を一時的に消す」の記録。かがくへんかガスも止め（除かない）、効果が消えたら力がもどる |

まきちらせ!ベトベトガス:

- 使ったプレイヤーの期限のある効果（v0.56 の `GameState.trainer_effects`。`TrainerTurnEffect` の種類 `POWER_SUPPRESSION`。消える番は使った番 + 1）。消える番の終わりに
  `procedures.expire_at_turn_end` が消します（ログ `trainer_effect_added`・`trainer_effect_removed`）。場のポケモンに印を付けず、はたらいているかは問い合わせのたびに
  `continuous.goop_gas_effects` で求めます。
- 特殊能力が止まっているかは `continuous.power_suppressed(state, power)`（かがくへんかガスの `suppressors_of` と、この効果）だけで聞きます。v0.8 から `suppressors_of` を
  聞いていた場所（宣言 `engine._use_pokemon_power` の `POWER_SUPPRESSED`・常にはたらく特殊能力 `effects.continuous_powers`・「とうめい」・「はんげき」・こんじょう・
  ふしちょう・ほのおでかいふく・［へんしょく］・［へんしん］・［サイコリンク］・めんえき・場に出たときの特殊能力の機会・解決の基盤の `catalog`）をこの関数に置きかえました。
  判定を複製していません。
- かがくへんかガスも止まります（PS-R3）。ガスどうしが消し合わない v0.8 の規定（名前で除く）はかがくへんかガスどうしのもので、この効果には当てはめません。
- 止まるのは場のポケモンの特殊能力です。使う前にすませた特殊能力の結果は戻しません（v0.8 の G27 と同じ）。
- GG1（5 章）: 止める範囲が、使った時点で場にいたポケモンだけか、あとから場に出た・進化した・退化したポケモンも含むかは決まりません（kyuura の card_differences の
  PMCG4-056 は二次資料の説明で確度は有力。印刷の文面と pcg-search.com の文面のどちらでも決まらない）。効果のはたらく間に、特殊能力を持つポケモンが場に出る・進化する・
  退化する操作（`effects.goop_gas_entry_check`。`zones.enter_play`・`evolution.place_evolution_card`・`evolution.devolve` が状態を変える前に呼ぶ）を止めます。特殊能力を
  持たないポケモンは止めません（どちらの読み方でも止める力がない）。これで、効果のはたらく間に場にいる特殊能力を持つポケモンは、どれも使った時点で場にいた同じ姿のポケモンになり、
  どちらの読み方でも止まるので、効果のはたらく間は場のすべての特殊能力を止めます。
- 錯乱ジムで相手プレイヤーが借りて使う場面は、説明が使ったプレイヤーの番（「次の相手の番」）を書くので v0.57 の CH1（`refers_to_user_turn`）です。

ショックアイ:

- 選んだ相手の場のポケモン（バトル場・ベンチ）への 10 ダメージ（v0.43 の `ChooseOpponentPokemonDamage`。弱点・抵抗力を計算しない）のあと、相手に与える持続する効果
  `state.CannotUsePowers`（はたらくのは与えた番から次の相手の番の終わりまで。`from_creation`・ベンチでもよい `bench_ok`）。相手のポケモンへの効果なので「ワザをうけない」
  状態・「とうめい」を評価し（要素の種類 `power_lock`）、このワザで HP 以上になったポケモンには与えません（p.309）。
- 受けたポケモンは、宣言して使う特殊能力を使えません（`engine._use_pokemon_power` が `POWER_USE_PREVENTED`。`persistent.powers_use_prevented`）。宣言して使う特殊能力の
  使う機会（こんじょう・ふしちょうの決定・場に出たときの特殊能力）も出しません（`catalog.offer_stopped`・`effects.ko_prevention_suppressed`）。常にはたらく・自動的に
  はたらく特殊能力の力は消しません（PS-R1）。英語版の「that power stops working」は根拠にしていません。
- 消える契機はほかの持続する効果と同じ（期限・ベンチにもどる・進化・場をはなれる）です。持続する効果の不変条件は、効果のどれもが `bench_ok` のときだけベンチのポケモンに
  持続する効果を許します（広げない）。
- こんじょうを使えるポケモンを選んだ場合、G37（v0.11。`UNRESOLVED_KO_PREVENTION_ATTACK_EFFECT`）です。宣言の前の先読みは、選ぶ答えのどれかが問いに当たれば宣言の前に
  止めるので、相手の場にこんじょうを使えるポケモン（サカキのカイリキー）がいて、10 ダメージで HP 以上になりうるときは、ほかのポケモンを選ぶつもりでもワザを使えません
  （v0.15c からの先読みの動き。v0.59 では変えていない）。

## 3. ［エネエネ］（マルマイン）

- 宣言して使う特殊能力（自分の番に何度でも。このカードが場をはなれるので 1 回）。ねむり・マヒ・こんらんのこのカードは使えません（`POKEMON_ASLEEP`・`POKEMON_PARALYZED`・`POKEMON_CONFUSED`。どくは使える）。
  かがくへんかガス・まきちらせ!ベトベトガス・ショックアイは共通の確認。
- 宣言のあと、使ったプレイヤーが、つける先（決定 `select_pokemon`。自分のほかの場のポケモンと相手の場のポケモン）→ 色（決定 `select_color`）を選びます。どちらも
  マルマインが場にいる間の決定です。
- 色を選んだら、使用後の処理（v0.42 の `resolution.after_power`）が、マルマインをきぜつさせ（ログ `knock_out` の `timing` は `power`・`to_energy`。重なったカード・ついている
  カードはトラッシュ、マルマインのカード（いちばん上）はトラッシュしない）→ 同じ uid のカードをつける先のエネルギーに加え、エネルギーとしての役割を記録（`attach_converted_energy`。
  `GameState.energy_roles` の `EnergyRole`。ログ `energy_conversion`）→ 相手がサイドを取る → 勝ち負け → バトル場に出す → 同じ番の `MAIN`。「きぜつ」なので相手は
  サイドを取ります。
- エネルギーとしての役割: 記録があり、そのカードが場のポケモンについているあいだだけ、カードの定義は特殊エネルギーの種類（`state.energy_role_definition`。印刷のカードの id・
  名前のまま。基本エネルギーカードではない）で、出すエネルギーは選んだ色 2 個（v0.58 の `effects.energy_units`）。ワザ・にげるの支払いは 2 個として数えます。場のポケモンの
  あいだのつけかえでは役割を保ちます。ついていなくなったら（トラッシュ・手札など）印刷のポケモンのカードにもどり、記録はコマンドの終わりに消します（`engine._apply`。実装上の判断）。
  印刷の定義（`CardDefinition`）は書きかえていません。
- 手札から出してつけることではないので、手札からつける通常の操作の回数・つけたときの効果（特殊エネルギーの説明）には数えません。
- 決まらない場面（5 章）: 相手のポケモンにつける（BZ1）・役割のカードを説明の「「X」エネルギー(カード)」として数える・選ぶ・つけたときの効果に当てはめる（BZ2。RB1 と同じ
  場所で聞く。つける先がほのおでかいふくを持ち、その色を選ぶときも）・無色・悪・鋼（BZ3）・「ばける」でのせたマルマインのカード（BZ4）・クリスタルビームを受けたポケモンにつける
  （CB1）。2000年3月の『トレーナーズ』の説明（8 色から選ぶ）は 2000.02.14 版のあとの記録なので使っていません。基本エネルギーの 6 色（草・炎・水・雷・超・闘）は止めません。
- ［へんしん］のメタモンが写したマルマインの［エネエネ］は v0.49 の TF1（写した特殊能力）です。

## 4. エネルギーをつける操作を変える効果（カツラ・クリスタルビーム・タケシの保護）

カツラ:

- 使ったプレイヤーの期限のある効果（`TrainerTurnEffect` の種類 `FIRE_DOUBLE_ATTACH`。この番だけ。消える番は使った番）。
- 手札からつける通常の操作 1 回（`AttachEnergy`）で、`energy2` に 2 枚目の「炎」エネルギーカードを渡すと、同じ「カツラのポケモン」（今の姿の名前が「カツラの」で始まる）に
  2 枚をつけます（ログ `attach_energy` の `energy2`・`trainer_card`）。操作は 1 回で、`energy_attachments_this_turn` は 2 になります（不変条件は、この番に 2 枚をいっしょにつけたログがあれば上限を 1 枚多くする）。`energy2` は既定の None なら辞書に書かず、v0.58 までの形のままです。
- 拒否（カードを動かす前）: カツラの効果がない・つける先がカツラのポケモンでない（`DOUBLE_ATTACH_NOT_ALLOWED`）・炎エネルギーカードでない（`NOT_FIRE_ENERGY`）・同じカード
  （`DUPLICATE_CHOICE`）。レインボーエネルギーは v0.58 の RB2（「「炎」エネルギーカード」として選べるか）。
- BL1（5 章）: 1 枚目を通常の操作でつけたあとに、2 枚目を別の操作でつけられるか（「1枚でなく2枚にする」が 1 回の操作の枚数か、番の枚数か）は決まらないので、カツラの効果の
  はたらく番の 2 回目の通常の操作を止めます。2 枚を 1 回の操作でつけるのは、どちらの読み方でもできるので受け付けます。英語版の「(Playing additional copies of this card
  this turn has no effect.)」は根拠にしていません（2 枚目のカツラは効果を重ねずに使える。実装上の読み方）。
- 手札からつけたので、つけたときの効果（v0.58。特殊エネルギーの説明・ほのおでかいふく）は 1 枚ずつ処理します。

クリスタルビーム:

- ダメージ → 要素のコイン →「おもて」なら相手に与える持続する効果 `state.CannotAttachEnergy`（はたらく番は次の相手の番。要素 `programs.OpponentAttachLock`。v0.41 の
  `OpponentRetreatLock` と同じ形）。相手がこのワザで HP 以上ならコインを投げません。「ワザをうけない」・「とうめい」で受けない相手は HC3・T19b（効果だけを決めるコイン）。
- はたらく番の間、受けたポケモンには、手札からつける通常の操作・カツラ・あまごい（`ENERGY_ATTACH_PREVENTED`）・ワザで手札・山札・トラッシュからつける効果（選べるものから
  除く）でエネルギーカードをつけられません（`effects.energy_attach_block` を共通に聞く）。
- CB1（5 章）: 場のエネルギーのつけかえ（エナジートランス・ナツメ・エネルギーサーキュレート・ようぶんきゅうしゅうなど）・［エネエネ］が「エネルギーカードをつける」に当たるかは
  決まらないので、受けたポケモンを移動先・つける先に選ぶと止めます（ほかの移動先は止めない）。v0.58 で使った CR-ENERGY-TRANS-NOT-ATTACHMENT（「つけかえは手札からつけることでは
  ない」）は、つけたときの効果を起こすかの記録で、この禁止の範囲を決めるものとしては使っていません。

タケシの保護:

- v0.2c のついているトレーナーの共通の処理（`zones.attach_trainer`。有効期限なし `discard_at_end_of_turn=None`）。ベンチにもどる・入れ替え・進化では受け継ぎ、場をはなれたら
  ほかのついているカードと同じく動きます。選べるのは今の姿の名前が「タケシの」で始まる自分の場のポケモン（v0.44 の `owner_pokemon`）。いなければ v0.44 の TR1。
- つけているポケモンのエネルギーカードは、相手プレイヤーの使うワザ・トレーナーカード（錯乱ジム・サイキックコントロールで使うときは使うプレイヤー）でははがされません
  （`effects.energy_removal_protected`）。はがす効果の選べるものを決めるときに聞き、はがせないカードは選べるものに入りません: エネルギー・リムーブ・超エネルギーリムーブの
  相手の側（v0.55）、相手のエネルギーをトラッシュするワザ（`DiscardOpponentEnergy`。はかいこうせんなど）、じりょくせん（`MoveOpponentEnergyToBench`）。効果のほかの部分ははたらきます。
- 自分のワザ・トレーナー・特殊能力・スタジアムの効果、ポケモンごと場をはなれる効果（エネルギーカードがついたまま動く・きぜつ）は関係しません。
- 選べるものが保護されたカードだけになる場面は、それぞれのカードの既存の問い・処理（エネルギー・リムーブの EM1・ワザは対象がなければトラッシュしない）です。新しい問いにしていません。
