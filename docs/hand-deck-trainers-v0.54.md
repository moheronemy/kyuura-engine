## 3. 条件・順番・枚数・見せるか

### 3.1 使うための条件（手札から出す前。拒否で状態・乱数・ログは変わらない）

- にせオーキドの逆襲（「…トラッシュしなければ、このカードは使えない。」）: このカードを除く手札が 1 枚より少なければ `INSUFFICIENT_CARDS_IN_HAND`（パソコン通信・カスミのなみだと
  同じ）。条件のトラッシュは決定 `discard_from_hand`（ちょうど 1 枚）で選び、すんだトラッシュは、そのあとの処理で取り消さない（不正な答えは決定の確認が拒否し、状態は変わらない）。
- カツラの奥の手（「…「カツラの奥の手」以外のカードがある時には、使えない。」）: このカードを除く手札に、名前（手札にある間の印刷の定義の名前の完全一致）が「カツラの奥の手」で
  ないカードがあれば `OTHER_CARDS_IN_HAND`。同じ名前のカードはあってよく、手札がこのカードだけでも使える。日本語版の文面に手札を見せる指示はないので見せない（条件はエンジンが
  確かめるだけで、ログに手札を書かない。英語版の「Show your hand」を持ち込まない）。
- カツラのギャンブル: 手札がこのカードだけなら、選べるのは 0 枚だけなので、HC5（3.3）で使う前に止める（`UnsupportedError`）。
- 10 枚とも、トレーナーの使用の禁止（［アレルギーかふん］・ずつう・こうしゅうは）が先（`TRAINER_PREVENTED`）。

### 3.2 対象のプレイヤーと順番

- 相手の手札をもどさせる・相手に引かせる（にせオーキドはかせ・逆襲）は、相手の手札・山札への効果で、相手の決定はない（選ぶものがない）。相手の場のポケモンへの効果ではないので、
  「ワザをうけない」「とうめい」などは関係しない。
- 両方のプレイヤー（ナツメの眼・ミニスカート）は、見せる・もどす・切る・引くのそれぞれを、使ったプレイヤー → 相手プレイヤーの順に行う（実装上の順番。HD1。手札・山札は
  プレイヤーごとに別なので、どちらの順でも結果の分布は同じ。乱数の使い方の順番だけを決めた。v0.52 のつれさるの切る順番と同じ扱い）。
- エリカは説明のとおり、使ったプレイヤーが引き終わってから相手プレイヤーの決定を出す（相手は使ったプレイヤーの引いた枚数（公開）を知ってから決める）。相手の枚数を決めるのは
  相手自身（「…それぞれ、のぞむなら…引いてよい」の主語）。このトレーナーの `decision_problems` だけが段階 1 の決定を相手に許し、ほかのトレーナーの「決めるのは使ったプレイヤー」
  の約束は変えていない（不変条件が確かめる）。
- コインの位置: ギャンブラーは山札を切ったあと（「その後、コインを投げて」）、カツラのギャンブルはトラッシュのあと。どちらも使ったプレイヤーが 1 枚だけ投げる（投げ直さない）。

### 3.3 枚数（0 枚・山札が足りない）

- もどす枚数（ナツメの眼）はプレイヤーごとに、そのプレイヤーの手札（使っているこのカードは手札にないので数えない）の枚数。手札が 0 枚のプレイヤーは 0 枚もどして 0 枚引く。
- もどすカードが 0 枚（手札が 0 枚・ミニスカートでトレーナーカードがない）でも、そのプレイヤーの山札は切る（説明の「よくきって」の主語はもどすプレイヤー。HD2）。にせオーキドはかせ・
  逆襲は相手の手札が 0 枚でも使え、相手の山札を切って引かせる（文面に使うための条件がない）。ギャンブラーは手札がこのカードだけでも使える。
- 引く枚数は、山札が足りなければ引けるだけ（0 枚でも負けではない。負けは番の最初に引けないときだけ。p.312・v0.2b のマサキと同じ規定）。手札をもどしたあとに引く 4 枚
  （ナツメの眼は、もどした枚数はかならず引ける）。
- エリカ: 選べる枚数は 0〜min(3, 自分の山札の枚数)。0 枚は「のぞむなら」の、引かないこと（`trainer_draw_declined` の `declined`）。山札が 0 枚のプレイヤーには決定を出さない
  （`empty_deck`）。両方が引かなくてもよい。
- スパイ作戦: トラッシュするのは 0〜すべて（このカードを除く手札）。0 枚は「のぞむなら」の、トラッシュも引くこともしないこと（`trainer_discard_declined` の `declined`）。
  トラッシュと引くことは 1 つの「のぞむなら」で、トラッシュして引かない選択はない（実装上の読み方。SM1）。自分の手札がこのカードだけなら決定を出さない（`empty_hand`）。
- カツラのギャンブル: 「好きなだけカードを選んでトラッシュする」（「のぞむなら」がない）で 0 枚を選べるかは、v0.31 の HC5（「好きなだけはがしてすてる」で 0 枚を選べるか）と同じ
  言い回しの問いで、記録で決まらない。0 枚の答えは HC5 で止め（決定は待ったまま）、手札がこのカードだけなら使う前に止める。HC5 の当てはめは、同じ言い回し（「のぞむなら」のない
  「好きなだけ」）に限る（似たカードの答えを自動で当てはめない。スパイ作戦は「のぞむなら」があるので 0 枚を受け付ける）。「おもて」ならトラッシュした数 × 2 枚引き、「うら」なら
  引かない（トラッシュしたカードはもどらない）。
- ポケモン図鑑: 見る枚数は 0〜min(5, 山札の枚数)。0 枚は「ことができる」の、見ないこと（`look_at_deck_top_declined`。PD1。v0.39 の GS1（ワザの「最大N」が 0 を含むか）は別の
  言い回しなので当てはめない）。山札が 0 枚なら見るカードがない（`look_at_deck_top_none`。決定なし）。1 枚なら並べかえる決定はない。

### 3.5 ミニスカートのトレーナーカード（CardFilter の分類）

- もどすのは、手札にある間の印刷の定義の分類（`GameState.card_def`。`CardFilter("trainer")` は `category == "trainer"`）がトレーナーカードのカードです。なにかの化石・ピッピ人形
  （手札ではトレーナーカード。v0.47）も、kyuura の種類（`trainer_kinds`）のあるトレーナー（夜の廃品回収の `rockets_secret_machine` など）も含みます。ポケモン・エネルギーは
  動かしません。
- v0.53 の `TakeFromDiscardTrainer.secret_machine_ok` は、夜の廃品回収の「このカード自身の種類」を登録で受け付けるための印で、選べるカードの種類（`CardFilter`）とは別です
  （選べるカードの側では種類で除いていない）。v0.53 の文書・CLAUDE.md の「ほかの種類のトレーナーは今までどおり拒否します」は、ほかの種類のトレーナーを登録しないという意味で、
  ミニスカート・ダウジングマシーンの選べるカードから除くという意味ではありません（書き方があいまいだっただけで、実装の誤りはない。CLAUDE.md の v0.54 の節に分けて書いた）。
