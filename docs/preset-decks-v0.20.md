# 最初の対戦用デッキ（v0.20）

v0.20 で、対応済みのカードだけを組み合わせた固定のデッキを 2 つ加えました。利用者は識別子でデッキを選び、正式な対戦開始（`new_game`）に渡せます。

（v0.26 で、別の識別子の第2版 `hitmonchan-dewgong-v2`・`venusaur-parasect-v2` を加えました。この文書の第1版の識別子と中身は変えていません。第2版は [preset-decks-v0.26.md](preset-decks-v0.26.md)。）

- **最初の試作の構成です。** 実在した大会のデッキや、勝率の釣り合いを確かめた構成ではありません。下の対戦の数字は、決まった手順（対戦相手の AI ではない）どうしの結果で、デッキの強さを示すものではありません。
- 新しいカードの効果は加えていません。`engine.py`・`resolution/`・公開のログの意味・書き出しの形式・固定した参照データ・研究資料とカードの写しの参照コミットは変えていません。
- 次の作業に分けたカード: 突風・パソコン通信・エネルギー回収・ポケモン育て屋さん（6 章）。

## 1. デッキの選び方と対戦の始め方

| 識別子 | 名前 | 枚数 |
|---|---|---|
| `hitmonchan-dewgong` | エビワラー・ジュゴン（デッキ A） | 60 |
| `venusaur-parasect` | フシギバナ・パラセクト（デッキ B） | 60 |

```python
from kyuura_engine import new_game, preset_deck, preset_deck_ids, validate_deck

print(preset_deck_ids())                      # ('hitmonchan-dewgong', 'venusaur-parasect')
deck0 = preset_deck("hitmonchan-dewgong").cards()   # new_game に渡せる 60 枚のカード id（呼ぶたびに新しいリスト）
deck1 = preset_deck("venusaur-parasect").cards()
validate_deck(deck0); validate_deck(deck1)    # 60 枚・同じ名前は 4 枚まで・たねポケモン・対応済み（p.308）
state = new_game(deck0, deck1, seed=1)        # 山札を切り、7 枚配り、切り直しまで
```

- デッキの中身は `kyuura_engine/decks.py` の `PRESET_DECKS` の 1 か所だけにあります（`PresetDeck.entries` は（カード id, 枚数）の並び）。`cards()`・`counts()` は呼ぶたびに新しいリスト・辞書を返すので、読み出した側が変えても次の読み出しは変わりません。`PRESET_DECKS` と `PresetDeck` は書きかえられません。
- テストの盤面・統合テストのためのデッキ（tests/ のもの）は登録していません。

### 開始だけの例（examples/start_preset_game.py）

```bash
python3 examples/start_preset_game.py --list
python3 examples/start_preset_game.py --deck0 hitmonchan-dewgong --deck1 venusaur-parasect --seed 1 --first 0
```

対戦準備（場に出すポケモン・切り直しのあとの引く枚数・ジャンケンの結果）を決まったやり方で済ませ、先攻の最初の番（`main`）の場を表示します。

- **これは対戦の「開始」だけの例です。人間が最後まで遊べる操作画面ではありません。** GUI・Web・通信対戦・対戦相手の AI はありません。最初の番から先は、`apply_command` にコマンドを渡して進めます（README の「使い方」）。どの操作が合法かを並べる API もありません。
- 場に出すポケモンは「手札のたねポケモンの最初の 1 匹をバトル場、残りを 5 匹までベンチ」で、これは例の決め方です（ルールの決まりではない）。
- 両方のプレイヤーが同時に切り直し、そのあと片方だけがさらに切り直すと、対戦は既存の未解決の裁定（`UNRESOLVED_MULLIGAN_COMPENSATION`。p.308。v0.1 から）で止まります（`halted`）。例はその状態をそのまま返します（4 章）。

## 2. デッキ A: エビワラー・ジュゴン（`hitmonchan-dewgong`）

| 種類 | カード | 枚数 |
|---|---|---|
| ポケモン（14） | エビワラー PMCG1-058（たね。HP 70・闘・ジャブ 闘 20・スペシャルパンチ 闘闘無 40・にげる 2） | 4 |
| | パウワウ PMCG1-029（たね。HP 60・水・ずつき 水 10・にげる 1） | 4 |
| | ジュゴン PMCG1-030（パウワウから進化。HP 80・オーロラビーム 水水無 50・れいとうビーム 水水無無 30＋コインが「おもて」なら相手をマヒ・にげる 3） | 3 |
| | コラッタ PMCG1-060（たね。HP 30・無色・かみつく 無 20・にげる 0） | 3 |
| トレーナー（24） | オーキドはかせ PMCG1-077 / マサキ PMCG1-074 / きずぐすり PMCG1-071 / ポケモンいれかえ PMCG1-073 / プラスパワー PMCG1-081 / ディフェンダー PMCG1-079 | 各 4 |
| エネルギー（22） | 闘エネルギー PMCG1-102 / 水エネルギー PMCG1-099 | 12 / 10 |

- **序盤の進め方**: エビワラーをバトル場に出し、闘エネルギーをつけてジャブ（闘 1）から攻めます。ベンチにはパウワウを出し、水エネルギーをベンチのパウワウにつけて育てます。
- **育てるポケモンと攻撃役**: 序盤の攻撃役はエビワラー（スペシャルパンチは闘 2 が要る）。パウワウ → ジュゴンが中盤からの攻撃役で、オーロラビーム（50）か、マヒを狙うれいとうビーム。
- **オーキドはかせの判断**: 手札が少ないときに使います。手札にジュゴンがあり、場にパウワウがいて次の番に進化できるなら、ジュゴンを捨てないように先に進化を待つ。エネルギーを捨てることになるので、その番のエネルギーをつけてから使います。山札が少ないときは、山札切れを避けて使いません。
- **交代・回復・エネルギー**: コラッタはにげるエネルギーが 0 なので、ダメージを受けたポケモンをベンチに戻すときの交代役です（バトル場にコラッタを出して、エネルギーを払わずにげる）。ポケモンいれかえも同じ目的。ベンチに戻したポケモンにきずぐすり。闘はエビワラー、水はパウワウ・ジュゴンへ。プラスパワーはあと 10 できぜつさせられるとき、ディフェンダーは相手の大きなワザ（ソーラービーム 60 など）を受ける前に。
- **既知の制限**: たねポケモンは 11 枚で、最初の 7 枚にたねポケモンがない確率は約 22%（切り直し）。弱点はエビワラー 超・パウワウとジュゴン 雷（デッキ B には超・雷のワザはない）。

## 3. デッキ B: フシギバナ・パラセクト（`venusaur-parasect`）

| 種類 | カード | 枚数 |
|---|---|---|
| ポケモン（18） | フシギダネ PMCG1-001（たね。HP 40・やどりぎのタネ 草草 20（ダメージを与えたら自分のダメージカウンターを 1 個とりのぞく）・にげる 1） | 4 |
| | フシギソウ PMCG1-008（フシギダネから進化。HP 60・つるのムチ 草無無 30・どくのこな 草草草 20＋どく） | 4 |
| | フシギバナ PMCG1-011（フシギソウから進化（2 進化）。HP 100・ソーラービーム 草草草草 60・ポケモンパワー エナジートランス） | 3 |
| | パラス PMCG2-003（たね。HP 40・ひっかく 無無 20・キノコのほうし 草草（ねむり）） | 4 |
| | パラセクト PMCG2-010（パラスから進化。HP 60・キノコのほうし 草草・きりさく 無無無 30） | 3 |
| トレーナー（22） | オーキドはかせ PMCG1-077 3 / マサキ PMCG1-074 4 / きずぐすり PMCG1-071 4 / ポケモンいれかえ PMCG1-073 4 / プラスパワー PMCG1-081 3 / ディフェンダー PMCG1-079 4 | 22 |
| エネルギー（20） | 草エネルギー PMCG1-097 | 20 |

- **序盤の進め方**: パラス・パラセクトのキノコのほうしで相手の対戦ポケモンをねむりにして時間を稼ぎ、ベンチでフシギダネ → フシギソウ → フシギバナと進化させます。
- **育てるポケモンと攻撃役**: フシギバナ（ソーラービーム 60）が主な攻撃役。パラセクトはねむりときりさく（30）、フシギソウはどくのこな。
- **エナジートランス**: 自分の番の中で何度でも、場の「草」エネルギーをほかのポケモンにつけかえられます（フシギバナがねむり・マヒ・こんらんのときは使えない）。ベンチに草エネルギーをためておき、攻撃するポケモンに集め、きぜつしそうなポケモンからはベンチに逃がします。
- **オーキドはかせの判断**: フシギソウ・フシギバナを手札に持ち、場に進化元がいるなら、捨てずに進化を待ちます。2 進化を捨てると育て直しに時間がかかります。山札が少ないときは使いません。
- **交代・回復・エネルギー**: ねむりにした相手が起きる前に攻撃役へ交代（ポケモンいれかえ）、ダメージを受けたフシギソウ・フシギバナにきずぐすり。プラスパワーはソーラービームできぜつまであと 10 のとき。
- **既知の制限**: たねポケモンは 8 枚（フシギダネ 4・パラス 4）で、最初の 7 枚にたねポケモンがない確率は約 35%。ベンチにポケモンがいないままバトル場のポケモンがきぜつして負ける場面が多い（4 章）。2 進化のフシギバナが場に出るまで時間がかかる。

## 4. 正式な対戦開始からの対戦（2026-10-15。Python 3.13.16）

`python3 tools/preset_deck_games.py`（駆動の方法は 5 章）で、席（デッキ A がプレイヤー 0 か 1 か）を入れかえ、先攻・後攻は seed の偶奇で入れかえて対戦させました。主な結果は 40 局（席ごとに seed 0〜19）、補足に 400 局（席ごとに seed 1000〜1199）です。

### 4.1 終わり方の内訳

| 分類 | 40 局 | 400 局 |
|---|---|---|
| 通常の勝敗で終了（`game_over`） | 36 | 392 |
| サドンデス（`sudden_death`） | 0 | 0 |
| 既知の未解決の裁定による停止（`halted`） | 4（どれも `UNRESOLVED_MULLIGAN_COMPENSATION`。対戦準備の切り直し） | 8（同じ） |
| 操作が `UNRESOLVED_…` で拒否されたあと、別の操作で続けた回数 | 0 | 0 |
| 手数の上限（8,000 手） | 0 | 0 |
| 想定外の拒否（手順が想定していない拒否） | 0 | 0 |
| 内部エラー（不変条件の違反・そのほかの例外） | 0 | 0 |
| 使った時間 | 2.1 秒 | 16.4 秒 |

- 止まった局は、両方のプレイヤーが同時に切り直したあと片方だけがさらに切り直した局です（v0.1 からの未解決の裁定。p.308 の文面から相手の引く枚数が決まらない）。デッキ・ルールを変えて避けることはしていません。どちらのデッキもたねポケモンが少ない（11 枚・8 枚）ので、切り直しが起こりやすい構成です。
- ルールによる拒否（手順が試して拒否された操作）は 40 局で 263 回で、どれも `IllegalActionError` でした（ねむり・マヒでワザ・にげるを宣言した・場に出した番・最初の番の進化など）。`UNRESOLVED_…` による拒否はありません。
- 通常の勝敗の 36 局の終わり方（負けた側。1 局で 2 つの条件がそろったものは両方に数える）: デッキ B が バトル場に出すポケモンがいない 16・山札切れ 6・サイドをすべて取られた 4、デッキ A が 山札切れ 6・サイド 4・バトル場に出せない 2。400 局では、デッキ B の負け 272 のうち 204 がバトル場に出すポケモンがいないため、山札切れの負けは両方で 103 局。
- 勝敗は 40 局でデッキ A 24・デッキ B 12、400 局でデッキ A 272・デッキ B 120 でした。**決まった手順どうしの結果で、デッキの釣り合いの判断には使えません**（手順はエネルギー・オーキドはかせ以外の判断をデッキに合わせていない）。先攻・後攻での差は小さい（400 局でデッキ A の勝ち 先攻 140・後攻 132）。

### 4.3 次の調整に役立つ事実

- **デッキ B は進化カードが余る**: 終局のとき、使わなかった進化カード（手札・山札・サイド）が 36 局で合計 171 枚（1 局あたり約 4.8 枚。10 枚中）。オーキドはかせで捨てた進化カードは 29 枚（16 局）。400 局ではフシギバナまで進化したのは 214 局。
- **デッキ B はワザを使わずに番を終えることが多い**: ワザを使わずに終えた番は 36 局で 193（デッキ A は 147）。ソーラービーム（草 4）を払えるまで時間がかかる。
- **デッキ B はベンチが薄い**: ベンチに 1 匹も出さなかった局が 400 局で 93（デッキ A 36）。たねポケモン 8 枚が原因の候補。
- **エネルギーの配分**: 駆動の手順がエネルギーをつけた先は、バトル場に足りないタイプ 173・ベンチの育てる系統 241・元の手順のまま（バトル場に手札の最初のエネルギー）399（40 局）。デッキ A は闘・水の両方が入るので、どちらかが足りずにワザを払えない番がある（ワザを使わずに終えた番 147）。
- **補助カードが余る**: 終局のとき、使わなかったトレーナー（手札・山札・サイド）は 36 局でデッキ A 368 枚・デッキ B 347 枚（1 局あたり約 10 枚）。そのうち手札に残っていたのはデッキ A 55・デッキ B 34。
- **山札切れ**: 400 局で 103 局が山札切れで終わった（マサキ・オーキドはかせを手順が積極的に使うため。手順はオーキドはかせを山札 7 枚未満で使わない。使わなかった番 263（400 局））。
- **オーキドはかせ**: 進化を待つために使わなかった番は 40 局で 10、400 局で 38。捨てたエネルギーは 40 局でデッキ A 25 枚・デッキ B 21 枚。
- **コラッタ**: 手順はコラッタを交代役として使っていない（バトル場に出すのは元の手順の「ベンチの先頭」）。かみつくを使った局が 20 局あり、交代役より攻撃役として出ていた。

## 5. 駆動の方法と限界

- 対戦の手順は、既存の統合テストの決まった手順（`tests.v017_games.play_game` と `tests.test_dark_wartortle_games_v0_13.policy_command`。v0.2b〜v0.13 の手順を重ねたもの）をそのまま使います: ベンチに出す・エネルギーをつける・進化（1 進化・2 進化）・トレーナー（マサキ・きずぐすり・ポケモンいれかえ・プラスパワー・ディフェンダー）・エナジートランス（`tests.test_bulbasaur_games_v0_5.energy_trans_command`）・ワザの選び方（パラセクトはねむりにできるならキノコのほうし、ジュゴンはマヒでなければれいとうビーム、フシギソウはどくでなければどくのこな）・拒否されたときの扱い（同じ番に同じ操作を繰り返さない）。
- tools/preset_deck_games.py が加える手順は 2 つだけです: エネルギーをつける先（バトル場に足りないタイプ → ベンチの育てる系統に足りないタイプ → 元の手順）と、オーキドはかせ（その番のほかの操作が終わったときだけ、山札 7 枚以上・残りの手札 2 枚以下・次の番に進化できる進化カードを持っていないときに使う）。
- 対戦相手の AI ではなく、合法手の一覧も作っていません。手順は相手の場を読まず、コラッタを交代役に使わず、バトル場に出すポケモンは「ベンチの先頭」です。勝率・バランスの判断には使えません。
- 終わり方の分類は、通常の勝敗・サドンデス・既知の未解決の裁定による停止（コード付き）・手数の上限・想定外の拒否・内部エラーで、どの局も 1 つに入ります（集計から落とさない）。`UNRESOLVED_…` で拒否されて別の操作で続けた回数は別に数えます。
