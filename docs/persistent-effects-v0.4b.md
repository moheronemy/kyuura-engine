# ワザによる持続する効果（v0.4b）: 原典照合と実装

v0.4b で実装した「ワザによる持続する効果」（『ポケモンカードオフィシャルブック2000』の公式ルールの言葉では「特殊状態以外の「持続する効果」」）について、原典で確かめたこと・決めたこと・決められなかったことと、実装・テストを対応づけた記録です。v0.4b で扱う効果は、トランセル・コクーンの「かたまる」の効果（「次の相手の番、このカードはダメージを受けない」）だけです。カードとワザは [harden-v0.4b.md](harden-v0.4b.md)、ダメージ計算との関係は [persistent-damage-v0.4b.md](persistent-damage-v0.4b.md)、設計は [architecture-v0.4b.md](architecture-v0.4b.md) にあります。

**実装上の仮定（原典の規定ではないもの）**:

- 「次の相手の番」を、効果を与えた番の番号 + 1 で表す（番は先攻から 1 つずつ交互に進む。v0.2e のディフェンダーと同じ前提。番を飛ばす・続ける効果を加えるときに見直す）。
- 期限切れの処理は、番の終わりのうち、ついているトレーナーのトラッシュのあと・`turn_end` のログの前に行う（どちらもポケモンチェックの前。原典の「番の最後」の中の順番は書かれていないが、どちらの順でも状態は同じ）。
- 効果を受けているポケモンを `pokemon_id` で指すが、進化したら効果は消すので、「同じ番号だから同じポケモン」として効果を残すことはない（v0.4a の `pokemon_id` の仮定はそのまま）。

## 3. 3 つの区別

| | 特殊状態（v0.3a〜） | ついているトレーナー（v0.2c〜） | ワザによる持続する効果（v0.4b） |
|---|---|---|---|
| 物理的なカードか | いいえ | **はい**（トラッシュする） | いいえ |
| 持つ場所 | `PokemonInPlay.conditions` | `PokemonInPlay.trainers` | `PokemonInPlay.persistent_effects` |
| どこにある | バトル場のポケモンだけ | バトル場・ベンチ | v0.4b の効果はバトル場のポケモンだけ（ベンチに戻ったら消える） |
| 期限 | ねむりのコイン・マヒの自動回復（ポケモンチェック） | カードごとの番の終わり（`discard_at_end_of_turn`） | 効果ごとの番の終わり（`active_turn`） |
| ベンチに戻る | 消える（p.311・p.322） | いっしょに移る（p.311） | 消える（p.311・p.322） |
| 進化 | 消える（p.310・p.322） | 受け継ぐ（p.310。効果も続く。v0.4a の E8'） | 消える（p.310・p.323） |
| きぜつ | なくなる | いっしょにトラッシュ（p.323） | なくなる（トラッシュに何も置かない） |
| ダメージ計算 | 関係しない（どくはポケモンチェック） | 5 段階・7 段階（`DamageModifier`） | 段階ではない。ダメージの要素を無効にする（p.321） |
| 消す処理 | `conditions.clear_special_conditions` | `_discard_expired_attachments`・`_knock_out` | `persistent.remove_persistent_effects` |

進化・ベンチに戻るときは、特殊状態の解除・持続する効果の解除・（進化なら）にげるの失敗の記録の解除を、それぞれ別の関数で行い、別のログを残す（`special_conditions_removed`・`persistent_effect_removed`・`retreat_failure_cleared`）。ついているトレーナーは変えない。

## 4. 実装

- 値: `state.PreventDamage(source_card, source_player, created_turn, active_turn)`（frozen。`kind = "prevent_damage"`）。`state.PERSISTENT_EFFECT_TYPES` が扱える型の一覧（v0.4b は 1 つ）。
- 付ける: `persistent.add_persistent_effect`（ログ `persistent_effect_added`）。v0.4b で呼ぶのは `effects.PreventDamageOnHeads` だけ。
- 消す: `persistent.remove_persistent_effects(state, owner, pokemon, reason)`（ログ `persistent_effect_removed`。消すものがなければ何もしない）。`reason` は `expired`・`retreat`・`switch`・`evolve`・`knock_out`。
- 期限切れ: `persistent.remove_expired_persistent_effects`（`engine._end_turn` から）。
- 調べる: `persistent.damage_prevention(state, pokemon)`（今の番にはたらいている `PreventDamage`）。
- 不変条件: `engine._persistent_effect_problems`（型・発生源・番・期限・置き場所・重複・ログとの対応）。
- 書き出し: 形式 8 の `persistent_effects`（形式 1〜7 は、効果があると `ValueError`）。
- 乱数: 付ける・消す・ダメージの無効は乱数を使わない（コインは「かたまる」の説明のコインだけ）。

- 原典で確定したが未実装: 相手のポケモンに与える持続する効果（「すなかけ」「からまるいと」など）、カウンター・マーカーをのせるタイプの持続する効果、退化での解除、「効果を受けない」状態（p.321）、持続する効果を消すカードの効果。どれも対応カードにない。
- 対応カードでは起こらない: 効果を与えた番にそのポケモンがベンチに戻る・進化する・きぜつする（「かたまる」はワザなので、使った番はすぐ終わる）。同じ効果の重複。相手の番に、ワザ以外のダメージ（トレーナー・特殊能力）を受ける。
