# R団のカビゴン（わるいねぞう・たおれこむ）（v0.17b）

R団のカビゴン（PMCG6-073。ジム拡張第2弾闇からの挑戦）を、解決の基盤（KERNEL）で実装した記録です。

- ［わるいねぞう］: 既存の窓に加える、新しい自動的な効果（仮説 H2）
- たおれこむ: 自分を対象にする特殊状態

カードの選定と照合は [card-selection-v0.17a.md](card-selection-v0.17a.md) 4.3 章、照合の記録は `kyuura_engine/data/card_verification.json`（PMCG6-073）にあります。

## 1. 結論

- **H2 は成り立った。**
  - ［わるいねぞう］は、はんげき（v0.10）と同じ既存の窓（ダメージを受けるとき → ダメージの要素のあと）と、同じ汎用の処理（`kernel.power_damage_to_damage_source`。特殊能力のダメージを、ダメージを与えたポケモンに）で処理した。
  - 加えたのは次の 2 つ。
    - 効果の定義 `catalog.RESTLESS_SLEEP`
    - 効果の定義の特殊状態の条件の一般化（`EffectDefinition.requires`。「この特殊状態のときだけはたらく」）
  - 通常の特殊状態による抑止（ねむり・マヒ・こんらんで消える）は、そのまま当てはめていない。
- **たおれこむ**:
  - 既存の要素 `Status` に、対象（自分）と「ダメージを与えた後」を加えた。どちらもカードごとの要素ではない。
  - 「ダメージを与えた後」の効果を、ダメージを与えなかったときに与えるかは原典で決まらない（Z23）。
    - 新しい止める理由 `UNRESOLVED_EFFECT_AFTER_NO_DAMAGE` を加え、宣言の前に止める。
- **ダメージの分類**: ［わるいねぞう］の 20 は特殊能力によるダメージ（CONFIRMED。p.245 の解説）。
  - 弱点・抵抗力を計算するかは、説明に書かれていない（Z9。UNRESOLVED）。
  - R団のカビゴンは無色で、無色の弱点・抵抗力を持つカードは kyuura の記録の 780 枚にないので、結果は変わらない。
  - 結果が変わる場合（今は起こらない）は止める。
- 既存の未解決の裁定は変えていない。
  - そろってのきぜつ（C18）は同じ問いとして同じコード `UNRESOLVED_COUNTERATTACK_DOUBLE_KNOCKOUT` で止める。新しいコードにしていない。
  - W24・S37・C34/C35 は、既存のまま。
- `engine.py` は変えていない。書き出しの形式 9・状態の型・ログのイベントの種類も変えていない。

## 4. ダメージの分類（ワザによるダメージか、特殊能力によるダメージか）

［わるいねぞう］の 20 は**特殊能力によるダメージ**です（CONFIRMED）。根拠:

1. p.245 の解説が、このダメージそのものについて「このダメージは特殊能力によるダメージなので「ディフェンダー」ではふせげません」と書いている。
   - ディフェンダーの最新の説明は「ワザによるダメージを受ける時、そのダメージは「-20」される」（p.321）。
   - 「特殊能力によるダメージ」だから「ワザによるダメージ」の効果を受けない、という理由づけになっている。
2. p.321「8」の「ワザによるダメージ」は、ワザがもたらしたダメージと、ワザがもたらした効果のダメージ（こうらがえしの例）。
   - ［わるいねぞう］はワザでもワザの効果でもない（特殊能力）。
3. 同じ形の特殊能力の解説:
   - p.138［ショックボム］「特殊能力のダメージ」
   - p.192［はんげき］（v0.10 の C13。SUPPORTED）

そのため、はんげきと同じ特殊能力の枠で与えます。

- p.321 の計算はしない。プラスパワー（ワザを使うポケモン側。そもそもその番にはついていない）・ディフェンダー・「ダメージを受けない」状態・「とうめい」は計算・評価しない（Z7・Z8）。
- 受けたポケモンの「受けたとき」の効果ははたらかない（Z10）。

弱点・抵抗力だけは、はんげきと事情が違います（Z9）。

- はんげきの最新の説明は「「弱点・抵抗力」に関係なく」と明記している。
- ［わるいねぞう］の最新の説明・解説には、弱点・抵抗力の記述がない。
- 公式ルールは、弱点・抵抗力を「9 ワザによるダメージ計算の順番」の中でだけ定め、どくのダメージ（「弱点・抵抗力に関係なく」）・こんらんの 20（「弱点・抵抗力の影響を受けます」）は個別に書いている。

したがって原典からは決められない（UNRESOLVED）。ただし、結果は変わりません。

- R団のカビゴンは無色で、kyuura の記録（PMCG1〜neo4 の 780 枚）に、無色の弱点・抵抗力を持つカードはない。
- そのため、計算してもしなくても 20。

実装は計算しない処理（はんげきと同じ）にし、結果が変わる場合だけ止めます。

- 受けるポケモンの弱点・抵抗力が与えるポケモンのタイプのときは、コードのない問い（エンジンの不具合として `RuntimeError`）で止める。
- 写しに無色の弱点・抵抗力がないことも、テストで確かめる。
- これは推測による解決ではなく、「結果が変わらない範囲だけを扱う」という扱いです。

## 5. 新しい未解決の裁定（Z23）とその扱い

**問い**: たおれこむ「ダメージを与えた後、自分を「ねむり」状態にする。」で、相手へのダメージの要素がダメージを与えなかったとき、自分をねむりにするか。

ダメージを与えなかったときとは、次の 3 つ。

- ディフェンダーで 20 − 20 = 0（p.321「ダメージを与えなかった」）
- 「ダメージを受けない」状態で要素が無効（かたまる・からにこもる）
- 「とうめい」で受けない

**読み方の比較**:

| 読み方 | 支える記述 | 反する記述 |
|---|---|---|
| 順番の記述（ダメージの要素のあとに、自分への効果の要素を処理する。ダメージを与えなかったときも、ねむりにする） | p.320（要素は書かれた順に処理する）・p.321（ダメージ以外の効果の要素は有効）・v0.9 の T18（ワザを使う側への要素は処理する） | — |
| 条件（ダメージを与えたときだけ、ねむりにする） | p.155 の同じ文面の解説「相手にダメージを与えたら、自分がねむり状態になってしまいます」・p.321「ダメージを与えなかった」ことになる | p.321 は「無効」になるのはダメージの要素だけと書く |

- どちらの読み方にも誌面の支えがあり、ほかの資料（公式会報・トレーナーズ）は見つからなかった。
- 自分がねむりになるかで、次の番のワザ・にげる・ポケモンチェックのコイン（乱数）が変わる。
- したがって推測で決めない（UNRESOLVED）。

**宣言の前に止めるか**:

- 止める。ダメージを与えないかは、コイン（「とうめい」）と盤面（ディフェンダー・「ダメージを受けない」状態）で決まる。
- 解決の基盤の先読み（`derived`）は、コインのすべての結果を試すので、どれかの結果で当たれば、宣言の前（こんらんのコインの前）に止まる。
- コインの結果で受け付けるかが変わらない（`CoinIndependenceTest`）。

**止める条件**:

- 要素 `Status` の `after_damage` に、そのダメージの要素の名前を書いたとき、その結果の `dealt` が 0 なら、問い `effect_after_no_damage`（`UNRESOLVED_EFFECT_AFTER_NO_DAMAGE`。優先度はワザの実装の `problem` と同じ 10）。
- カードごとの分岐ではない。今は「たおれこむ」だけが使う。
- 同じ文面のワザ（ナツメのヤドンの「ぐうたらこうげき」・p.38 のクサイハナの「ゆめみのまい」など）を加えるときも同じ要素で止まる。

**隣の止まらない場合**: プラスパワーで 30 − 20 = 10（ダメージを与えた）・相手をきぜつさせた（`EffectAfterNoDamageBoundaryTest`）。

**原典で決まったら**: 止める処理を決まった処理に置きかえ、分類を変える根拠をこの章に書く。
