# ケーシィ・ユンゲラー・フーディンの原典の照合と裁定（v0.7）

v0.7 でフーディン（PMCG1-049）を対戦で使えるようにするために、進化元のケーシィ（PMCG1-043）・ユンゲラー（PMCG1-046）と、3 枚のワザを『ポケモンカードオフィシャルブック2000』[P43] で確かめた記録です。フーディンのポケモンパワー「ダメージスワップ」は [damage-swap-v0.7.md](damage-swap-v0.7.md)、設計は [architecture-v0.7.md](architecture-v0.7.md)。照合の記録は kyuura_engine/data/card_verification.json の PMCG1-043・PMCG1-046・PMCG1-049。

## 1. 確かめ方

- 300dpi の画像を目で読み、カードの図版の説明文は 600dpi で拡大した（OCR はページの位置を探すのに使っただけ）。
- 照合したのは「ポケモンカード第1弾」のカードだけ。同じページのほかのケーシィ（LV.8 拡張シート第1弾青版・LV.14 ロケット団）、ユンゲラー（LV.39 拡張シート第3弾緑版）、フーディン（LV.45 プロモーション・わるいフーディン）、p.150 のナツメのケーシィは別のカードで、代わりにしていない。
- 使わなかった資料: 英語版の文面（kyuura の `text.en`）、後年の英語版の規定、現代のルール。

図版の説明文（印刷の文面）: ケーシィ「コインを投げて「おもて」なら、相手を「マヒ」状態にする」（「投げて」のあとに読点がない）、ユンゲラー「自分の「超」エネルギーカードを1枚はがしてすてることによってダメージカウンターを全てとりのぞく。」（kyuura と同じ）、フーディン「コインを投げて「おもて」なら、相手を「こんらん」状態にする。」（kyuura と同じ）。

解説（処理に関わる記述）: ケーシィ「超エネルギー1個で使え、相手をマヒ状態にできるかもしれないワザ「ねんりき」」「逃げるときにエネルギーが必要ありません」。ユンゲラー「相手の攻撃でダメージカウンターがたくさんのってきたら、「じこさいせい」でダメージをすべて回復してバトル再開」「「じこさいせい」のあとでダメージを受けてしまっては意味がありません」（どのカードをトラッシュするか、ダメージカウンターがないときの扱いは書いていない）。

kyuura の記録（段階・進化元・HP・タイプ・弱点・抵抗力・にげる・ワザの名前・エネルギー・ダメージ・LV）は、この本と同じ。エラッタの記録はない。

## 4. 印刷の文面と最新の説明の違い

- ケーシィの「ねんりき」: kyuura の写し「コインを投げて、「おもて」なら、相手を「マヒ」状態にする。」は「投げて」のあとに読点が 1 つ多い（図版・最新の説明にはない）。意味は同じ。登録の `AttackEntry.text_ja` は照合用に kyuura の写しの値、`play_text_ja` は最新の説明。
- ユンゲラーの「じこさいせい」: 印刷の文面「…1枚はがしてすてることによってダメージカウンターを全てとりのぞく。」に、最新の説明は「自分についている」「自分にのっている」「トラッシュできないとき、このワザの効果はなくなる」を書く。最新の説明にしたがう（p.6）。
- フーディンの「あやしいひかり」: 同じ。

kyuura の記録に、印刷の文面と最新の説明を区別した記録がないこと、ケーシィの文面の読点の違い、ユンゲラー・フーディンの ja_text_source の URL（nazonobasho の pmcg01-044・pmcg01-045）の番号が kyuura の id の番号（046・049）と違うことは、報告事項として [data-provenance.md](data-provenance.md) に書いた（誤りとは決めない。kyuura は変更していない）。
