## 2. 先に直したこと: エコロジムとリサイクルエネルギーの不要な TE2

v0.82 は、エコロジムの場で、相手の［へんしん］のメタモンについている「無色」の特殊エネルギーを相手の効果でトラッシュするとき、そのカードが「「無色」以外の「エネルギーカード」」に
当たるかが TE2 の答えで変わるとして、カードの種類を見ずに止めていました。リサイクルエネルギーなら、エコロジムに当たっても当たらなくても同じカードが 1 回だけ持ち主の手札に
もどるので、結果は変わりません。

- v0.83 から、`effects.energy_discard_problem(state, holder, uid, *, cause, by_player)` が、止める必要のあるカードだけを答えます（エコロジムがはたらき、原因が相手の
  ワザ・特殊能力・トレーナーで、カードがリサイクルエネルギーのような場からもどるカードでなく、色が決まらないとき）。`_not_colorless` は色が決まらないとき None を返し、
  `energy_discard_plan` は、ほかの理由でもどることが決まっていないときだけ TE2 で止めます。
- 選ばせる決定（相手のエネルギーカードをトラッシュさせるワザの `DiscardOpponentEnergy`・［だつりょくえき］の `energy_drain_discard`・トレーナーのエネルギーをトラッシュする
  決定）は、これに当たるカードを、選べるが選ぶと止めるもの（`unresolved_choices`）にします。どのカードも当たるなら決定の前に止めます。先読みは止めないカードの答えだけを試します。
- 無色2個エネルギー（リサイクルエネルギーでない「無色」の特殊エネルギー）は、今までどおり TE2 です。エコロジムのない場・自分の効果・きぜつ・にげるは変わりません。
- 確かめた経路（tests の `EcogymRecycleTe2Test`）: トレーナー（エネルギー・リムーブ）・ワザ（相手のエネルギーカードをトラッシュさせるワザ）・特殊能力（キョウのベトベトンの
  ［だつりょくえき］。［へんしん］のメタモンがひかるカブトプスの姿で、ベンチのキョウのベトベトンにダメージを与えた場面）。リサイクルエネルギーだけ・リサイクルエネルギーと
  無色2個エネルギー（無色2個エネルギーの答えだけを止める）・無色2個エネルギーだけ（TE2）・ふつうの側。

記録のない判断を加えていません（止めるのは結果が変わるときだけ）。もどったリサイクルエネルギーは、もう一度つけられます。

## 3. 「おたがいのプレイヤーは、それぞれ、…」の共通の進み方

要素の基底 `programs.EachPlayerStep` が、おたがいのプレイヤーが自分のカードについて選ぶワザの共通の進み方を持ちます（きんいろのうろこ・ふしぎなはばたき・あかりでてらす・
すくいあげる・みずかき）。

- 順番はワザを使ったプレイヤー → 相手プレイヤーです（実装上の順番。説明は順番を書かない）。v0.54 のエリカ・v0.73 のパソコン大暴走！は説明に順番があり、同じ順番にしました。
  先に選んだプレイヤーの公開したカード・引いた枚数を、あとのプレイヤーは知ってから選びます。この順番は研究の論点として記録し、止める処理にはしていません（どちらの順番でも
  ルールに反しない。結果が順番で変わる場面があることは、kyuura への報告事項）。
- 決めるのはそのプレイヤー自身です（`context` の `"stage"` が 0 ならワザを使ったプレイヤー、1 なら相手）。ワザを使ったプレイヤーが相手のぶんを答えることはありません。
  決める人が段階で変わるのを許すのは、これらのワザの決定の形（`_each_player_decision_problems`）だけです。
- 選べるものがないプレイヤーには決定を出しません。
- 相手のワザとして使う（ゆびをふるなど）ときも、実際にワザを使ったプレイヤー・カードの持ち主・決めるプレイヤーを別の値として持ちます（tests の
  `test_copied_by_metronome_keeps_players_separate`）。

### 3.1 見えない情報

- 引いたカード（ログ `draw`）・山札の上から見たカード・見た中から選ばなかったカードは、そのプレイヤーだけが見ます。手札に加えた基本エネルギーカード（みずかき）・トラッシュから
  選び出したカード（見せてから置く）は公開です。
- 山札の中身から選ぶ決定 `take_looked_cards` を `observation.HIDDEN_COUNT_KINDS` に加えました（選べるものの数が見たカードの中身を漏らすため）。v0.55 のカスミのいかりの
  決定も、v0.83 から相手に選べるものの数を見せません（意図した変更）。
- 見た中から選ばなかった理由（ログ `deck_top_take_declined` の `reason`）は、そのプレイヤーだけが見ます（`PRIVATE_FIELDS`）。

### 3.2 ポケモンタワー

ポケモンタワー（v0.74）の場では、トラッシュから手札に加える効果（ふしぎなはばたき・あかりでてらす）は、おたがいのぶんとも消えます（コインの前に確かめ、あかりでてらすのコインも
投げない。v0.75 のおにびあつめと同じ読み方）。山札にもどす効果（すくいあげる）は消えません。

## 4. ひかるポケモンのデッキの制限

## 6. リフレクトシールド

- 自分自身の持続する効果 `state.ReflectShield`（種類 `reflect_shield`。はたらく番は次の相手の番。期限・ベンチにもどる・進化・きぜつで消える。v0.4b と同じ）。形式 8 から書けます。
- 「受けるとき」は、要素を無効にする効果・「とうめい」・かげぶんしんで受けないと決まったあと、［ベンチガード］・ダメージをのせる前です（`kernel.reflect_shield_holds`）。
  最終ダメージが 0 なら「ダメージを受けなかった」のでコインを投げません。持ち主のコイン 1 枚（ログ `reflect_shield_check`）。「おもて」ならそのダメージを受けません
  （履歴の理由 `VOID_REFLECTED`。ダメージ以外の効果は受ける）。
- 相手に与える 20 は、効果を与えたワザ（リフレクトシールド）のワザによるダメージとして、そのワザのダメージの要素のあとの窓で与えます（効果の定義 `REFLECT_SHIELD_RETURN`。
  v0.12 のほのおのかべと同じ処理。弱点・抵抗力・ディフェンダーを計算する。ログ `reflect_shield_damage`）。ダメージを与えたポケモンがすでに HP 以上なら与えません
  （ログ `reflect_shield_skipped`）。
- コインの時点と、20 を与える窓のあいだに、ダメージを与えたポケモンのダメージが変われば、20 をどちらの時点で与えるかで結果が変わりうるので RS1（`UNRESOLVED_REFLECT_SHIELD_TIMING`。
  先読みが宣言の前に見つける）で止めます。変わらなければ、どちらの時点でも同じです。
- 20 でダメージを与えたポケモンがきぜつしたら、ワザのあとのきぜつの判定です（v0.12 と同じ）。
