# こんらん（v0.3c）: 原典照合と実装

こんらん状態について、原典で確かめたこと、決められなかったこと、実装、テストを対応づけた記録です。こんらん状態のポケモンのワザ（コイン・20 ダメージ・自分のきぜつ）とロコンの「あやしいひかり」は [confusion-attacks-v0.3c.md](confusion-attacks-v0.3c.md)、こんらん状態のポケモンの「にげる」（コイン・エネルギー・再宣言の制限）は [retreat-confusion-v0.3c.md](retreat-confusion-v0.3c.md)、設計は [architecture-v0.3c.md](architecture-v0.3c.md) にあります。特殊状態の共通基盤とどくは [special-conditions-v0.3a.md](special-conditions-v0.3a.md)、ねむり・マヒは [sleep-paralysis-v0.3b.md](sleep-paralysis-v0.3b.md) です。

- 基準のルール: 「ポケットモンスターカードゲーム公式ルール 2000.02.14版」（『ポケモンカードオフィシャルブック2000』pp.306〜326 [P43]、kyuura `NEO-2000-OFFICIAL-RULES`）
- 照合の方法: スキャン [J38] のページ画像を目で読んだ（2026-10-12。300dpi）。読んだページは p.309（ワザを使う手順 1〜6）、pp.310〜311（にげるの手順 1〜4・再宣言・ベンチに戻ったら消える）、p.321（8 ワザによるダメージと効果、9 ダメージ計算の順番）、p.322（4. こんらん状態・特殊状態の重複）、p.323（12 ワザの失敗、15 ポケモンチェック）、p.325（21 ポケモンの入れ替え）、p.257（プラスパワー・ディフェンダー）と、カードのページ p.67（ロコン）。OCR の文字はページの位置を探すのに使っただけ
- 現代のルールのこんらん（ダメージカウンター 3 個、にげるにコインがない）、第4版の冊子の「こんらんしたワザ」（相手へのダメージ・効果を自分に）、第5版の告知・二次資料（失敗したワザのコストを払わない、など）では補っていない。kyuura の研究記録（`confusion_attack`・`confusion_retreat`。参照コミット `ecb2d69`）は照合の手がかりにだけ使い、2000.02.14版の行が原典と同じであることを確かめた（6 章）

## 2. 裁定の分類（こんらん状態そのもの）

分類: CONFIRMED（原典に直接ある）・SUPPORTED（確定した規定から導ける）・UNRESOLVED（原典から決められない）・CONFLICT（資料のあいだで食い違う）。ワザのときの規定（A1〜）は [confusion-attacks-v0.3c.md](confusion-attacks-v0.3c.md) 3 章、にげるときの規定（R1〜）は [retreat-confusion-v0.3c.md](retreat-confusion-v0.3c.md) 3 章です。

|---|---|---|---|---|

## 3. 原典で決められない事項（UNRESOLVED）

| 事項 | 内容 | 扱い |
|---|---|---|
| こんらんの 20 ダメージにプラスパワー・ディフェンダーを計算するか | こんらんのダメージが「ワザによるダメージ」（p.321「8」）かが書かれていない。プラスパワーは「ワザが…ダメージを与えるとき」、ディフェンダーは「ワザによるダメージを受けるとき」（p.257） | ワザを使うこんらん状態のポケモンにダメージを変えるカードがついていれば、コインを投げる前に `UnsupportedError`（`UNRESOLVED_CONFUSION_DAMAGE_MODIFIERS`）。[confusion-attacks-v0.3c.md](confusion-attacks-v0.3c.md) 3 章 A11 |
| 「にげる」に失敗したあと、ベンチに戻ってこんらんが消え、同じ番にバトル場に戻ったポケモンが「にげる」を宣言できるか | p.311 の主語は「一度「にげる」に失敗したこんらん状態のポケモン」。こんらんでなくなったポケモンが含まれるかは書かれていない | 宣言を `UnsupportedError`（`UNRESOLVED_RETREAT_AFTER_CONFUSION_CLEARED`）で止める（エネルギーもコインも使わない）。次の番には記録が消えるので宣言できる。[retreat-confusion-v0.3c.md](retreat-confusion-v0.3c.md) 3 章 R14 |
| ワザの説明にエネルギーをトラッシュするなどのコストがあるワザで、こんらんの「うら」のときにコストを払うか | 2000.02.14版に書かれていない（kyuura の第5版の行の二次資料は「払わない」とするが、基準にしない） | 対応カードにない（v0.3c の対応カードのワザに、説明によるコストはない）。そのワザを加えるときに照合する |

v0.2f の未解決（ワザの説明による自分へのダメージに弱点・抵抗力を計算するか。`UNRESOLVED_SELF_DAMAGE_WEAKNESS_RESISTANCE`）は、こんらんの規定（p.322「このダメージは」はこんらんのダメージを指す）では決まらないので、変えていません。v0.2b のベンチがないときのポケモンいれかえ（`UNRESOLVED_SWITCH_WITHOUT_BENCH`）、v0.3a・v0.3b の止める 3 つ（`UNRESOLVED_POKEMON_CHECK_DOUBLE_KNOCKOUT`・`UNRESOLVED_POKEMON_CHECK_SLEEP_COIN_ORDER`・`UNRESOLVED_REPARALYSIS_RECOVERY_TURN`）も変えていません（こんらんがあっても同じ条件で止まることをテストで確かめた）。

## 4. 状態の持ち方

| 情報 | 持つ場所 | 理由 |
|---|---|---|
| こんらん状態 | 場のポケモンの `PokemonInPlay.conditions.exclusive = Confused()`（frozen。共有してよい値 `CONFUSED`） | ねむり・マヒと重複しない（C8）。カードの uid・プレイヤー単位では持たない |
| 「にげる」に失敗した番 | 場のポケモンの `PokemonInPlay.retreat_failed_turn`（なければ None） | 制限はポケモンごと（p.311 の主語）。プレイヤー単位の「この番はもうにげられない」にしない。番の終わりに消す |

詳しくは [architecture-v0.3c.md](architecture-v0.3c.md) 3 章・6 章。
