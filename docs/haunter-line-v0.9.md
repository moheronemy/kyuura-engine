# ゴース・ゴーストのワザの原典の照合と裁定（v0.9）

v0.9 でゴースト（PMCG3-030。ポケモンカード第3弾化石の秘密）を対戦で使えるようにするために、進化元のゴース（PMCG3-029。化石の秘密）と、2 枚のワザを『ポケモンカードオフィシャルブック2000』[P43] で確かめた記録です。ゴーストのポケモンパワー「とうめい」は [transparency-v0.9.md](transparency-v0.9.md)、自動的にはたらく特殊能力の扱いは [automatic-powers-v0.9.md](automatic-powers-v0.9.md)、設計は [architecture-v0.9.md](architecture-v0.9.md)。照合の記録は kyuura_engine/data/card_verification.json の PMCG3-029・PMCG3-030・PMCG1-047。テストは tests/test_haunter_line_v0_9.py。

## 1. 確かめ方

- 300dpi の画像を目で読み、カードの図版の説明文は 600dpi で拡大した（OCR はページの位置を探すのに使っただけ）。
- 同じ名前の別のカードを混同しないように、見出しの収録商品と LV・HP で照合した。p.158 のナツメのゴース 2 枚（ポケモンジム第3弾・ジム拡張第2弾。名前が違う）、p.157 の第1弾のゴース（PMCG1-044。LV.8／HP30。さいみんガス・みちづれ）、p.160 の第1弾のゴースト（PMCG1-047。LV.22／HP60。さいみんじゅつ・ゆめくい。特殊能力なし）は別のカードで、代わりにしていない。
- 進化は名前で決まる（p.310「○○から進化」）ので、化石の秘密のゴーストは、名前が「ゴース」のどのカードからでも進化できる。kyuura の写しの対戦で使えるゴースは化石の秘密のゴースだけ（第1弾のゴースは写しにない）。
- 使わなかった資料: 英語版の文面（kyuura の `text.en`）、後年の英語版の規定、現代のルール。

図版の説明文（印刷の文面）: ゴースの「したでなめる」は「ワザ」欄と同じ。「エナジーへんかん」は「自分のトラッシュから最大2枚のエネルギーカードを選び、手札に加える。その後、自分に10ダメージ。」と読め（小さくかすれている。kyuura と同じと読める範囲だけ読んだ）、最新の説明と言い回しが違う（意味は同じ。4 章）。ゴーストの「あくむ」は「ワザ」欄と同じ。

解説（処理に関わる記述）: ゴース「まずは超エネルギーを1個つけて「したでなめる」を使いましょう。…ダメージは10だけですが、超ポケモンを弱点とする闘ポケモンに対しては抵抗力もあり…」「「エナジーへんかん」は、エネルギーカードの種類を問わず、2枚を選んでトラッシュから手札に持ってこられるめずらしいワザです。」。ゴースト「ワザ「あくむ」は、ダメージは10と少なめですが、必ず相手をねむり状態にすることができます。」。

kyuura の記録（段階・進化元・HP・タイプ・弱点・抵抗力・にげる・ワザの名前・エネルギー・ダメージ・LV）は、3 枚とも、この本の見出し・図版と同じ。エラッタの記録はない。

第1弾のゴーストを対応にしなかった理由: 「ゆめくい」の「このワザは失敗する」（p.323「12 ワザの失敗」）を処理する仕組みが未実装。カードの分類（cards.py）が「ゆめくい」の実装がないことでデッキに入れない（tests/test_transparency_v0_9.py の `test_registration`・tests/test_haunter_line_v0_9.py の `test_values`）。

## 4. 印刷の文面と最新の説明の違い

- ゴースの「エナジーへんかん」: 印刷の文面「自分のトラッシュから最大2枚のエネルギーカードを選び、手札に加える。」に対し、最新の説明は「自分のトラッシュから、「エネルギーカード」を最大2枚選び出し、手札に加える。」（意味は同じ。実装は最新の説明 `play_text_ja` にしたがう。どちらも 0 枚を含むかを書いていない（H4））。
- ゴースの「したでなめる」・ゴーストの「あくむ」: 印刷の文面と最新の説明は同じ。
- 第1弾のゴーストの「ゆめくい」: kyuura の写し「相手が「ねむり」状態のときだけ、ダメージをあたえる。」に対し、最新の説明は「相手が「ねむり」状態でないとき、このワザは失敗する。」（実装していない）。

kyuura の記録に、印刷の文面と最新の説明を区別した記録がないことは、報告事項として [data-provenance.md](data-provenance.md) に書いた（誤りとは決めない。kyuura は変更していない）。
