# 既存の効果の型で加えたポケモン 10 枚（v0.28）

v0.28 は、既存の効果の型の登録だけで対応できるポケモン 10 枚を、まとめて加えた版です（版 0.28.0）。

- 開始点: `claude/v0.27-scyther` の `e730ce2`。作業のブランチは `claude/v0.28-existing-effect-pokemon`。
- 基準のルール: 2000.02.14 版（『ポケモンカードオフィシャルブック2000』[P43] pp.306〜326）。
- 研究の基準 `3f34908`・カードの写しの元 `ecb2d69` は変えていない。kyuura の還元のコミット `0a82aed`（ブランチ `codex/engine-findings-through-v0.25`）は、
  既存の記録を探すのにだけ使った（研究の対応表・参照の基準は上げていない）。

## 3. カードごとの根拠

最新の説明は p.6 によって処理の根拠にし、印刷の文面（kyuura の写し）は登録の照合（`AttackEntry.text_ja`）にだけ使います。英語版の文面は使っていません。

- **ラプラス**（p.116。LV.31／HP80・水・弱点 雷・にげる 2）: みずでっぽうの最新の説明は、p.90 のカメックスのハイドロポンプと一字一句同じ
  （「ワザに必要なエネルギーよりも多く「水」エネルギーがついているとき、多い「水」エネルギー1個につき、10ダメージを追加する。ダメージ追加は2個ぶんまで。」）。
  必要なエネルギーは「水」1 個だけなので、多いエネルギーの数え方が決まる（v0.6 の `ExtraEnergyDamage.check`。無色が混ざるワザではない）。解説「3個めの水エネルギーを
  つけて「みずでっぽう」の攻撃力を増していく」と合う。あやしいひかりは p.67 と同じ。
- **スターミー**（p.112。ヒトデマンから進化・LV.28／HP60・水・弱点 雷・にげる 1）: じこさいせいの最新の説明は p.151 のユンゲラーとエネルギーの種類だけが違う
  （「自分についている「水」エネルギーカードを1枚トラッシュして、自分にのっているダメージカウンターを、すべてとりのぞく。トラッシュできないとき、このワザの効果は
  なくなる。」）。解説「たった1枚の水エネルギーカードをトラッシュするだけで…全部回復できる」。トラッシュするのは「水」の基本エネルギーカードから選ぶ 1 枚（決定
  `DISCARD_ENERGY`。v0.7 の K2）。「トラッシュできないとき」は、必要なエネルギー（水水）を基本エネルギーでしか払えない今の対応カードでは起こらない（v0.7 と同じ）。
  スターフリーズは p.17 と同じ。
- **トサキント**（p.108。LV.12／HP40・水・弱点 雷・にげる 0）・**アズマオウ**（p.109。トサキントから進化・LV.28／HP70・にげる 1）: どのワザも「ワザ」欄に説明文が
  ない（説明文が空なことは、ワザ欄の名前だけの表示と図版で確かめた。データの空欄だけを根拠にしていない）。アズマオウの解説「「つのでつく」は、「トサキント
  （ジャングル）」が使っているワザとまったく同じです」。
- **カイロス**（p.58。LV.24／HP60・草・弱点 炎・にげる 1）: まんりきばさみは p.17 と同じ。ハサミギロチンは説明文なし。解説「ダメージ20に加え、コイントスで表が
  出れば相手の対戦ポケモンをマヒ状態にします」（ダメージ → コイン → マヒ）。
- **タマタマ**（p.49。LV.14／HP50・草・弱点 炎・にげる 1）: さいみんじゅつは p.38 と同じ（コインなし）。やどりぎのたねは p.13 のフシギダネと一字一句同じ
  （「相手にダメージを与えたら、自分にのっているダメージカウンターを1個とりのぞく。」）。解説「相手にダメージを与えることができれば、ダメージカウンターを1個取り
  のぞくことができます」（与えなかったらとりのぞかない。p.13 の解説と同じ扱い）。ワザ名は図版・「ワザ」欄・解説ともひらがなの「やどりぎのたね」で、kyuura の写しは
  「やどりぎのタネ」（表記の違い。登録の照合は写しの名前で行う。PMCG1-008「つるのムチ」と同じ扱い）。
- **プリン**（p.225。LV.14／HP60・無色・弱点 闘・抵抗力 超 −30・にげる 1）: こもりうたは p.38 と同じ。はたくは説明文なし（kyuura の notes のとおり、2 つめは
  「はたく」）。解説「「こもりうた」で相手をねむり状態にする」。
- **ラッキー**（p.235。LV.55／HP120・無色・弱点 闘・抵抗力 超 −30・にげる 1）: まるまるの最新の説明は「かたまる」と一字一句同じ（印刷の文面「…うけるダメージが
  0になる。」にはしたがわない）。すてみタックルは「自分にも80ダメージ。」。解説「この「ラッキー」自身も80ダメージ受けてしまいます」「「ディフェンダー」と
  「きずぐすり」などを組み合わせて使うとよいでしょう」（自分へのダメージはワザによるダメージで、ディフェンダーで減る。v0.2f・v0.3d・v0.10 の規定と同じ）。
- **スリープ**（p.164。LV.12／HP50・超・弱点 超・にげる 1）: あやしいひかりは p.67 と同じ。はたくは説明文なし。自分の弱点が超なので、こんらんで自分に与える 20 は
  40（p.322。ケーシィの系統の K10 と同じ）。
- **シェルダー**（p.103。LV.8／HP30・水・弱点 雷・にげる 1）: ちょうおんぱは p.229 のねこノミと同じ（ダメージの目安なし・コインでこんらん）。からをとじるは
  「かたまる」と同じ（印刷の文面「…受けるダメージは0になる。（ダメージ以外の効果はそのまま）」）。解説「どく状態やマヒ状態などの効果は受けてしまう」。

- p.235 のラッキーの解説「ワザにかぎらず、トレーナーカードによるダメージも受けません」: 今の対応カードに、ダメージを与えるトレーナーはありません。

## 5. 検証

### 5.1 単体テスト（tests/test_existing_effect_pokemon_v0_28.py）

登録の誤りとパラメーターの差を見つけるものに絞りました（型そのものの境界は、型を加えた版のテストが確かめている）。

- 19 のワザの位置・名前・型・パラメーター・出典・照合の文面と、10 枚にほかの位置の登録がないこと。照合の記録のページ・確認日。
- 型の検査が取りちがえを拒否すること（ダメージのある・ないこんらん・ねむり、効果のないワザ、エネルギーの種類、自分へのダメージ・「ダメージを受けない」の取りちがえ）。
- 要素の並び（ダメージのある特殊状態のワザは Damage → Status、ダメージのないワザは Status だけ）。
- ダメージ・ワザのコイン・特殊状態のログ（7 つの特殊状態のワザ）と「うら」。
- ラプラス: 「水」1〜5 個で基本となるダメージ 10・20・30・30・30、ほかのエネルギーは数えない、プラスパワーは追加のあと。
- スターミー: 選べるのは「水」の基本エネルギーカードだけ・ほかのエネルギーを答えると拒否・すべてとりのぞく。
- ラッキー: 自分に 80。C18 で、自分への 80 を数えて宣言の前に止まる（ダメージ 30）・止まらない（ダメージ 20）が、先読みの方法 `derived`・`derived_full`・`legacy` で同じ。
