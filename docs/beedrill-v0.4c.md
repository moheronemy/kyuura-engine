# スピアー（v0.4c）: 原典照合と実装

v0.4c で対応した 2 進化ポケモンのスピアー（PMCG1-012）と、そのワザ「ダブルニードル」「どくばり」を、『ポケモンカードオフィシャルブック2000』のカードのページと照合した記録です。2 進化の規定は [stage2-evolution-v0.4c.md](stage2-evolution-v0.4c.md)、3 枚の重なりの状態は [stage2-state-v0.4c.md](stage2-state-v0.4c.md)、設計は [architecture-v0.4c.md](architecture-v0.4c.md) にあります。照合の記録は `kyuura_engine/data/card_verification.json`。

- 照合の方法: Internet Archive のスキャン [J38] の PDF の p.21（PDF の 23 ページ）をページ画像（300dpi）にし、見出し・図版（左上の進化の印・「○○から進化」・タイプ・ワザ・にげる・弱点・抵抗力）・ワザの部分の拡大・左の「ワザ」欄の「最新の説明」・右の解説を目で読んだ（2026-10-12）。OCR の文字はページを探すのに使っただけ。
- kyuura の参照コミット: `ecb2d694e6280ec5dc9ddd2a8f709cea16a6b691`（data/cards.json）。写しは `python3 scripts/extract_kyuura_cards.py --kyuura ../kyuura` で作り直し、`pool_v0_4c`（スピアーだけ）を加えた（`--check` で一致）。
- バタフリー（PMCG2-007）は写しに加えていない（ワザ「ふきとばし」「メガドレイン」が未実装。[architecture-v0.4c.md](architecture-v0.4c.md) 14 章）。

| ワザ（位置） | 必要なエネルギー | ダメージの目安 | 印刷の文面（図版・kyuura） | 最新の説明（実装がしたがう） | 登録（`effects.DEFAULT_EFFECTS`） |
|---|---|---|---|---|---|
| ダブルニードル（0） | 無色 3 | 30× | 「コインを2枚投げて「おもて」の出た数×30のダメージ。」 | 「コインを2枚投げ、「おもて」の数×30のダメージ。」 | `AttackKey("PMCG1-012", 0)`: `CoinFlipDamage(coins=2, damage_per_heads=30)`、`text_ja`（kyuura の写し）・`play_text_ja`（最新の説明）・`source="P43 p.21"` |
| どくばり（1） | 草 3 | 40 | 「コインを投げて「おもて」なら、相手を「どく」状態にする。」（図版は読点のかわりに空き） | 「コインを投げて「おもて」なら、相手を「どく」状態にする。」 | `AttackKey("PMCG1-012", 1)`: `PoisonOnHeads()`、同じ文面・`source="P43 p.21"` |

- 新しいワザの実装（`AttackEffect`）は加えていない。ダブルニードルはドードーの「みだれづき」（v0.2d）、どくばりはビードルの「どくばり」（v0.3a）・コクーンの「どくのこな」（v0.4b）と同じ実装を、スピアーのカード id とワザの位置で登録した。
- ビードルの「どくばり」（p.19。草 1・ダメージ 10）と同じ名前・同じ最新の説明でも、同じワザとして共有しない。登録のキーはカード id とワザの位置（`AttackKey`）で、必要なエネルギー・ダメージの数字はそれぞれのカードの定義から読む（tests/test_stage2_v0_4c.py `test_poison_sting_is_registered_for_beedrill_not_shared_with_weedle`）。
- `CoinFlipDamage.check` は、ダメージの目安に「×」があり、数字が「おもて」1 枚あたりのダメージ（30）と同じことを確かめる。`PoisonOnHeads.check` は、「×」「+」「−」がなく、ダメージが 10 の倍数の正の数（40）であることを確かめる。登録した説明文（`text_ja`）とデータの説明文が違えば、そのワザは使えない（v0.2d からの約束）。
- 2 つのワザをどちらも処理できるので、スピアーはカード全体で対応（`supported=True`）。ダブルニードルを「ダメージを受けない」相手に使う場合だけ原典で決められず止める（5 章）のは盤面ごとの拒否で、カード全体が未対応という意味ではない（v0.2d からの方針のまま）。

## 4. 処理

### ダブルニードル（`CoinFlipDamage(coins=2, damage_per_heads=30)`）

- ワザの説明にしたがう処理（p.309 の手順 6）の中で、`flip_coins` でコインを 2 枚（1 枚 1 回 `GameState.rng.getrandbits(1)`。ログ `coin_flip` が 2 つ、`source` は `attack`、`effect` は `PMCG1-012#0`）。
- 「おもて」の数 × 30 が p.321 の 1 段階（基本となるダメージ）。0・30・60。ダメージを受けるのは、説明で特に指定されていないので相手の対戦ポケモン（p.320）。
- 「おもて」が 0 枚なら 0 で、2 段階までで 0 以下なので計算を終える（ログ `damage` の `amount` 0、`stopped_after_step_2`。弱点・抵抗力・プラスパワー・ディフェンダーは計算しない。v0.2d と同じ）。これはワザの「失敗」ではない（説明に「失敗」とは書かれていない）。ワザは使ったことになり、番は終わる。
- 弱点 ×2（ディグダ: 30 → 60、60 → 120）、抵抗力 −30（対応カードに草の抵抗力を持つものはないので、テスト専用のカードで確かめた）、プラスパワー +10（5 段階）、ディフェンダー −20（7 段階）は、v0.2c〜v0.2e の計算のまま。
- こんらん状態のスピアー: こんらんのコイン（p.309 の手順 5。`source` は `confusion`）が先。「おもて」ならダブルニードルのコイン 2 枚。「うら」ならワザの処理をしないので、ダブルニードルのコインは投げず、自分に 20（弱点・抵抗力だけ。v0.3c）。
- 計算の例（相手はガーディ。弱点・抵抗力が草に関わらない）: うら・うら → 0、おもて・うら → 30、おもて・おもて → 60（HP 60 のガーディはきぜつ）。プラスパワー: おもて 1 枚で 40、0 枚で 0。

### どくばり（`PoisonOnHeads`）

- ダメージの目安に「×」「+」「−」がないので、説明の最初の「相手の対戦ポケモンに 40 ダメージ。」が省略されている（p.320）。ワザの要素は書いてある順番に処理する（p.309・p.320）: 相手への 40 → コイン 1 枚 → 「おもて」なら相手の対戦ポケモンをどく状態に（v0.3a）。
- 相手がこのワザのダメージできぜつしたら、どくにする内容は対象がいないので、コインを投げない（p.309・p.323。v0.3a と同じ）。
- もうどく状態の相手は、二重のどくにならない（p.322。ログ `special_condition` の `already`）。
- どくのダメージは番の終わりのポケモンチェックで 10（p.323。v0.3a）。それできぜつすれば、ポケモンチェックの中で処理する（`timing` は `pokemon_check`）。
