# フシギダネ・フシギソウ（v0.5。B3）

フシギバナの進化元として、フシギダネ（PMCG1-001）とフシギソウ（PMCG1-008）を対戦で使えるようにした記録です。『ポケモンカードオフィシャルブック2000』[P43] のカードのページと照合し（300dpi の画像。OCR はページの位置を探すのに使っただけ）、照合の記録は kyuura_engine/data/card_verification.json にあります。ワザが未対応のまま、フシギバナ全体を対応にはしていません（3 枚とも、すべてのワザ・パワーを登録した）。

## 1. フシギダネ（p.13）

- 見出し「たねポケモン フシギダネ LV.13／HP40」、収録「ポケモンカード第1弾」。図版: 草、やどりぎのタネ（草草）20、にげる（無）1、弱点 炎、抵抗力の欄は空。ポケモンパワーの欄はない。
- やどりぎのタネの印刷の文面（図版・kyuura の写し）: 「相手にダメージをあたえることができたら、その時点で自分のダメージカウンターを1つとりのぞくことができる。」
- 最新の説明（「ワザ」欄）: 「相手にダメージを与えたら、自分にのっているダメージカウンターを1個とりのぞく。」
- 解説: 「攻撃と回復が組み合わされた、ちょっと不思議なワザです。」「このワザはダメージを与えないと、自分のダメージカウンターを取れないので、相手のポケモンが「ディフェンダー」などを使ってダメージを与えられなかった場合は、ダメージカウンターを取りのぞくことができません。覚えておいてください。」

|---|---|---|---|---|
| L1 | 相手の対戦ポケモンに 20（説明に「×」「+」がないので目安の数字ぶん） | p.320 | CONFIRMED | `DamageAndRemoveCounters(counters=1)` |
| L2 | 「相手にダメージを与えたら」は、最終ダメージ（`DamageResult.dealt`）が正のとき。最終ダメージ 0（ディフェンダー）・「ダメージを受けない」状態（かたまる）なら、とりのぞかない | p.13 の解説、p.319（0 以下なら与えなかった）、p.321 | CONFIRMED（解説） | `test_no_damage_dealt_no_removal`・変異 17 |

## 2. フシギソウ（p.14）

- 見出し「フシギダネから進化 フシギソウ LV.20／HP60」、収録「ポケモンカード第1弾」。図版: 左上に「1進化」の印と「フシギダネから進化」、草、つるのむち（草無無）30（説明文なし）、どくのこな（草草草）20「相手を「どく」状態にする。」、にげる（無）1、弱点 炎、抵抗力の欄は空。ポケモンパワーの欄はない。
- 「ワザ」欄: 「●つるのむち」「●どくのこな 相手を「どく」状態にする。」（印刷の文面と同じ）。
- 解説: 「「つるのむち」は草エネルギーが1個ついていれば、残りの2個はどのエネルギーでもかまわない」「草エネルギーが3個ついているなら、確実に対戦ポケモンをどく状態にする「どくのこな」を使うほうがよいでしょう。「どくのこな」の20ダメージと、どくのダメージをあわせると、次の自分の番までに、相手の対戦ポケモンは40ダメージを受けることになります。」

## 3. 進化

フシギダネ → フシギソウ（p.14「フシギダネから進化」）→ フシギバナ（p.16「フシギソウから進化」）。v0.4a〜v0.4c の進化の処理（`EvolvePokemon`）をそのまま使う（進化の条件・受け継ぐもの・きぜつで 3 枚トラッシュ・サイド 1 枚）。tests/test_bulbasaur_line_v0_5.py `EvolutionLineTest` と自然な対戦（フシギソウへ 109 回・フシギバナへ 70 回）で確かめた。
