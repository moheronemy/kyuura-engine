# 実カードによる KERNEL の拡張性の確かめ方とカードの選定（v0.17a）

v0.17 は、v0.16 で一本化した解決の基盤（KERNEL。`kyuura_engine/resolution/`）に、まだ対応していない実在のカードを加えて、拡張性を確かめる版です。
この文書は、確かめる仮説、候補のカードの比較と原典の照合、選定の結果をまとめます。

関連する文書:

- 既存の要素だけで実装したカード: [card-implementation-v0.17a.md](card-implementation-v0.17a.md)
- R団のカビゴン: [rocket-snorlax-v0.17b.md](rocket-snorlax-v0.17b.md)
- キョウのベトベトンの設計の検証: [kogas-muk-event-design-v0.17c.md](kogas-muk-event-design-v0.17c.md)
- 拡張性の測定と最終の確かめ: [card-extensibility-verification-v0.17d.md](card-extensibility-verification-v0.17d.md)

## 1. 確かめる仮説

| 仮説 | 内容 | 確かめるカード |
|---|---|---|
| H1 | 既存の要素で足りる。`engine.py`・`resolution/kernel.py` を変えず、新しい共通の関数も加えない | モンジャラ（登録だけ）・サカキのニャース（既存の要素の新しい並び） |
| H2 | 既存の窓に新しい自動的な効果を加えるとき、汎用の候補の集め方・条件・処理（効果の定義と汎用の処理の追加だけ）で扱える | R団のカビゴン（わるいねぞう・たおれこむ） |
| H3 | 新しい窓、または窓の途中の決定が要る | キョウのベトベトン（だつりょくえき。設計だけ。本番の実装は求めない） |

方針:

- 新しいカードを、むりに既存の仕組みへ押し込めない。
- 既存の仕組みで足りるカードのために、新しい抽象化を増やさない。

## 2. 確かめ方

- 資料と優先順:
  - 『ポケモンカードオフィシャルブック2000』[P43]（スキャン J38）のカードのページ。「最新の説明」と図版を使う。
  - 公式ルール 2000.02.14 版（同書 pp.306〜326）。
  - 公式会報・トレーナーズの記事は、kyuura（`ecb2d69`）の資料に、この版の候補のカードの記事が見つからなかった。
- 方法:
  - PDF のページを画像にして読んだ（110dpi で位置を確かめ、400dpi でカードの図版・最新の説明・解説を読んだ）。
  - OCR の文字は、ページを探すのに使っただけ。
  - 印刷物の実物とは照合していない。
- kyuura の写し（`ecb2d694`）との違いは、照合の記録（`kyuura_engine/data/card_verification.json`）と 7 章に書く。
  - kyuura は読み取り専用。このリポジトリの作業では変更していない。
- 次のものは、日本版の処理の根拠にしない。
  - 英語版の文面
  - 現代のルール
  - 後年（2002年）の扱い（kyuura の `docs/rules/errata-history.md` の「ポケボディーとして扱う旧裏・neo の特殊能力」。わるいねぞう・だつりょくえきを含む）
  - ポケモンWiki の転記。kyuura のカードの文面の出典で、照合の起点に使っただけ。

## 4. カードごとの記録

### 4.1 モンジャラ（PMCG1-007）

- 正式名: モンジャラ。たねポケモン、LV.8／HP50、草、弱点 炎、抵抗力なし、にげる 2。
- 収録: 「ポケモンカード第1弾」（p.55 の見出し）。kyuura の `jp_print.series` は「第1弾拡張パック、スターターパック」。
  - 書き方の違いで、エンジンは使わない項目。
- 出典: [P43] p.55（PDF 57）。
  - p.55 にはモンジャラが 3 枚ある。
  - 照合したのは上の第1弾のカード。
  - 真ん中は拡張シート第2弾赤版の LV.15、下はエリカのモンジャラ。別のカードです。
- しめつける（草無）20:
  - 図版（印刷の文面）:「コインを投げて「おもて」なら、相手を「マヒ」状態にする」
  - 最新の説明:「コインを投げて「おもて」なら、相手を「マヒ」状態にする。」
- どくのこな（草草草）20:
  - 図版:「相手を「どく」状態にする。」
  - 最新の説明: 同じ。
- 公式の補足（同じページの解説）:
  - 「コイントスがありますが、表を出せば相手をマヒ状態にして、足止めすることができます」
  - 「「どくのこな」は、20ダメージに加えて、確実に相手をどく状態にする効果があります」
  - ダメージ → 効果。どくはコインなし。
- 関係するルール:
  - p.309（ワザの手順）
  - p.320（ワザの要素の順番。ダメージと効果）
  - p.321（ダメージの計算。「ダメージを受けない」状態でも効果の要素は有効）
  - p.322（特殊状態）
- 原典で決まらない点: なし。
  - 「とうめい」のゴーストにしめつけるを使う場合は、既存の T19b（`UNRESOLVED_EVADED_EFFECT_COIN`）で止まる。
  - 「はんげき」とのそろってのきぜつは、既存の C18 で止まる。
- エンジンの処理との対応:
  - しめつける = `ParalyzeOnHeads`（要素 `Damage`→`Status(PARALYSIS, local_coin=HEADS, reparalysis_check=True)`）
  - どくのこな = `PoisonOpponent`（`Damage`→`Status(POISON)`）
  - どちらも v0.13 の 24 種類のうちの型で、登録を加えるだけ。

### 4.2 サカキのニャース（PMCG6-063）

- 正式名: サカキのニャース。たねポケモン、LV.17／HP50、無色、弱点 闘、抵抗力 超 −30、にげる 2。
- 収録: 「ジム拡張第2弾闇からの挑戦」。
- 出典: [P43] p.229（PDF 231）。
  - p.229 の上のカード。真ん中はロケット団のニャース、下はペルシアンで、別のカードです。
- ねこノミ（無。ダメージの目安なし）:
  - 図版:「コインを投げて「おもて」なら 相手を「こんらん」状態にする。」
  - 最新の説明:「コインを投げて「おもて」なら、相手を「こんらん」状態にする。」
- ねこキック（無無無）30: 説明文なし。
- 公式の補足（解説）:「「ねこノミ」は、コイントスで表を出せば相手の対戦ポケモンをこんらん状態にできます」。
- 関係するルール:
  - p.320（「ダメージの目安」がないワザには「相手に○○ダメージ」の要素がない）
  - p.321（ダメージ以外の効果の要素は「ダメージを受けない」状態の相手にも有効）
  - p.322（こんらんは、ねむり・マヒと重ならない。どくとは重なる）
  - p.159・p.160（「とうめい」は効果を受けるときにはたらく。v0.9 の T19・T22（CONFIRMED）・T33）
- 原典で決まらない点: なし。
  - ダメージの要素がないので、T19b（受けないと決まったあとのワザのコイン）は起こらない。
- エンジンの処理との対応: 既存の要素 `Status(CONFUSION, local_coin=HEADS)` だけの並び。
  - v0.3c の `ConfuseOnHeads` のこんらんの要素と同じ。
  - 実装の型 `ConfuseOnHeadsWithoutDamage` と、`programs.BUILDERS` の 1 行を加えた。
  - v0.13 の約束（`resolve`・`resume`）は持たない。

### 4.3 R団のカビゴン（PMCG6-073。必須の調査）

- 正式名: R団のカビゴン（古い設計資料の「わるいカビゴン」ではない。kyuura の記録と p.245 の見出しはどちらも「R団のカビゴン」）。
- 種類と数値: たねポケモン、LV.40／HP90、無色、弱点 闘、抵抗力 超 −30、にげる 4。
- 出典: [P43] p.245（PDF 247）。
  - p.245 の真ん中のカード。上は拡張シート第1弾青版のカビゴン（とおせんぼ・ねころぶ）、下はくいしんぼカビゴンで、別のカードです。
- わるいねぞう:
  - 図版:「このカードが「ねむり」状態で、相手のワザによるダメージを受けた時、（このカードが「きぜつ」するしないにかかわらず）ダメージを与えたポケモンに 20ダメージ。」
  - 最新の説明:「このカードが「ねむり」状態で、相手のワザによるダメージを受けたとき、（それによってこのカードが「きぜつ」しても、）ダメージを与えたポケモンに、20ダメージ。」
- たおれこむ（無無無）20:
  - 図版:「ダメージを与えたあと、自分を「ねむり」状態にする」
  - 最新の説明:「ダメージを与えた後、自分を「ねむり」状態にする。」
- 公式の補足（解説）:
  - 「特殊能力［わるいねぞう］は、ねむり状態でしかはたらかない、めずらしい特殊能力です」
  - 「ねむり状態のときにワザのダメージを受けると、そのダメージを与えたポケモンに20ダメージを与えます。このダメージは特殊能力によるダメージなので「ディフェンダー」ではふせげません」
  - 「「たおれこむ」は、ワザを使ったこの「R団のカビゴン」自身をねむり状態にしてしまいますが、［わるいねぞう］があるので気にせずに使えます」
- 関係するルール:
  - p.309・p.311・p.320〜p.325
  - p.89（「ダメージを受けたとき」の効果の時点。v0.10 の C 裁定）
  - p.138（同じ形の特殊能力のダメージ）
- 原典で決まらない点（詳しくは [rocket-snorlax-v0.17b.md](rocket-snorlax-v0.17b.md)）:
  - たおれこむのダメージが「ダメージを与えなかった」とき（ディフェンダーで 0・「ダメージを受けない」状態・「とうめい」で受けない）に、自分をねむりにするか。
    - 「ダメージを与えた後」が順番の記述か、条件か。p.155 のナツメのヤドンの解説は同じ文面を「相手にダメージを与えたら」と書く。
  - わるいねぞうの 20 に弱点・抵抗力を計算するか。
    - 最新の説明に「弱点・抵抗力」に関係なく、がない。
    - R団のカビゴンは無色で、kyuura の 780 枚に無色の弱点・抵抗力を持つカードがないので、結果は変わらない。
- エンジンの処理との対応:
  - わるいねぞうは、はんげきと同じ既存の窓（ダメージを受けるとき → ダメージの要素のあと）と既存の処理（`power_damage_to_damage_source`）を使う。
  - 特殊状態の条件が「ねむりのときだけ」なので、効果の定義の特殊状態の条件を一般化する（H2）。
  - たおれこむは、相手にしか効かない `Status` の要素を、ワザを使ったポケモン自身にも使えるようにする。

### 4.4 キョウのベトベトン（PMCG6-023。必須の調査）

- 正式名: キョウのベトベトン。キョウのベトベターから進化（1 進化）、LV.38／HP80、草、弱点 超、抵抗力なし、にげる 3。
- 出典: [P43] p.49（PDF 51）。
- だつりょくえき:
  - 図版:「このカードが相手のワザによってダメージを受ける時、（このカードが「きぜつ」するしないにかかわらず、）コインを投げて「おもて」なら、ダメージを与えたポケモンについているエネルギーカードを1枚選び、トラッシュする。ダメージを受ける時、すでにこのカードが「ねむり・マヒ・こんらん」状態だったなら、この力は使えない。」
  - 最新の説明:「このカードが相手のワザによってダメージを受けるとき、（それによってこのカードが「きぜつ」しても、）コインを投げて「おもて」なら、ダメージを与えたポケモンについている「エネルギーカード」を1枚選び、トラッシュする。ダメージを受けるとき、すでにこのカードが「ねむり・マヒ・こんらん」状態だったなら、この力は使えない。」
- ヘドロのうず（草草無）40: 説明文なし。
- 公式の補足（解説）:
  - 「自分自身がダメージを受けてはじめて効果がはたらきます」
  - 「ダメージを受けるたびにコイントスをして、表ならダメージを与えたポケモンのエネルギーカードを選んで1枚トラッシュできるのです。バトル場でもベンチでも使うことができます」
- 原典で決まらない点: [kogas-muk-event-design-v0.17c.md](kogas-muk-event-design-v0.17c.md) 2 章（DR1〜DR20）。
  - 宣言するか（「使えない」「できる」。DR1）
  - 処理する時点（コイン・選択。DR6。DR1 と結びつく）
  - ダメージを与えたポケモンがすでに HP 以上のとき・エネルギーカードがないとき（DR8・DR13）
  - ほかの「ダメージを受けたとき」の効果との順番（DR18）
  - 選ぶプレイヤーは、解説から持ち主（DR10。SUPPORTED）
- エンジンの処理との対応:
  - ダメージの要素のあとの窓の中で、相手のプレイヤーの決定（エネルギーを選ぶ）が要る。
  - 今の KERNEL は、その窓の中で決定を出して続ける形を持たない（H3）。

## 5. 選定

- **モンジャラ（PMCG1-007）**:
  - 2 つのワザがどちらも「ダメージ＋効果」の 2 要素の組み合わせ。
  - 既存の実装の型で表せるので、登録だけで加えられるかを確かめる（H1 の最小の場合）。
  - 自然な対戦で使える（たね）。
  - マヒの再付与・T19b・C18・「はんげき」の時点など、既存の裁定が新しいカードにもそのまま当てはまるかも確かめる。
- **サカキのニャース（PMCG6-063）**:
  - ねこノミは、既存の要素（`Status` のコインつき）の、今の登録表にない並び（ダメージの要素がない）。
  - 新しい組み合わせを、解決の基盤・エンジンを変えずに対応表の 1 行で加えられるかを確かめる（H1 の新しい並びの場合）。
- **R団のカビゴン** は v0.17b、**キョウのベトベトン** は v0.17c で扱う（必須の調査）。
- 選ばなかった候補:
  - スリープ・カイロス: モンジャラと同じ型の組み合わせで、追加の確かめにならない。
  - タケシのイワーク: サカキのニャースと同じ形（ダメージなし・コインで特殊状態）。
  - ナゾノクサ: 要素が 1 つずつ。
  - ベロリンガ: kyuura の記録とワザ名が違う。

## 7. kyuura の記録との違い（報告事項。kyuura 側の作業）
