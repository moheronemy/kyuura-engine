## 2. Z9: 特殊能力のダメージに弱点・抵抗力を計算するか

問い（kyuura）: 説明に「「弱点・抵抗力」に関係なく」と書かれていない特殊能力のダメージ（わるいねぞうの 20、ショックボムの 20）に、受けるポケモンの弱点・抵抗力を計算するか。

### 2.1 材料

| 誌面 | 記述 | どちらの読み方を支えるか |
|---|---|---|
| p.321「9 ワザによるダメージ計算の順番」 | 弱点（×2）・抵抗力（−30）は、ワザによるダメージの計算の段階として書かれている | 決めない（ワザ以外のダメージは個別に書く） |
| p.322「どく」「こんらん」 | どくの 10 は「弱点」「抵抗力」に関係なく。こんらんの 20 は弱点・抵抗力の影響を受ける | 決めない（ワザ以外のダメージごとに書き分けている） |
| p.192［はんげき］ | 「「弱点・抵抗力」に関係なく、10ダメージ」 | 「計算する」が既定で、はんげきはその例外と読める（ただし念のための書き方とも読める） |
| p.245［わるいねぞう］・p.138［ショックボム］ | 最新の説明・解説に弱点・抵抗力の記述がない。p.138 の解説は「［ショックボム］のダメージは特殊能力のダメージなので効果がはたらかない」「同じ理由で［ショックボム］によるダメージは、「ディフェンダー」で防ぐこともできません」 | 決めない（ディフェンダーの最新の説明は「ワザによるダメージを受けるとき」（p.257）なので、防げない理由はディフェンダーの文面で説明がつく。p.321 の計算の段階が特殊能力のダメージに当てはまらないことの根拠にはならない） |
| **p.314・p.316（新しい材料）** 「カードの見かた」の弱点 | 「このポケモンが、弱点となるタイプのポケモンからダメージを受ける場合、ダメージは2倍になります。」 | 「計算する」を支える（「ワザによる」と限っていない） |
| **p.314・p.316（新しい材料）** 「カードの見かた」の抵抗力 | 「このポケモンが、抵抗力の色（タイプ）のポケモンからダメージを受ける場合、ダメージは「抵抗力の大きさ」分、マイナスされます（たとえば、ダメージが「50」で「抵抗力の大きさ」が「30」だったら、ダメージは「20」になります）。」 | 同上 |

p.314・p.316 は公式ルール（pp.306〜326。柱は「公式ルール」）の中のページで、kyuura の論点の資料（`sources`）にはありません（kyuura への報告事項 7 章）。

### 2.2 判断

- 「計算する」の読み方: p.314・p.316 は弱点・抵抗力を「（そのタイプの）ポケモンからダメージを受ける場合」と一般に書き、ワザに限っていない。はんげきの「関係なく」は、その一般の規定の例外を書いたものと読める。
- 「計算しない」の読み方: p.314・p.316 は、カードの欄の意味を説明する図解で、計算の手順は p.321 の「ワザによるダメージ計算の順番」だけにある。ワザ以外のダメージは p.322 で 1 つずつ書き分けており（どくは計算しない、こんらんは計算する）、特殊能力のダメージには書かれていない。はんげきの「関係なく」は念のための書き方とも読める。
- p.314・p.316 は「計算する」の読み方を支える材料ですが、図解の一般的な書き方を、p.321 が段階を定めていない種類のダメージに当てはめてよいかは、誌面からは決まりません（推論が要る）。kyuura が分類する前にエンジンが SUPPORTED に変えることはしません（「SUPPORTED を根拠なく…」の規則の向きとは別に、未解決の論点を正本より先に決めない）。
- **UNRESOLVED のまま**です。エンジンの止め方（結果が変わる場合だけ止める。無色の弱点・抵抗力のカードがないので今は起こらない）は変えません。
- ［ショックボム］（雷。kyuura の `data/ja_text_pcgsearch.json` にある。docs/research-alignment-v0.18a.md 11.2）を加えると、雷の弱点・抵抗力のカードで起こります。加えるのは、kyuura がこの論点を決めるか、止める場合を確かめてからです。

## 3. Z23: 「ダメージを与えた後、…」の効果を、ダメージを与えなかったときに与えるか

問い（kyuura）: 「ダメージを与えた後、…」と書かれたワザの効果（たおれこむ・ぐうたらこうげき）は、そのダメージの要素がダメージを与えなかったときにも処理するか。

### 3.1 読み方の候補（v0.17b から変わらない）

- 順番の記述と読む: p.320 は要素を書かれた順に処理するとし、p.321 は「ダメージを受けない」状態でもダメージ以外の効果の要素は有効とする。→ ダメージを与えなくても自分をねむりにする。
- 条件の記述と読む: p.155 の同じ文面の解説は「相手にダメージを与えたら、自分がねむり状態になってしまいます」と書き、p.319 は最終的なダメージが 0 なら「ダメージを与えなかった」ことになるとする。→ ダメージを与えなかったらねむりにしない。

### 3.2 ダメージを与えなかった場合を分ける

kyuura の問いは 3 つの場合を 1 つの論点に含めていますが、それぞれの場合に当てはまる規定が違います。どれか 1 つで公式の答えが見つかっても、ほかの場合が同じ答えになるとは限らないので、エンジンでは場合を分けて記録し、テストも場合ごとに置きます（場合の id はこの文書の番号で、kyuura の id ではない）。

| 場合 | 例 | ダメージの要素の扱い | 当てはまる規定 | 「順番」の読み方 | 「条件」の読み方 | エンジン |
|---|---|---|---|---|---|---|
| Z23-a 要素が無効 | 相手が「ダメージを受けない」状態（かたまる・からにこもる） | 要素そのものが無効（計算しない。p.321） | p.321「…ダメージを与える「ワザの要素」は無効」「ダメージ以外の効果をもたらす「ワザの要素」も有効」 | ねむりにする | ねむりにしない | 止める（理由「「ダメージを受けない」状態で無効」） |
| Z23-b 計算の結果が 0 | ディフェンダーで 20 − 20 = 0、抵抗力で 30 − 30 = 0 | 要素は有効で、最終ダメージが 0 | p.319「最終的なダメージが 0」なら「ダメージを与えなかった」 | ねむりにする | ねむりにしない | 止める（理由「最終ダメージが 0」） |
| Z23-c 「とうめい」で受けない | 相手がゴースト（化石の秘密）で「とうめい」のコインが「おもて」 | 要素は処理するが、ゴーストがダメージを受けない（p.159・p.160） | ［とうめい］の最新の説明「そのワザによるダメージや効果を受けない」（受けないのはゴーストへのダメージと効果で、自分への効果は別。T8） | ねむりにする | ねむりにしない | 止める（理由「「とうめい」で受けなかった」。先読みが「おもて」の結果を試すので、コインの結果によらず宣言の前） |
| Z23-d 対象がいない | ダメージの要素の前に相手の対戦ポケモンがいなくなる | 要素の内容は無視される（p.309「処理の対象がなくなってしまっている場合、その内容は無視して、次の内容の処理を」） | p.309 | ねむりにする（次の内容を処理） | ねむりにしない | **起こらない**（たおれこむ・ぐうたらこうげきは、ダメージの要素がワザの最初の要素。相手の対戦ポケモンはワザを使う時点でいる） |

ダメージを与えなかった場合ではないもの（止めない）:

- 相手をきぜつさせた（HP 以上のダメージを与えた）。ダメージは与えているので、ねむりにする（kyuura の CR-COLLAPSE-AFTER-KO-DEFENDER。SUPPORTED）。
- プラスパワーで最終ダメージが 0 より大きい（ディフェンダーとあわせて 10 など）。
- 自分が「はんげき」・「ほのおのかべ」・「こうらがえし」のダメージで HP 以上になった。ねむりにしない（効果の対象のポケモンの処理がない。CR-COLLAPSE-SELF-KO。SUPPORTED）。これは Z23 ではなく、v0.4d からの規定（p.309・p.89）です。

### 3.3 場合が同じ裁定になるとは限らない理由

- Z23-a は、p.321 が「ダメージ以外の効果の要素も有効」と明記する場面です。ねむりにする効果を「ダメージ以外の効果の要素」と見れば「順番」の読み方に近づきますが、「ダメージを与えた後」がその効果の条件なら、要素が無効な時点で条件が成り立ちません。
- Z23-b は、要素は有効で計算も行われ、p.319 が「ダメージを与えなかった」と明記する場面です。p.319 の例（ダメージを受けたらはたらく能力がダメージ 0 ではたらかない）は「条件」の読み方に近い材料です。
- Z23-c は、ダメージを受けないのがゴースト側の特殊能力の効果です。v0.9 の T17・T18 で、「とうめい」で受けなくてもワザは失敗にならず、ワザを使う側への要素は処理すると決めています。
- Z23-d は、p.309 が「次の内容の処理をおこなってください」と書く場面で、Z23-a〜c とは別の規定です（今のカードでは起こらない）。

したがって、例えば「ディフェンダーで 0 のときはねむりにしない」という公式の答え（Z23-b）が見つかっても、Z23-a・c を同じに扱う根拠にはなりません。エンジンは、答えの見つかった場合だけを止める処理から外し、ほかの場合は止めたままにします（`effects.effect_after_no_damage_error` の理由の文が場合を区別しているので、外すときは場合ごとに条件を分ける）。

## 4. DR1: だつりょくえきは宣言する特殊能力か

最新の説明（p.49。kyuura の LD-PMCG6-023-PWR0）: 「このカードが相手のワザによってダメージを受けるとき、（それによってこのカードが「きぜつ」しても、）コインを投げて「おもて」なら、ダメージを与えたポケモンについている「エネルギーカード」を1枚選び、トラッシュする。ダメージを受けるとき、すでにこのカードが「ねむり・マヒ・こんらん」状態だったなら、この力は使えない。」

### 4.1 新しい比較の材料

v0.17c は、宣言する特殊能力（こんじょう p.193・ふしちょう p.82）は発動の文に「使える」があり、自動的にはたらく特殊能力（はんげき p.192・とうめい p.160）は「はたらかない」「消える」と書く、という書き分けを比べました。v0.18 で、同じ「ダメージを受けるとき、すでに…状態だったなら、この力は使えない」で終わる特殊能力を全ページで探し、次の 2 つを画像で読みました。

| 誌面 | 特殊能力 | 最新の説明（要点） | 解説（要点） |
|---|---|---|---|
| p.100 | カスミのドククラゲ［にげこむ］ | 「この力は、このカードがバトル場でワザによるダメージを受けたとき、使える。自分の控えポケモンから1匹を選び、このカードと入れ替える。そのとき、このカードは、そのワザによる「ダメージ以外の効果」を受けない。ダメージを受けるとき、このカードがすでに「ねむり・マヒ・こんらん」状態だったなら、この力は使えない。」 | 「この特殊能力はダメージを受けたとき、使うかどうかを相手プレイヤーに言ってから使います。ですから、ベンチにもどりたくないときはもどらなくてもOKです。」 |
| p.104 | カスミのパルシェン［シェルアーマー］ | 「この力は、このカードがワザによるダメージを受けるたびに、1回使える。このカードが受けるダメージは「-10」される。ダメージを受けるとき、すでにこのカードが「ねむり・マヒ・こんらん」状態だったなら、この力は使えない。」 | 「毎回ワザで受けるダメージをマイナス10する［シェルアーマー］は、意外に強力な特殊能力です。」 |

- ［にげこむ］は「使える」と書き、解説が「使うかどうかを…言ってから使います」と書くので、宣言する特殊能力です（v0.11 の G1 でも挙げた）。
- ［シェルアーマー］は「使える」と書く（宣言の形）一方で、効果は「受けるダメージ」を減らすもので、ダメージを受ける処理の中ではたらかないと意味がありません。解説は「毎回…マイナス10する」と、選ぶことを書いていません。
- だつりょくえきは、発動の文に「使える」がなく（自動の形）、最後の文だけが「使えない」です。p.100・p.104 のどちらとも書き方が違います。

### 4.2 判断

- 「使える」「使えない」と「宣言する」「自動的にはたらく」の対応は、誌面の中で一貫しているとは言えません（［シェルアーマー］は「使える」の形で、ダメージの処理の中ではたらく）。v0.11 の G1（こんじょうを宣言する特殊能力とした。SUPPORTED）は、こんじょう自身の「使える」と［にげこむ］の解説を根拠にしたもので、この比較で G1 の結論は変わりませんが、「書き方から決める」方法でだつりょくえきを決めることは、さらに難しくなりました。
- **UNRESOLVED のまま**です。

## 5. DR6: だつりょくえきを処理する時点

候補（v0.17c 2.4）: （a）ダメージを受けた直後、（b）そのワザのダメージの要素をすべて処理したあと・ダメージ以外の効果の前、（c）ワザの要素をすべて処理したあと・きぜつの処理の前。

### 5.1 v0.17c の導き方の見直し

v0.17c は「宣言する特殊能力なら、p.309（ワザを使っている最中に、…特殊能力の使用を宣言してはいけません）で（c）」としました。p.100・p.104 の 2 つは、この導き方に合わない例です。

- p.100 の［にげこむ］は、解説が「使うかどうかを相手プレイヤーに言ってから使います」と書く宣言する特殊能力で、しかも「そのとき、このカードは、そのワザによる「ダメージ以外の効果」を受けない」（解説「どく・ねむり・マヒ・こんらんはもちろん、「えんまく」などのそれ以外の効果も受けません」）。ワザのダメージのあと、同じワザのダメージ以外の効果より前に使うことになり、（b）の時点で使われる宣言する特殊能力の例です。
- p.104 の［シェルアーマー］は、「使える」の形で、受けるダメージそのものを減らします（（a）よりさらに前、ダメージの計算の中）。
- したがって、p.309 の禁止は「ワザを使っているプレイヤー」の宣言に向いていて、相手のプレイヤーは（決められたときに）ワザの最中でも特殊能力を使える、と読むのが誌面と合います。少なくとも「宣言するなら（c）」は誌面から一意には出ず、宣言する読み方でも（a）・（b）が候補に残ります。
- v0.17c の表（2.3 の「処理する時点（DR6）」の行・2.4 の（c）の根拠）は、この留保つきで読んでください（v0.17c の文書に注を加えた）。

### 5.2 判断

- 候補は（a）〜（c）の 3 つのまま、どれにも決まりません。DR1 が決まっても DR6 が一意に決まるとは限らない、という点が v0.17c からの変更です。
- v0.11 の G2（こんじょうを使う時点。SUPPORTED）は、p.309 だけでなく、きぜつの判定がワザのあと（p.309・p.324）であることにも基づくので、この見直しで変わりません。
- **UNRESOLVED のまま**です。
