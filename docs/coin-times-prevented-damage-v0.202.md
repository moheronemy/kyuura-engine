## 1. 採用した読み方と範囲

- **読み方:** 「コインを N 枚投げ、「おもて」の数×M のダメージ」のワザを、ダメージだけを無効にする効果（［からにこもる］［かたまる］。持続する効果 `PreventDamage`）の相手に使うとき、通常どおり N 枚のコインを投げ、その結果で決まるダメージに無効を当てます。[v0.201](quick-attack-prevented-coin-v0.201.md) の［でんこうせっか］と同じ読み方です。
  - **記録の区分:** カード文面と既存のルールに基づく実装解釈。当時の直接裁定は見つかっていません。研究の論点（kyuura の `UQ-COIN-IN-NULLIFIED-ELEMENT`）は未解決のままです。
- **変えた処理（2 か所）:**
  - 解決の基盤: ダメージの値 `HeadsTimes` に、v0.201 の `HeadsBonus` と同じ印を付けました（判定は `Damage.run` のまま。無効にする効果が効果の窓を持たないときだけ投げる）。
  - 登録の側: `CoinFlipDamage.problem` は止めません。ここで見る `PreventDamage` はどれもダメージだけを無効にする効果なので、先読みの方法 `legacy`（v0.13 の止める関数）と解決の基盤が同じ答えになります。
- **当てはまる登録:** `CoinFlipDamage` 85・`CoinFlipDamageThenSelfConfuse`（［はなびらのまい］）2。後に効果のあるワザは、ダメージの無効のあとも文面どおりに処理します（［はなびらのまい］は無効のあとに自分がこんらん）。
- **変えていないもの（止まるまま）:** ［バリアー］などワザ全体を受けない効果、［たまなげMAX］（エネルギーの数だけコイン）、［マジックダーツ］（相手の場から選ぶ別の経路）、失敗を決めるコイン（［ゴッドバード］）、同じ登録の側の関数を使う［いかりのスーパーパンチ］、T19b、［きあいのハチマキ］。
