# v0.77: neo 期の拡張パックの対象化と、既存の効果の型で表せる 52 枚

neo 期の拡張パック（neo1〜neo4）を、エンジンの実装の対象に加えました。そのうち、既存の効果の型で表せる 52 枚（ポケモン 50 枚・ワザ 77、トレーナー 2 枚）を、kyuura データの採用で
登録しました。どのワザも、どのトレーナーの効果も登録した状態で、対戦に使えます。新しい効果の型・要素・決定・状態はありません。v0.76 の文書・コメントの小さな誤りも直しました（12 章）。

- 写しの元・研究の基準: kyuura `7d3f4ca76c084774efb4ac6a1d3a943387e183c3`（変えていない。kyuura には書き込んでいない）。
- 採用したデータ: kyuura の `data/cards.json`（写しの組 `pool_v0_77`）。id は kyuura の小文字の id（`neo1-006` など）のままで、PMCG の形に変えたり番号を振り直したりしていません。
  処理に使う文面は kyuura の印刷の文面です（52 の id を指す最新の説明・照合・裁定・論点・訂正の記録は、研究の基準のコミットにない）。
- ガイドブック（『オフィシャルブック2000』）のキャプチャ・OCR・画像の読み直しは行っていません。52 枚の日本語は nazonobasho.com（28 枚）・ポケモンWiki（24 枚）の転記（kyuura の
  `ja_text_source`）で、そのページを開き直すことは独立した照合になりません。外部照合はしていません（pcg-search.com も開いていない。カードの画像も読んでいない）。
- 英語の欄で日本語を補っていません。ルールの基準は 2000.02.14 版のままです。発売日（neo1 は 2000-02-04、neo2〜neo4 は 2000.02.14 版のあと）は写しの欄のまま持ち、後年のルール・
  2002 年の特殊能力の分類・現代の裁定・ベイビィの規定は持ち込んでいません。
- 既存の登録の照合の出典（「P43 p.xx」など）は、新しいカードの照合の実績として写していません。採用の記録の出典は新しいカード自身の kyuura のデータです。

## 4. 型の選び方

同じ文面の既存の登録と、ダメージの目安の有無・コインの枚数・追加の量・効果の順番・必要なエネルギーで、既存の型とパラメーターを選びました。どの型も、登録したワザの印刷の文面と
意味を型の `check`・`card_problems` で照らします（文面の確かめを一律に緩めていない。句読点の一律の除去・あいまいな語の置きかえもしていない）。`engine.py`・`resolution/` に
カード id の分岐はありません。

### 4.1 ダメージ・コイン・特殊状態

- 説明のない 27 のワザは `DamageOnly`（ダメージ・必要なエネルギー・ワザの位置は写しの値）。
- 「おもて」の数 × のダメージは `CoinFlipDamage`。3 枚 × 10（ワニノコ neo1-024・オタチ・テッポウオ）、2 枚 × 10（トサキント）・20（ウパー・サワムラー）・30（オオタチ）を
  区別しました。
- コインで追加するダメージは `CoinBonusDamage`。ヘラクロスは + 30、オドシシ・オオタチ・ゴマゾウは + 10 です。
- サワムラーの「かかとおとし」は `FailOnTailsDamage(1)`（「うら」はワザの失敗。0 ダメージとは別）。
- 自分へのダメージは `DamageAndSelfDamage`（キャタピー・ウリムー neo3-038・パウワウ 10、ニョロボン 20）と `SelfDamageOnTails`（メリープ neo2-020。「うら」のときだけ 10）。
- どく・ねむり・マヒ・こんらんは既存の型のまま（`PoisonOpponent`・`PoisonOnHeads`・`SleepOpponent`・`PutToSleep`・`DamageThenSleepOnHeads`・`ParalyzeOnHeads`・`ConfuseOnHeads`）。
  ズバット neo3-001 の「どくをとばす」はダメージのない `PoisonWithoutDamage` で、ダメージのある型と取りちがえていません。
- マンタイン・キングドラ・キリンリキ・ストライクの防御（「ワザによるダメージや効果を受けない」）は `DamageThenSelfBarrierOnHeads`（持続する効果 `AttackBarrier`）。ダメージだけを
  受けない `PreventDamage`（「ダメージを受けない」）とは別の型で、自分への効果まで消える場合と相手へのダメージだけを無効にされる場合を混ぜていません。

### 4.2 個別に確かめた既存の処理

| カード | 流用した型と注意点 |
|---|---|
| ヒマナッツ neo1-006 | `AttachEnergyFromHandOnHeads(草, 2)`・`DamageAndDrain()`。手札からつけるのは「最大 2 枚」（通常の操作の回数に数えない）、回復は与えたダメージの半分（切り上げ）。レインボーエネルギーの境界（RB2）は既存のまま |
| ワニノコ neo1-024 | v0.76 の `AttackLockWhileSourceActiveOnHeads`。コインの「おもて」・次の相手の番・発生源がバトル場にいる間。最大HP 50 の条件はつけない |

| ヌオー neo1-031 | `DamageAndOwnBenchDamage(10, True)`。自分の控え全員に 10、「弱点・抵抗力」に関係なく（説明に書かれた型。JS1 の、書かれていない型にしない） |

していません。

### 4.3 既存の確かめの強化（`CoinFlipDamage`）

`CoinFlipDamage.check` は v0.76 まで、説明のコインの枚数と登録の `coins` を照らしていませんでした（枚数を間違えた登録を受け付けた）。v0.77 から、説明の先頭の
「コインをN枚投げ」の N と `coins` を照らします（書き方は版ごとに違う（「投げ、」「投げて」「出た数」など）ので、枚数の数字だけを比べる）。v0.76 までの 54 の登録と v0.77 の 7 の登録（合わせて 61）はどれも同じ枚数で、
処理（対戦の動き）は変わりません。

## 6. 進化の系統

進化は名前の完全一致と段階で決まり、カード id・商品で限っていません。通常の進化の制限（おたがいの最初の番・その番に場に出したたねポケモン）とポケモン育て屋さんの系統の確かめは
変えていません。

- ポポッコ neo1-012・neo3-003 ← ハネッコ PRN-047（登録済み）・neo2-004（今回）。
- ヌオー neo1-031 ← ウパー PRN-003（登録済み）・neo1-026（今回）。
- キングドラ neo1-035 ← シードラ PMCG3-020（登録済み。タッツー PMCG3-014 も登録済み）。商品をまたぐ通常の 2 進化の系統で、ポケモン育て屋さんでタッツーに直接重ねることもできる。
- オオタチ neo1-064 ← オタチ neo1-059（今回）。
- ニョロボン neo2-037 ← ニョロゾ PMCG1-028・ES1-017・QSG-015（登録済み）。
- トゲピー neo1-066 は写しの段階（たね）のまま扱い、ベイビィの共通の規定は加えていません。

## 7. 含めないもの

- ハガネール neo1-057: ワザの型は流用できますが、「テールクラッシュ」に「鋼」エネルギーが必要です。今のレインボーエネルギーの支払いの範囲は基本の 6 色なので、鋼・悪の特殊エネルギーと
  関わるカードを扱う次の作業に分け、今回は加えていません。
- ベイビィ・アンノーン固有の規定・ひかるポケモンの制限・新しい特殊エネルギー: 今回の 52 枚にありません。カードの範囲を広げたことを理由に、これらのルールの設計には広げていません。
- GD5-007・IP2-032 の「ウィンディ」の表記の保留はそのままです。
- 「とづく」（ニョロボン neo2-037 のワザ 0）は写しの名前のままで、推測で名前を直していません。
