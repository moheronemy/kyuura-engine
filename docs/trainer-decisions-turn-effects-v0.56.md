## 2. 共通の進行（この 10 枚に要るものだけ）

1. **相手プレイヤーに答えさせ、そのあとの選択に続ける**（マチスの交渉・カスミのわがまま）: 既存のトレーナーの決定（`push_trainer_decision`。再開先 `"trainer"`）で、決める
   プレイヤーを相手にした決定 `accept_request`（選べるものは 1（オーケー）。0〜1 個）。答えはログ `request_answered`（公開）。相手の決定を許すのは、そのカードの
   `decision_problems` だけです（ほかのトレーナーの「決めるのは使ったプレイヤー」の約束を緩めない）。続きの情報（決定の `context`）に、見たサイドのカードを書きません（位置だけ）。
2. **相手の場にカードを出し、場に出たときの特殊能力を確かめてからトレーナーにもどる**（エリカの香水・マチス）: 手札から場に出すのは `zones.hand_to_bench_by_effect`（カードの持ち主の
   ベンチの最後。ログ `trainer_bench_from_hand`。`chooser` は選んだプレイヤー）・`zones.hand_basic_to_active`（ログ `trainer_hand_to_active`）で、場のポケモンは手札から出すのと同じ
   `zones.enter_play` で作ります（新しい場のポケモンの番号・場に出た番は今の番。その番には進化できない）。場に出たときに使える特殊能力（v0.43 の `EntryPower`）を持つたねポケモンは
   写しにない（4 枚ともわるいゴルバット・わるいヤドラン・わるいカイリュー・サカキのペルシアンの進化カード）ので、トレーナーの途中で特殊能力の決定を出してからトレーナーにもどる
   処理は加えず、`effects.placed_entry_power_guard` が状態を変える前に `RuntimeError` で止めます（エンジンの制限。来るカードを加えるときは、相手の効果で「出させ」られたときに
   「手札から出した時」の機会があるかも決めてから置きかえる。tests が写しのたねポケモンに `EntryPower` がないことを確かめる）。
3. **使用中のカードをトラッシュしてから番を終える**（ロケット団員）: 実装の `resume`・`resolve` が `effects.END_TURN` を返したら（`TrainerEffect.may_end_turn` の実装だけ）、
   `engine._finish_trainer` がこのカードをトラッシュしてから `resolution.end_turn_after_trainer`（ログ `trainer_turn_end` → ワザのあとと同じ番の終わり → 番の終わりの期限 →
   ポケモンチェック → 次の番）を呼びます。効果の中で番を終えず、使用中のカードを残しません。
4. **きぜつによらずサイドを取り、使い終えてから勝ち負けを判定する**（マチスの交渉）: サイドを取るのは `zones.take_prize_by_trainer`（ログ `trainer_take_prize`。カードは取った
   プレイヤーだけ）で、ログ `knock_out`・`take_prize` を作りません。サイドが 0 枚になっても効果の途中では対戦を終えず、`TrainerEffect.takes_prizes` の実装を使い終えたら、
   `resolution.after_trainer`（v0.50）が、きぜつがなくてもサイドが 0 枚のプレイヤーがいれば p.311 の表で判定します（両方が同時に満たしたらサドンデス）。
5. **期限のある効果**（カスミ・キョウ・見えない壁・ロケット団の実験）: 6 章。

順番の判断（実装上の判断。資料の規定ではない）: マチスの交渉は「お互いのプレイヤーは、それぞれ」を、使ったプレイヤー → 相手の順に処理します（v0.54 の HD1・v0.55 の EK1 と同じ
読み方。どちらが先でも結果のサイドと手札は同じで、勝ち負けはそのあとに判定する）。エリカの香水で選んだカードは、答えの順ではなく手札の並びの順でベンチに出します。

## 3. カードごとの処理

- **エリカの香水**: 相手の手札を見る（`zones.look_at_hand`。v0.54。ログの `cards` は見たプレイヤーと持ち主だけ。観測の手札の見え方は変えない）→ 相手のベンチに空きがあり、
  相手の手札にたねポケモン（手札にある間の印刷の定義。なにかの化石・ピッピ人形はトレーナーカードなので入らない）があれば、使ったプレイヤーが 0〜min(空き, 数) 枚を選ぶ
  （決定 `opponent_hand_to_bench`。観測では見た手札から選ぶので、決めるプレイヤーに選べるカードが見える。`LOOKED_HAND_KINDS`）。0 枚は「てよい」の出さないこと（ログ
  `trainer_take_none`）。空きがない・たねポケモンがなければ見るだけ。
- **マチス**: 使うための条件はベンチの空き（`BENCH_FULL`。手札から出す前）。選ぶ（決定 `hand_to_active`。手札のたねポケモンから 1 枚）→ バトル場のポケモンを場のポケモンごと
  ベンチの最後へ（特殊状態・持続する効果は理由 `switch` で消す。「にげる」ではないので、にげるエネルギー・こんらんのコイン・「にげる」ことができない効果は関係しない）→ 選んだ
  たねポケモンをバトル場に出す。選んでからもどす・出すを続けて行うので、バトル場が空いた状態にならず、勝ち負けの判定にかかりません。
- **ロケット団のワナ**: コインは使ったプレイヤーが 1 枚（`source="trainer"`）。「うら」なら何もしない（山札を切らない。v0.53 の MB1 と同じ読み方）。「おもて」なら、使った
  プレイヤーが相手の手札の位置を 1〜min(3, 枚数) 個選ぶ（決定 `select_hand_positions`。選べるものは位置 0〜（枚数 − 1）で、カードの uid・中身を渡さない。観測の意味は
  `position`）→ 選んだ位置のカードを動かす前にすべて決め、持ち主の山札の一番下にもどす（`zones.hand_positions_to_deck`。ログの位置は公開・カードは持ち主だけ）→ 相手の山札を
  切る。もどしたカードを使ったプレイヤーに見せません。
- **ロケット団員**: 相手に控えがいなければ RG1（コインの前）。コイン 2 枚はいつも両方投げる。2 枚とも「おもて」なら、使ったプレイヤーが相手の控えを選び（`select_pokemon`）、その
  ポケモンと重なったカード・ついているカードを同じ uid のまま持ち主の手札にもどす（v0.42 の `zones.return_in_play_to_hand`。v0.56 から出どころ `trainer` を渡せる）。ダメージ
  カウンターと特殊状態はなくなり、持続する効果は理由 `return_in_play_to_hand` で消す。きぜつではない（サイドは取られない）。1 枚でも「うら」なら番が終わる（2 章の 3）。
- **マチスの交渉**: たずねる → オーケーなら使ったプレイヤー → 相手の順に、自分のサイドの位置を選んで（`select_prize_card`。裏のまま選ぶ）取る。オーケーでないなら使ったプレイヤーが
  1 枚引く（山札 0 枚なら引けない。p.312。負けではない）。
- **カスミのわがまま**: このカードのほかに手札がなければ MY1（手札から出す前）。使ったプレイヤーが自分のサイドの位置を選び（`select_prize_card`）、そのカードを見る（v0.47 の
  `zones.look_at_card`。カードは見たプレイヤーだけ）→ たずねる → オーケーなら手札から 1 枚を選び（`swap_with_prize`）、見たサイドと入れかえる（`zones.swap_prize_with_hand`。
  サイドの枚数は変わらない。サイドを取ることではない。ログの位置は公開・入れかえたカードは持ち主だけ）。オーケーでないなら 1 枚引く。v0.47 のわるふざけ（山札の一番上と入れかえる）
  とは別の処理です。

## 5. カスミ・キョウ・見えない壁（ダメージの時点で決める）

- **カスミ**（`ATTACK_DAMAGE_BONUS`）: 「カスミのポケモン」（ワザを使うポケモンの今の姿のいちばん上のカードの名前が「カスミの」で始まる。ダメージを計算する時点で決める。使ったときの
  場で決めない。進化・入れ替え・相手のワザとして使うワザも同じ）が使うワザの、相手の対戦ポケモンへのダメージに + 20。段階は p.321 の 6 段階（kyuura の
  GR-2000-P321-DAMAGE-ORDER の「それ以外の効果」。ワザを使うポケモン自身の効果（2 段階）・受けるポケモンの効果（8 段階）でない。弱点・抵抗力のあと）。`effects.attack_damage_modifiers`
  が加え、解決の基盤の `kernel.deal_damage` と宣言の前の `preview_attack_damage` が同じ関数を使います（ログ `damage` の `modifiers` に (6, 使ったトレーナーのカード, 20)）。控えへの
  ダメージには加えません（「(控えポケモンへのダメージは、そのまま)」）。2 枚使えば 2 つの効果（どちらも 6 段階の加算なので順番で結果は変わらない）。効果はこの番の終わりに消えます。
  自分へのダメージ（カスミのジュゴンの「とっしん」）に当てはめるかは決まらない（MS1。7 章）。
- **キョウ**（`POISON_ON_ATTACK_DAMAGE`）: 「キョウのポケモン」がワザで相手の対戦ポケモンにダメージを与えたら（最終ダメージが 0 より大きく、ダメージをのせたあと）、受けたポケモンを
  どくにします（`conditions.poison`。ログ `special_condition` の `effect` はトレーナーのカード id）。最終ダメージ 0（ディフェンダー）・「ダメージを受けない」状態・「とうめい」で受けない・
  控えへのダメージではどくにしません。すでにどくのポケモンをどくにしても、どくは 1 つです（v0.3a の 14。二重にしない）。受けたポケモンがそのダメージで HP 以上なら飛ばし、こんじょうを
  使える場合は既存の G37（`UNRESOLVED_KO_PREVENTION_ATTACK_EFFECT`）です。同じワザで受けるダメージの違う特殊などくを与える場合は順番が決まらない（KG1。7 章）。
- **見えない壁**（`BENCH_ATTACK_DAMAGE_PREVENTION`）: 使った番から次の相手の番の終わりまで、使ったプレイヤーの控えポケモン（受ける時点の控え。あとから出したポケモン・バトル場から
  ベンチにもどったポケモンも同じ）へのワザのダメージの要素を無効にします（解決の基盤の効果の定義 `catalog.INVISIBLE_WALL`。「かたまる」と同じく計算せず、ログ `damage_prevented`）。
  ダメージ以外の効果は受けます。特殊能力のダメージ・ダメージカウンターをのせる・動かす効果には当てはめません（「ワザによるダメージ」）。特殊能力ではないので、特殊状態・かがくへんか
  ガスでは消えません（`disabled_by` は空・抑止されない）。相手のワザでも自分のワザでも（ミニじしんの自分の控え）同じです。コインが決めるのが控えへのダメージだけで、その控えが
  どれも無効なら、v0.4b の `UNRESOLVED_PREVENTED_COIN_DAMAGE` でコインの前に止めます（要素 `BenchDamage` の `coin_receiver` が `"bench"`・`void_for_all`、`ChosenBenchDamage` の
  要素のコイン。新しいコードにしない）。

## 6. 期限のある効果と、トレーナーの使用の禁止の出どころ

- カスミ・キョウ・見えない壁の効果は、場のポケモンに写さず、使ったプレイヤーの記録 `GameState.trainer_effects`（`state.TrainerTurnEffect`。種類・プレイヤー・トレーナーのカード・
  カード id・与えた番・消える番）に持ち、はたらく時点の場で問い合わせます（`effects.trainer_turn_effects`・`trainer_attack_damage_bonuses`・`trainer_poison_effects`・
  `bench_damage_preventions`）。消える番は、カスミ・キョウが使った番、見えない壁が使った番 + 1（次の相手の番）。消える番の終わりに `procedures.expire_at_turn_end` が消します
  （ログ `trainer_effect_added`・`trainer_effect_removed`。公開）。場をはなれる・入れ替え・進化では消えません。トレーナーで番が終わったとき（ロケット団員）も同じ番の終わりの処理です。
- ロケット団の実験の「うら」は、v0.47 の `TrainerUseLock` を出どころ `origin="trainer"` で使います（使ったプレイヤー自身に与え、消える番は使った番 + 2（`SELF_TRAINER_LOCK_TURNS`）。
  この番の残りと次の自分の番に使えない）。ワザの禁止（ずつう・こうしゅうは。`origin="attack"`。消える番は与えた番 + 1）とは別の記録で、同じ消える番に重なってもそれぞれの記録が
  それぞれ消えます（片方がもう片方を消さない）。v0.56 の途中で見つけた不具合: ワザの禁止を与える要素（`programs.LockOpponentTrainers`）が、同じ消える番の禁止を出どころを見ずに
  「すでにある」として `RuntimeError` にしていた（実験の「うら」のあとに相手がずつうを使う場面）。出どころがワザの禁止だけを比べるよう直しました。
- 不変条件: `engine._trainer_effect_problems`（型・種類・番の範囲・持ち主の番・登録の `turn_effect_terms()`・カードの持ち主・ログとの対応）、`engine._trainer_lock_problems`（出どころ・
  期間（ワザ 1・トレーナー 2）・登録の `tails_self_lock`・ログとの対応）。
- 書き出しの形式 16 = 形式 15 + 最上位の `trainer_effects` と、トレーナーの使用の禁止の `origin`。形式 1〜15 は、期限のある効果・出どころが `trainer` の禁止があると `ValueError`
