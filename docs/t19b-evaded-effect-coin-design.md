## 2. ソースの照合（7f7712a）

### 2.1 拒否に至る道

1. ［あやしいひかり］の登録は効果の型 `ConfuseOnHeads`（`effects.py` の登録。出典 P43 p.153）で、解決の基盤の要素の並びは `Damage(OPP, Printed())` → `Status(CONFUSION, local_coin=HEADS)` です（`resolution/programs.py` の表）。
2. 宣言の確かめ（`flow.check_use_attack`）のあと、宣言の前の先読みをします。既定の方式は `derived` です（`flow.py` の `preflight: str = "derived"`。記録に方式の記載はない）。実際の処理を記録する乱数で行い、まだ試していないコインの結果を、コマンドの入口の状態の複製の上で試します（`preflight.after_real_run`）。
3. ダメージの要素で、ゴーストの「とうめい」がはたらき、ゴースト側のプレイヤーが 1 枚投げます（`kernel` の受ける判定。ログ `coin_flip` → `evade_check`。「おもて」なら `attack_evaded`。受けるかの記録はワザ 1 回の中の `reception`）。
4. 特殊状態の要素（`Status.run`）は、対象が HP 以上なら何もしません。そうでなく、ワザのコイン（`local_coin`）の前に、対象が「とうめい」で受けないと決まっていれば、問い `evaded_effect_coin` を投げます（`programs.py:2190〜2194`）。
5. 「とうめい」の「おもて」の枝でこの問いに当たるので、どちらの結果が実際に出たかによらず、宣言を拒否します（状態・乱数・ログは入口のまま）。

- 旧い v0.13 の約束の止める関数（`effects.evaded_effect_coin_problem`。`ConfuseOnHeads.problem` などが呼ぶ）も、同じ条件（相手の「とうめい」がはたらき、最終ダメージが 0 より大きい）で同じコードを返します。既定の `derived` では、ワザの型の止める関数ではなく、要素の並びの問いで止まります。
- 実際の処理の枝で「とうめい」が「おもて」だったか「うら」だったかは、記録にありません。

### 2.3 同じ停止コードを返すほかの経路

7f7712a で問い `evaded_effect_coin` を返す箇所は、解決の基盤（`resolution/programs.py`）に 15 か所、旧い止める関数（`effects.py`）に 1 か所です（`out/t19b_paths.json`）。

- **今回の経路:** `programs.Status.run` のワザのコイン（`local_coin`）の前（1 か所）。
- **同じ問いを返す別の要素（14 か所）:** 入れ替え（`ForceSwitch`）・ワザの禁止（`OpponentCannotAttack`）・相手のエネルギーのトラッシュ（`DiscardOpponentEnergy`。複数の対象・選ぶ答えを含む 2 か所）・相手のワザのコインの効果（`OpponentAttackCheck`）・にげるの禁止（`OpponentRetreatLock`・`_opponent_lock`）・選んだ特殊状態（`ChosenStatus`）・HP の残りへのダメージカウンター（`CountersToRemainingHp`）・相手のトレーナーのトラッシュ（`DiscardOpponentTrainers`）・選んだ個体へのダメージだけを決めるコイン（`TargetDamage`）・「うら」が出るまでのトラッシュ（`DiscardChosenTypedEnergyUntilTails`）・効果だけを決めるコインの共通の関数（`effect_coin_questions`）・ワザ全体のコイン（`void_coin_question`。［ゴッドバード］などの型）。
- **旧い止める関数:** `effects.evaded_effect_coin_problem`（3 つの型の `problem`）。

ほかの経路は、無効になる要素の種類（入れ替え・禁止・トラッシュ・ダメージの量）、コインの数・ワザ全体のコインか、選ぶ答えの有無、複数の対象が違います。どれも「コインが、受けないと決まったポケモンへの要素だけを決める」点は同じですが、今回の局面と同じ条件で扱える根拠は、ソースでもテストでも確かめていません。**限定の規約の対象外に残します。**

- `Status` の `local_coin` の経路にも、今回の 3 つの型のほかに、同じコインが「うら」の効果も決める型（`otherwise`。例: どくかこんらん）・ダメージのない型・自分への特殊状態の型・ほかの要素と組む型があります。これらも対象外にします（D2）。

### 3.3 何が無効になり、何が残るか（今回の局面）

- **史料で決まる部分（既存の裁定）:**

  - 「うら」: 30 ダメージを受けて HP 以上になり、こんらんの要素は対象がいないので処理しません（p.309。`ConfuseOnHeads` の説明・`Status.run` の HP 以上の確かめ）。ワザのあと、きぜつ・サイド・バトル場に出す処理です。
- **史料で決まらない部分（T19b。UNRESOLVED）:** 「おもて」の枝で、ワザを使う側がこんらんにするかのコインを投げるか。p.321 は「効果を受けない」状態のポケモンへの効果の要素を「無効」とだけ書き、無効な要素の中のコインを投げるかを書きません。p.159 は「ワザを失敗させる効果ではありません」と書きますが、受けないと決まったあとのコインには触れていません（kyuura の `UQ-COIN-IN-NULLIFIED-ELEMENT`・`official_material` `none_found`）。

- 隣の既存の読み方: コインが有効な要素も決めるなら投げます（kyuura の CR-STICKY-VS-PREVENTED・CR-GAMBLE-VS-PREVENTED。エンジンの M6・L10）。今回のコインは無効な要素だけを決めるので、この読み方の範囲の外です。
