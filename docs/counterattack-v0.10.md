# カイリキーの「はんげき」の原典の照合と裁定（v0.10）

v0.10 でカイリキー（PMCG1-057。ポケモンカード第1弾）のポケモンパワー「はんげき」を対戦で使えるようにするために、『ポケモンカードオフィシャルブック2000』[P43] で確かめた記録です。進化元のワンリキー・ゴーリキーとワザは [machamp-line-v0.10.md](machamp-line-v0.10.md)、ダメージを受けたあとに自動的にはたらく特殊能力の扱いは [post-damage-powers-v0.10.md](post-damage-powers-v0.10.md)、設計は [architecture-v0.10.md](architecture-v0.10.md)、確かめた結果は [v0.10-verification.md](v0.10-verification.md) です。照合の記録は kyuura_engine/data/card_verification.json の PMCG1-057（と PMCG1-055・PMCG6-061）。

## 1. 確かめ方と使わなかった資料

- Internet Archive のスキャンの PDF からページを画像にし（300dpi。カードの図版は 600dpi で拡大）、目で読んだ。PDF の文字（OCR）は、ページの位置を探すのに使っただけ（「はんげき」「きぜつ」しても」などの語で p.192・p.89・p.138・p.203・p.245・p.321 を見つけた）。PDF のページ = 誌面のページ + 2。
- 照合したのは p.192 の真ん中の「ゴーリキーから進化 カイリキー LV.67／HP100」「ポケモンカード第1弾」のカード。同じページの上の LV.54／HP90（プロモーションカード「通信進化キャンペーン」スペシャルカード）、下のわるいカイリキー（PMCG4-044。ロケット団）、p.193 のサカキのカイリキー（PMCG6-061。闇からの挑戦。特殊能力［こんじょう］）は別のカードで、代わりにしていない。サカキのカイリキーは照合だけして参照カード（デッキに入らない）にした。
- 「はんげき」の解説は p.192 の解説だけで、公式ルール（p.323「14 ポケモンの特殊能力」）に［はんげき］の例はない。同じ形の発動条件（「このカードが（相手の）ワザによってダメージを受けたとき、（それによってこのカードが「きぜつ」しても、）」）を持つ特殊能力・ワザの解説を探して使った: p.89（わるいカメールの「こうらがえし」。ワザ）、p.138（マチスのマルマインの［ショックボム］。特殊能力）、p.203（R団のエビワラーの「クロスカウンター」。ワザ）、p.245（R団のカビゴンの［わるいねぞう］。特殊能力）、p.20（コクーンの［どくのたいえき］。特殊能力。「ダメージを受けるとき、すでに…」の形）、p.321（「8 ワザによるダメージと効果」の「こうらがえし」の例）。
- 『ポケモンカード ファンクラブ vol.3』（1997 年。改訂文面の記録があるという二次資料の情報）の誌面は、実物・スキャンを見つけられず確かめていない。一次資料として使っていない。この本の「最新の説明」がファンクラブの改訂文面と同じかも確かめていない。
- 当時の公式の Q&A・訂正は、ウェブの検索（「ポケモンカード ファンクラブ vol.3」「カイリキー」「はんげき」「改訂」の語）では見つけられなかった（見つかったのは雑誌の巻の一覧と、現代のカードの販売ページだけ）。この本の p.192・p.89・p.138・p.245 の解説を当時の公式の説明として使った。
- 使わなかった資料: 英語版の文面（kyuura の `text.en`。「Whenever your opponent's attack damages Machamp (even if Machamp is Knocked Out), this power does 10 damage to the attacking Pokémon. …」）、後年の規定（kyuura の rule_history.json の `card_lists.poke_body` など）、現代の「特性」のルールと、後年の同じ名前の特性（ダメカンをのせる「はんげき」）。きぜつするポケモンの特殊能力がいつまで有効か（A4-1）は、現代の一般的な処理やプログラムの都合から決めず、最新の説明と 2000.02.14 版のルール・この本の解説だけで決めた。

## 3. 印刷の文面と最新の説明の違い

印刷の文面は「カイリキーがダメージをうけたときには」で、何によるダメージかを書かない。そのまま読むと、どく・ほかの特殊能力・「はんげき」自身のダメージでもはたらき、カイリキーどうしでは「はんげき」が「はんげき」をはたらかせて終わらない（A4-2）。与える相手も「相手」とだけ書き、特殊状態は「つかえない」と書く。

最新の説明（p.192）は、次のことを書いている。

1. 発生源: 「相手のワザによって」ダメージを受けたとき
2. きぜつ: 「（それによってこのカードが「きぜつ」しても、）」
3. 与える相手: 「ダメージを与えたポケモンに」
4. 特殊状態を判定する時点: 「ダメージを受けるとき、すでに」。消えるのではなく「はたらかない」

p.6 により最新の説明にしたがう（`PowerEntry.play_text_ja`）。kyuura の写しの印刷の文面は、登録の照合（`PowerEntry.text_ja`）にだけ使う。

## 4. 裁定（C1〜C43）

分類は次のとおり。

- CONFIRMED: 原文がそのまま決めている
- SUPPORTED: 原文と解説から強く支持される。ほかの読み方の余地が小さい
- UNRESOLVED: 原文で決められない

「実装上の仮定」は、規定ではなく実装の都合で決めたこと。「未到達」は、規定は確かめたが v0.10 の対応カードでは起こらないこと。テストは tests/test_counterattack_v0_10.py（盤面を直接作る）と tests/test_machamp_games_v0_10.py（自然な対戦）。

5〜8 は v0.2f からの処理で、v0.10 では変えていない。5 で、カイリキーのきぜつと「はんげき」によるワザを使ったポケモンのきぜつが同じワザのあとにそろう場合だけは、2 匹が同時のきぜつかが決められない（C18 (b)。UNRESOLVED）ので、ワザの宣言の前に止める。

**A4-2（相互反撃）**: カイリキーどうしで、カイリキー A がワザ（ちきゅうなげ）でカイリキー B にダメージを与えると、B の「はんげき」の 10 が A に与えられる。この 10 は特殊能力によるダメージ（C13）で、A の「はんげき」は「相手のワザによって」受けたダメージでだけはたらくので、はたらかない（C14）。印刷の文面（「ダメージをうけたときには」）だけなら、どのダメージでもはたらき、A と B のあいだで終わらない。最新の説明で発生源が決まり、連鎖は起こらない。エンジンは発生源の分類（ワザのダメージの要素だけが判定する）で止まり、回数の上限は使っていない。

**A4-3（ダメージ 0）**:

|---|---|---|---|

**A4-4（特殊状態の評価時点）**: 最新の説明に「ダメージを受けるとき、すでにこのカードが「ねむり・マヒ・こんらん」状態だったなら」がある（p.192。印刷の文面には「すでに」がない）。ダメージを受ける前から特殊状態ならはたらかず（C19〜C21）、同じワザの効果でダメージのあとに特殊状態になってもはたらく（C23。いとをはくの「おもて」でマヒ、あくむでねむり）。特殊状態の効果は「はんげき」のあとに処理される（C28）ので、エンジンでも判定の時点の状態は受ける前の状態と同じ。

**A4-5（反撃と通常のダメージの処理）**: 「はんげき」のダメージに、ワザのダメージの計算（`deal_attack_damage`・p.321 の 1〜8 段階）を流用していない。弱点・抵抗力を計算しない（C12）だけでなく、特殊能力によるダメージでワザによるダメージではない（C13）ので、プラスパワー・ディフェンダー（C37）・「ダメージを受けない」状態・「とうめい」（C36）・「はんげき」自身（C14）を計算・判定しない。「弱点・抵抗力に関係なく」だけでは分類は決まらない（p.159 のレアコイルの「じばく」の控えへの 20 は「弱点・抵抗力に関係なく」でもワザによるダメージ）。ダメージカウンター 1 個の移動（v0.7 の `move_damage_counter`）にもしない: 移動は「ダメージを受けた」ことにならない（p.320）が、「はんげき」は「10ダメージ」で、ワザを使ったポケモンが受けたダメージ（ログ `counterattack`。HP 以上ならきぜつ。サイドは相手側のプレイヤー）。ワザを使ったポケモンが「ダメージを受けたとき」にはたらく特殊能力を持つ場合に、特殊能力によるダメージではたらくかは、その特殊能力の説明しだい（［ショックボム］は「ワザによるダメージ」に限る）。対応カードには、ほかに「ダメージを受けたとき」にはたらく特殊能力はない。
