# v0.58: スタジアムの処理を再利用するカード 3 枚と特殊エネルギー 4 枚

基準のルールは「ポケットモンスターカードゲーム公式ルール 2000.02.14版」です。カードデータは kyuura の `data/cards.json`（写しの元のコミット `ecb2d69`）を
採用し、pcg-search.com の同じ版のページと照らしました。公式ガイドブック（『オフィシャルブック2000』）のキャプチャ・画像化・OCR・読み直しはしていません。英語版の文面・
現代のルール・後年の規定で日本語の不足を補っていません。

## 2. 共通の変更: エネルギーの枚数・個数・色

カードの枚数（場のポケモンについているカード）・エネルギーの個数（ワザ・にげるで払う数）・色の割り当て（1 個ごとに、どのタイプとして使えるか）を分けました。

- `effects.energy_units(state, pokemon, uid)`: ついているカード 1 枚が出すエネルギー（1 個ずつ、使えるタイプの集まり）。基本エネルギーカードは印刷のタイプ 1 個、特殊
  エネルギーは登録の実装の `units()`（無色2個エネルギーは無色 2 個、配合エネルギーは無色 1 個、レインボーエネルギーは「6 色のどれか」1 個。合計 1 個で、色ごとに 1 個と
  数えない）。エナジーバーンで「炎」になったカードは、出す 1 個ずつが「炎」（個数は変えない。無色2個エネルギーは「炎」2 個。TXT-CHARIZARD「すべてのエネルギー」の
  実装上の読み方）。印刷の定義（`CardDefinition`）を基本エネルギーに書きかえていません。
- `attached_units`・`energy_unit_count`: ついているエネルギーの並び・個数。
- ワザに必要なエネルギー: `effects.attack_cost_payable`（`cards.can_pay_with_units`。2 部グラフのマッチングで、色の指定のある記号から割り当てる）。［へんしん］の
  メタモンは 2 つの読み方（`special_energy_payment_readings`）のどちらでも払えるときだけ払える。読み方で払えるかが変わるワザは TE2（5 章）。
- にげる: トラッシュするカードの出すエネルギーの個数で数える（無色2個エネルギーは 1 枚で 2 個で、分けてトラッシュできない）。余計なカードを除いても足りる選び方は
  `WRONG_RETREAT_COST`（基本エネルギーだけの理由の文は v0.57 と同じ）。どのカードを除いても足りなくなる選び方（無色2個エネルギーでにげる 1 を払う）は RT1。v0.46 の
  CP2（下限の当てはめ方）は個数で判定する。
- 手札からつける通常の操作（`engine._attach_energy`）: 登録された特殊エネルギーもつけられる（1 番に 1 枚の数え方は同じ）。エネルギーカードでないカードの拒否のコード・
  理由の文は v0.57 と同じ（`NOT_BASIC_ENERGY`）。つける前に `attach_from_hand_problem`（RB1・RB4）、つけたあとに `energy_attached_from_hand`（特殊エネルギーの効果）→
  `after_energy_attached`（ほのおでかいふく）→ きぜつしうるなら `resolution.after_energy`（ログ `knock_out` の `timing` は `energy`。サイド → 勝ち負け → バトル場に出す →
  同じ番の `MAIN`。v0.42 の `after_power` と同じ形）。
- つけたときの効果は手札から出してつけたときだけ（GR-2000-P310-ATTACH-ENERGY）。場のカードの移動（エナジートランス・ナツメ・エネルギーサーキュレート・じりょくせん）・
  山札やトラッシュからつける効果では起こさない（CR-ENERGY-TRANS-NOT-ATTACHMENT と同じ読み方）。
- 場の外（手札・山札・トラッシュ）の特殊エネルギーは「基本エネルギーカード」ではない（ERR-ENERGY-RETRIEVAL。エネルギー回収・`CardFilter("basic_energy")` の
  トレーナー・「「X」エネルギーカード」を選ぶ効果の選べるものに入らない。レインボーエネルギーを「X」エネルギーカードとして選ぶかもしれない効果は RB2）。「エネルギーカード」（エネルギー・リムーブ・超エネルギーリムーブ・
  じりょくせんなど）には入る。

既存のカードへの影響（どれも、特殊エネルギーがなければ v0.57 と同じ。6 章の比較で確かめた）:

| 処理 | 変えたこと |
| --- | --- |
| ワザに必要なエネルギー（すべてのワザ。`checks.attack_request`） | 個数と色で払う（`attack_cost_payable`）。TE2 は `usage_problem` のあと |
| にげる（`engine._retreat`） | 個数で数える。RT1 |
| エナジートランス | レインボーエネルギーを「草」として移せる（CR-ENERGY-TRANS-RAINBOW。CONFIRMED）。移動で 10 ダメージは受けない |
| あまごい・せいちょう・ひなたぼっこ・プラズマ・たいでん（手札・山札・トラッシュの「X」エネルギーカードをつける） | 選べるかもしれないレインボーエネルギーがあれば RB2 |

| エネルギーサーキュレート・ヤマブキシティジム・じりょくせん（場の「基本エネルギーカード」を選ぶ） | レインボーエネルギーがあれば RB3 |
| デッキの検査 | 特殊エネルギーは同じ名前 4 枚まで（GR-2000-P308-SAME-NAME） |

## 4. ナツメのサイキックコントロール

- コインは使ったプレイヤーが 1 枚。「うら」なら何もしない。「おもて」なら、使えるカード（`effects.discard_trainer_use_choices`）から 0〜1 枚を選ぶ（決定
  `use_discard_trainer`。決めるのは使ったプレイヤー。0 枚は「使ってよい」の使わないこと。ログ `discard_trainer_use_declined`）。使えるカードがなければ決定を出さない
  （ログ `discard_trainer_use_none`）。
- 使えるカード: 相手のトラッシュのトレーナーカード（トラッシュにある間の印刷の分類）で、登録があり、ポケモンにつけて使う（`stays_in_play`）・場に出して使う
  （`enters_play`。なにかの化石・ピッピ人形）・スタジアム（`is_stadium`）でないもの。使うための条件（`check_playable`）を使ったプレイヤーの手札・場で満たせないカードは
  除く。場のリムーブ禁止ジムの追加の 2 枚も使ったプレイヤーの手札で数える。条件の確認が決められない（`UnsupportedError`）カードは、選べるが選ぶと止める。
- 選んだら、外側の使用を `GameState.trainer_stack` に積み、カードを相手のトラッシュから使用中の場所（`trainer_in_use`）に移す（同じ uid・持ち主のまま。複製しない・
  使ったプレイヤーの手札に移さない）。`TrainerInUse.via` は外側のカード、`user` は使うプレイヤー（持ち主と違うとき）。ログ `play_trainer` の `player` は使うプレイヤー、
  `owner` は持ち主、`source_zone` は `discard`、`via` は外側のカード。英語版の「The card stays in your opponent's discard pile」は根拠にしない（日本語の「手札にあるものと
  みなして、使ってよい」を、カードを使う手順で処理した。実装上の読み方）。
- 内側の使用は、手札から使うときと同じ手順（錯乱ジムのコイン → リムーブ禁止ジムの追加の条件 → 使うための条件と効果）。費用・選ぶもの・「あなた」は使ったプレイヤー。
  内側のカードは使い終わったら持ち主（相手）のトラッシュに、外側のカードはそのあと使ったプレイヤーのトラッシュに（ログ `discard_trainer` の順。`_finish_outer_trainers`）。
  内側の効果のあとのきぜつ・勝ち負け・番の終わりは、外側のカードもトラッシュしてから（使用中のカードを残さない）。
- 錯乱ジム: コインは使用ごと（外側・内側で 1 回ずつ。外側のコインの結果を内側に持ち越さない）。内側で「うら」なら、相手（= カードの持ち主）が借りて使うかを聞く。
  借りても持ち主・`via` は変えず、使うプレイヤーだけを変える。
- CH1（v0.57）: 内側のカードが使ったプレイヤーの番を書くカード（`refers_to_user_turn`）で、使うプレイヤーが番のプレイヤーでない（錯乱ジムで相手がサイキック
  コントロールを借りて使った）ときだけ、選ぶと止める。自分の番に使うなら、相手のカードを使うことだけで CH1 にしない。
- トレーナーの使用の禁止（［アレルギーかふん］・ずつう・ロケット団の実験）がはたらいていれば、サイキックコントロール自体を使えない（`TRAINER_PREVENTED`）。内側の
  使用でも同じ確かめをする。
- 決定の不変条件: 使わない（0 個）がいつも答えになる（`ENTRY_POWER`・`EVOLUTION_HEAL` と同じ例外。CH1 で選ぶと止めるカードしかないときも答えられる）。
  `_trainer_stack_problems` が外側の使用と内側のカードの整合（外側のカードが `via`、持ち主のゾーン・トラッシュとの保存則）を確かめる。

## 5. 未解決（停止コード）と実装上の制限

新しい停止コード 6 件（どれも kyuura の未解決の一覧にない `not_in_kyuura`）。エンジンが止める `UNRESOLVED_…` は 115 件、未解決の裁定は 116 件です。どれも状態を変える前
（コイン・エネルギーのトラッシュ・カードを動かす前）に止めます。

| 番号 | 停止コード | 場面 |
| --- | --- | --- |
| RB1 | `UNRESOLVED_RAINBOW_ENERGY_TYPE` | 場のレインボーエネルギーを、説明の「「X」エネルギー(カード)」として数える・選ぶ・当てはめるかで結果が変わる（ハイドロポンプ・ほのおでかいふく・［ガスのからだ］・タイプのエネルギーカードのトラッシュなど） |
| RB2 | `UNRESOLVED_RAINBOW_ATTACH_AS_TYPE` | 手札・山札・トラッシュのレインボーエネルギーを、「「X」エネルギーカード」をつける効果で選べるか（あまごい・せいちょう・ひなたぼっこ・プラズマ・たいでん） |
| RB3 | `UNRESOLVED_RAINBOW_AS_BASIC_ENERGY_CARD` | 場のレインボーエネルギーを、説明の「基本エネルギーカード」として選べるか（エネルギーサーキュレート・ヤマブキシティジム・じりょくせん） |
| RB4 | `UNRESOLVED_RAINBOW_DAMAGE_RECEIVED_POWER` | レインボーエネルギーの 10 ダメージに、受けるダメージ全体を書く常にはたらく特殊能力（［カブトアーマー］）を当てはめると量が変わる |
| TE2 | `UNRESOLVED_TRANSFORM_SPECIAL_ENERGY` | ［へんしん］のメタモンの「どの色としても使える」が無色の特殊エネルギーにも当てはまるかで、ワザを払えるかが変わる |
| RT1 | `UNRESOLVED_RETREAT_OVERPAY` | 「にげる」で、どのカードを除いても足りなくなる選び方の個数が、にげるエネルギーの数より多い（無色2個エネルギーでにげる 1） |

- レインボーエネルギーの支払い（ワザ・にげる）とエナジートランスの「草」は決まっているので止めません。あまごいには CR-ENERGY-TRANS-RAINBOW を使わず、決まらない組
  （レインボーエネルギーを選んだとき）だけを止めます。
- なんでもなおし配合エネルギーの対象はつけたポケモン（説明に書かれている）なので、トレーナーのなんでもなおしの FH1 は当てはまりません。
- 実装上の制限（停止コードではなく、今の写しでは起こらないので `RuntimeError`）: 特殊エネルギーのつけたときの効果と、つけたときにはたらく特殊能力が同じタイミングに起こる組
  （SE2。順番の決定は未実装）。
- 実装上の読み方: エナジーバーンで無色2個エネルギーは「炎」2 個。サイキックコントロールのカードは使用中の場所に移る。外側・内側の錯乱ジムのコインは別々。
