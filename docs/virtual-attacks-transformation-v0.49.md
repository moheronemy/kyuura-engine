## 2. 共通の処理: 実際のカード・今の姿・ワザと特殊能力の出どころ

### 2.1 区別するもの

| 区別するもの | どこに持つか・どう求めるか |
| --- | --- |
| 実際のカード（uid・持ち主） | カードの表（`GameState.cards`）と場のポケモン（`PokemonInPlay.card`・`evolution_stack`、v0.49 の `disguise`）。どの効果も、印刷の定義・共有する `CardDefinition`・カードの id を書きかえない |
| 場のポケモンの番号 | `PokemonInPlay.pokemon_id`（v0.2a から。今の姿が変わっても変えない） |
| 今の姿 | `effects.current_form(state, pokemon)` → `Form(card, kind, defender)`。`kind` は `printed`（いちばん上のカード）・`transform`（［へんしん］。相手の対戦ポケモンのいちばん上のカード）・`disguise`（「ばける」でのせたカード）。状態に持たず、問い合わせのたびに今の場から求める。`form_def` がその定義 |
| 今使えるワザ | `effects.available_attacks(state, pokemon)` → `AttackOption(card, card_id, attack_index, route, provider, problem)` の並び（今の姿のワザ → 「思い出させる」の進化前のワザ → ［サイコリンク］のワザ） |
| ワザの元のカードと位置・登録された効果 | `AttackOption.card`（ワザを印刷したカードの uid）と `AttackOption.key`（= `AttackKey(card_id, attack_index)`。登録の効果はこのキーで引く） |
| ワザを実行するポケモン | いつもバトル場の、ワザを使ったプレイヤーのポケモン（`UseAttack.player` の対戦ポケモン）。供給するポケモン・重なっている進化前のカードは処理しない |
| 今持つ特殊能力 | `effects.powers_of(state, pokemon)` → `PowerSlot(card, key, power, effect)`（印刷したカードの uid と `PowerKey`） |

v0.47 の印刷の定義と場での役割の分離（`printed_def`・`card_def`）と、v0.48 の今有効な最大HP・タイプ・弱点・抵抗力の問い合わせ（`max_hp`・`type_readings`・
`weakness_of`・`resistance_of`・`definition_views`）はそのまま使い、もとにする定義を今の姿の定義（`form_def`）にしました（今の姿が `printed` なら v0.48 と同じ値）。

### 2.2 コマンド

- `UseAttack(player, attack_index, card=None)`: `card` はワザを印刷したカードの uid。None（v0.48 までの形）なら今の姿のカードのワザ。［サイコリンク］・「思い出させる」の
  ワザは `card` で指す（`available_attacks` の `card`）。ワザの名前・一覧の位置では指さない（同じ名前のワザ・一覧の変化で取りちがえない）。
- `UsePokemonPower(..., card=None)`: `card` は特殊能力を印刷したカードの uid。None なら今の姿のカード（「ばける」ならのせたカード、［へんしん］なら相手のカード（TF1））。
  のせたカードの下のタケシのキュウコンの「ばける」は、そのカードの uid で指す。
- `RemoveDisguise(player, pokemon)`（新しい操作）: 「ばける」でのせたカードをトラッシュして元にもどす。自分の番の `Phase.MAIN` だけ。特殊能力の使用の宣言ではない。
  拒否は `NOT_DISGUISED`（のっていない）・`NOT_YOUR_TURN`・`WRONG_PHASE`・`POKEMON_NOT_IN_PLAY`・MH1。
- `command_to_dict` は `card` が None なら書かない（v0.48 までの辞書と同じ形）。

### 2.3 同じワザ・同じ特殊能力の識別

| 場面 | 識別のしかた |
| --- | --- |
| 宣言・使用条件 | `checks.attack_request` が `find_attack_option`（印刷したカード・位置）でワザを探し、必要なエネルギー・説明の条件・止める理由（`AttackOption.problem`）を確かめる |
| 使用禁止（あわあわ・メガバーン・きあいずつき・ドわすれ） | `persistent.attack_locked(state, pokemon, key)` が `AttackKey` で探す。効果は使えなくなるワザを (カードの id, 位置) で持つ（`CannotUseOwnAttack.attack_card`・`CannotUseAttack.target_attack_card`。None ならいちばん上のカード（v0.48 と同じ））。出どころ（どのポケモンが供給したか）は問わない |
| 使用回数（場に出てから 1 回） | ワザを使ったポケモンのいちばん上のカードのワザだけ v0.44 の記録で数える。ほかのカードのワザとして使うときは VA1 |
| 決定の再開・先読み | 決定の続きの情報 `use` = (プレイヤー, 場のポケモンの番号, ワザを印刷したカードの id, 位置)。不変条件はワザのログの `card_id` と照らす（「こんじょう」の決定・でんれいのあとの決定も） |
| 特殊能力の決定 | 印刷したカードがいちばん上のカードでないとき、決定の `context` に `power_card`（uid）。「自分の番に 1 回」の記録は (場のポケモンの番号, 位置) か、のせたカードなら (…, カードの uid) |
| ログ | ワザのログ `attack` に、出どころがいちばん上のカードでないときだけ `card`・`card_id`・`route`（`form`・`recall`・`psylink`）・`provider`。特殊能力の宣言 `pokemon_power` に、のせたカードの特殊能力なら `card`・`card_id` |
| 観測 | 場のポケモンごとに `form`・`disguise`・`attacks`（出どころ・持ち方・止める理由のコード）・`powers` を書く（9 章） |

### 2.4 必要なエネルギー

どの出どころのワザも、ワザを使うポケモンについているエネルギーで、そのワザの必要なエネルギーを払う（`effects.attack_cost_payable`）。ピッピの「ゆびをふる」の
「（必要なエネルギーがついていなくても、かまわない）」は、その説明だけの免除で、今回のワザの追加・姿の変更には使っていません。［へんしん］がはたらいているメタモンだけ、
ついているエネルギーカードをどの色のエネルギーとしても払えます（1 枚が出すエネルギーは 1 つのまま。同じ 1 枚を 2 つの記号に数えない: 炎 1 枚では「水水」を払えない）。

## 3. ナツメのフーディン（［サイコリンク］・メガバーン）

- ［サイコリンク］は常にはたらく特殊能力（宣言しない）。ねむり・マヒ・こんらん・かがくへんかガスで消える（どくは関係しない）。場所はどこでもよい（ワザを使えるのは
  バトル場のときだけ）。
- ワザを持つポケモン（供給するポケモン）は、自分の場のこのカード以外のポケモンで、今有効なタイプ（v0.48 の `type_readings`）が「超」のもの。持つワザは、その
  ポケモンの今の姿のカードのワザ（ほかの［サイコリンク］・「思い出させる」で持つワザは数えない）。どのフーディンも同じ自分の場を見るので、2 匹以上の［サイコリンク］が
  重なっても再帰・ワザの増え続けは起こらない（`test_two_psylinks_do_not_recurse_or_grow`）。
- 供給するポケモンの進化・移動・きぜつ・特殊状態に応じて、問い合わせのたびに一覧が変わる（状態に持たない）。同じワザ（同じカードの同じ位置）を 2 匹が持つときは、
  出どころ（カードの uid）ごとに選べる。
- ［へんしょく］で変えた色が今有効か決まらない（v0.48 の VS1）ポケモンは、読み方でワザを持つかが変わるので、そのワザを選ぶと VS1（`AttackOption.problem`）。
- 持ったワザは、フーディンのワザとして使う。必要なエネルギー・説明の条件・エネルギーのトラッシュ・自分へのダメージ・「このカード」はフーディンについて処理し、弱点・
  抵抗力はフーディンのタイプで計算する（ユンゲラーの「じこさいせい」はフーディンの超のエネルギーをトラッシュし、フーディンのダメージカウンターをとりのぞく）。
- メガバーン（次の自分の番、このカードは「メガバーン」を使えない）は、既存の `DamageThenLockSelf` の登録だけ。効果は `AttackKey` で探すので、自分のメガバーンを使うと、
  次の自分の番は［サイコリンク］で持つほかのフーディンのメガバーンも使えない。ほかのフーディンのメガバーンを［サイコリンク］で使っても、効果を受けるのはワザを使った
  フーディン。ナツメのヤドランの「きあいずつき」を［サイコリンク］で使うと、効果は `attack_card`（ナツメのヤドランのカードの id）を持つ（書き出しの形式 14）。

## 4. タケシのキュウコン（「ばける」）と 2000年2月の基準

**適用する時代**: kyuura の ERR-BROCK-NINETALES（`official_errata`。『トレーナーズ』Vol.6 pp.58〜59、2000-05-01 発行）は、「ばける」でのせた進化カードの特殊能力を
「はたらかず、使うこともできない」と変えました。この基準（『ポケモンカードオフィシャルブック2000』2000-02-29 発行の 2000.02.14 版）より後の変更なので、持ち込んでいません。
同じ記録と card_differences の PMCG5-019 は、この本の p.69 の特殊能力解説が「手札から場に出したときに使える能力は、[ばける]で場に出したときには使えません。たとえば、
「わるいゴルバット」の特殊能力[こっそりかみつく]など。」とだけ書き、のせたカードの特殊能力を使えないとは書いていないと記録しています（kyuura の記録の再利用。ガイドブックは
読んでいない）。英語版（エラッタ後の内容で印刷）も持ち込んでいません。

- 宣言して使う（自分の番に 1 回。宣言のときに記録。v0.42）。ねむり・マヒ・こんらんのこのカードは使えない。かがくへんかガスで使えない。バトル場・ベンチのどちらでも使う。
- 宣言のあと、手札の進化カードを 1 枚選ぶ（決定 `select_evolution_card`。名前・段階の一致は要らない）。選んだカードは `PokemonInPlay.disguise` にのせる（ログ `disguise`。
  進化の重なりではないので、場のポケモンの番号・場に出た番・進化した番・ダメージ・エネルギー・ついているトレーナー・持続する効果・特殊状態は変えない）。
- のせたあとは、そのカードのポケモンとしてあつかう（今の姿 `disguise`: 名前・段階・HP・タイプ・弱点・抵抗力・にげる・ワザ・特殊能力）。いちばん上のカード（タケシの
  キュウコン）の「ばける」も持つ（もどす・特殊状態でもどる説明のため）。のせたカードの特殊能力ははたらき・使える（印刷したカードの uid で識別する）。
- 「手札から場に出した時」の特殊能力（わるいゴルバットの［こっそりかみつく］など）は、のせたときに使う機会を出さない（p.69 の解説）。「場に出た時」の特殊能力
  （わるいカイリューの［てしたをよぶ］）を持つカードは DG2（選べるが選ぶと止める。それしかなければ宣言の前）。
- 進化・退化はできない（`evolution_forbidden`）。
- もとにもどす: `RemoveDisguise`（自分の番。のせたカードをトラッシュ。ログ `disguise_removed` の `reason` `revert`）。ねむり・マヒ・こんらん状態になったら、特殊状態を付ける
  処理がのせたカードをトラッシュしてもどる（`reason` `special_condition`、特殊状態にした効果 `effect`）。どちらも、のせる前の姿にもどるだけで、ダメージ・エネルギー・
  使用回数の記録は残る（同じ番にもう一度「ばける」は使えない）。
- 最大HPが下がり、のっているダメージ以下になる場合: もどす操作は MH1（受け付けない）。相手のワザの特殊状態でもどったなら、ワザのあとのきぜつの判定（v0.48 と同じ）。
- 手札に進化カードがない: PW3（v0.43 の問い）。もうのせているポケモンがもう一度「ばける」を使う: DG3。かがくへんかガスで「ばける」が消える（のせたカードのガスを含む）: DG1。
  ほかに、のせると決められない姿・MH1 になるカードは選べるが選ぶと止める（`shapeshift_choices`。選択ごとの理由 `unresolved_detail`）。
- 未対応のワザ・特殊能力を持つカードをのせた場合は、既存の対応範囲のとおり、そのワザ・特殊能力を使うときに `UNSUPPORTED_ATTACK`・`UNSUPPORTED_POKEMON_POWER` で拒否する
  （暗黙に効果のないものとして続けない）。

## 5. メタモン（［へんしん］）

- 常にはたらく（宣言しない）。はたらくのは、バトル場にいて、ねむり・マヒ・こんらんでなく、かがくへんかガスに消されていないとき。ベンチにもどる・力が消えるとメタモン自身
  （HP 50・無色・ワザなし）にもどる。
- 今の姿は相手の対戦ポケモンのいちばん上のカード。相手の入れ替え（突風・ポケモンいれかえ・ワザ）・進化・きぜつ（バトル場が空いている間はメタモン自身）に、問い合わせの
  たびの答えが追随する。相手のポケモンが受けている効果（ダメージ・特殊状態・持続する効果・テクスチャー・「きょだいか」）は写さない。メタモンが受けている効果はメタモンの
  まま。
- メタモンどうし: 相手のメタモンのいちばん上のカード（メタモン）と同じカード（ワザなし）。相手の今の姿をたどらないので循環しない。
- 写したカードのワザは、必要なエネルギーをそのまま払って使う（2.4）。トラッシュする「○エネルギーカード」はカードの印刷の種類で選ぶ。
- **TE1**（新規。`UNRESOLVED_TRANSFORM_ENERGY_COUNT`）: ワザの説明がタイプのエネルギーの数を数える・タイプのエネルギーカードを選ぶとき、どの色としても使えるエネルギー
  カードをそのタイプとして数えるかは決まらない。2 つの読み方（今のタイプ・すべてそのタイプ）で数・選べるカードが変わるときだけ、宣言の前に止める（すべてそのタイプなら
  止めない）。
- **TF1**（新規。`UNRESOLVED_TRANSFORM_COPIED_POWER`）: 写したカードの特殊能力を持つか（使える・はたらくか）は決まらない（英語版の「always has this Pokémon Power」を
  根拠にしない）。常にはたらく・自動的にはたらく・きぜつするとき・きぜつしたときの特殊能力を持つ相手と同じカードになる状態は作らない（その状態にするコマンドを受け付けない）。
  宣言する特殊能力なら姿にはなれ、写した特殊能力を使う宣言を止める。
- **TF2**（新規。`UNRESOLVED_TRANSFORM_MODIFIED_DEFENDER`）: 相手の対戦ポケモンが「ばける」でほかのポケモンとしてあつかわれている・ポケモンとして出したなにかの化石・
  ピッピ人形なら、どのカードと同じにあつかうかは決まらない（その状態にしない）。
- 進化カードをつけることはできない（`evolution_forbidden`。ヒトカゲと同じカードでも、リザードは重ねられない。ポケモン育て屋さんの対象にもならない）。
- きぜつしてトラッシュするのはメタモンとついているカード（相手のカードは動かさない）。

## 6. 思い出させる

- 使うと、この番の記録（`GameState.recalls` の `RecallEffect`。使ったプレイヤー・番・使ったときの対戦ポケモンの番号といちばん上のカード・トレーナーのカード）を置く
  （ログ `recall`。トレーナーはいつもどおりトラッシュ）。番の終わりに消える。
- 進化前に持っていたワザは、実際に重なっている進化前のカード（`evolution_stack`）のワザ（p.310「進化前に持っていたワザや特殊能力」と同じ言い方。kyuura の
  GR-2000-P310-EVOLUTION）。すぐ下のカードのワザは、最後に進化する前に持っていたワザなので使える。ポケモン育て屋さんで 1 進化を飛ばした 2 進化ポケモンは、重なって
  いるたねポケモンがすぐ下のカード（飛ばした 1 進化カードは場にないので混同しない）。
- 自分のワザとして使うので、必要なエネルギー・説明の条件をそのまま当てはめる（「ゆびをふる」の免除とは違う）。英語版の「(You still have to pay ...)」は根拠にしていない。
- **RC1**（新規。`UNRESOLVED_RECALL_WITHOUT_PRE_EVOLUTION_ATTACK`）: 対戦ポケモンが進化していない・進化前のカードにワザがないときに使えるか（効果のないトレーナーを使えるか）
  は決まらない（使う前に止める。カードは手札のまま）。
- **RC2**（新規。`UNRESOLVED_RECALL_EARLIER_STAGE`）: 2 進化ポケモンのいちばん下のたねポケモンのワザが「進化前に持っていたワザ」に入るかは決まらない（英語版の
  「its Basic Pokémon card or any Evolution card attached to it」を根拠にしない）。選ぶと止める。
- **RC3**（新規。`UNRESOLVED_RECALL_TARGET_CHANGED`）: 使ったあとに対戦ポケモンが入れかわった・進化したとき、説明の「この番だけ」が使ったときの対戦ポケモンにだけ
  当てはまるかは決まらない。選ぶと止める。
- **RC4**（新規。`UNRESOLVED_RECALL_FORM`）: 対戦ポケモンが「ばける」でほかのポケモンとしてあつかわれているとき、「進化前」がどのカードかは決まらない（使う前・使ったあとに
  ばけたなら選ぶと止める）。［へんしん］のメタモンは進化していないので RC1。

## 7. 新しく到達する組み合わせ

### 7.1 決められない姿と、答えのない決定を残さないこと

`engine._apply` は、コマンドのあとに新しく決められない姿（TF1・TF2・DG1。`effects.form_problems`）ができたら、そのコマンドを受け付けません。決定への答え
（バトル場に出す・サイドを取る・ワザや特殊能力の途中の決定）で、どの答えでもできるなら、その前の状態で対戦を止めます（`Phase.HALTED`。答えのない決定を残さない）。
ポケモンチェックでねむり・マヒが回復して決められない姿・MH1 になるなら、コインの前に止めます。

トレーナーの効果の途中の決定（ポケモンいれかえ・突風・ポケモン育て屋さん）は、使用中のトレーナーを残したまま止められないので、`engine._trainer_dead_end` が、どの答えの
続きも受け付けられない（決められない姿・MH1）なら、使う・前の段階の答えを受け付けません（状態の複製の上で深さ優先で試す。上限 256 の答え）。ほかの答えがあれば、その答え
だけを受け付けません。かおりのわな（v0.42。コインのあとに入れ替える特殊能力）は、どの控えでも止まるならコインの前に止めます（`effects.switch_choice_stops`）。

### 7.2 MH1 の入れ替えの確かめ

v0.48 の `switch_max_hp_drop_check` は、どの控えを選んでも同じとして最初の控えだけで MH1 を確かめていました。［へんしん］のメタモンの最大HPは、入れ替えでバトル場に出る
相手の控えで変わるので、v0.49 から、どの控えでも下がるときだけ使う前に止め（理由の文は v0.48 と同じ最初の控えのもの）、一部の控えで下がるならその答えだけを受け付けません。
v0.48 までに起こる組では答えは同じです。

### 7.3 最大HPの RuntimeError（最大HPを決まった数にする効果と、大きくする特殊能力）

v0.48 の `max_hp` は、「きょだいか」（`MaxHpSet`）と［ガスのからだ］（`MaxHpPerAttachedEnergyCards`）が同じポケモンにはたらく組を RuntimeError にしています。v0.49 で
到達しうる経路を調べました: メタモンがキョウのメタモンと同じカードとして「きょだいか」を使い、そのあと相手の対戦ポケモンがナツメのゴースになる組だけが候補で、
［ガスのからだ］は常にはたらく特殊能力なので TF1 でその状態にしません（`test_max_hp_set_and_gaseous_form_never_meet`）。「ばける」でのせられるのは進化カードで、
キョウのメタモン・ナツメのゴース（どちらもたねポケモン）はのせられません。［サイコリンク］はキョウのメタモン（無色）のワザを持ちません。思い出させるで使えるのはワザだけ
です。到達しないので RuntimeError のままにしました（到達する組を作るカードを加えるときは、先に問いを加える）。

### 7.4 v0.49 で直した既存の不具合（公開の API から内部エラーになっていたもの）

| 不具合 | 直し方 |
| --- | --- |

### 7.5 そのほかの点検

- ワザの使用禁止・1 度だけ使えるワザ（2.3）。決定を待つ間のワザの識別（決定の続きの情報とログ）。
- まねるワザ（「ゆびをふる」・「ちょうのうりょく」・「ドわすれ」）: 相手の対戦ポケモンが今持つワザ（［サイコリンク］で持つワザ・［へんしん］の今の姿のワザを含む）から、
  ワザ（`AttackKey`）ごとに 1 つ選ぶ（同じワザを 2 匹が供給しても 1 つ。`effects.held_attack_keys`）。選べるものが v0.48 までの並び（いちばん上のカードのワザ）と
  違うときだけ、決定の `context` に `copy_attacks`・`lock_attacks` を書く（同じなら v0.48 と同じ決定の形）。番をまたぐ効果を与えるワザ（メガバーンなど）をまねるのは、

### 10.2 技術的な制限（エンジンの未対応・止め方）

- 番をまたぐ効果を与えるワザをまねる（`UNSUPPORTED_COPIED_ATTACK`）は v0.35 からのまま。
- 答えのない決定を探す試し・トレーナーの続きの試しは、答えの数 256 までです（今の対応カードでは届かない）。
- 決定への答えでどの答えでも決められない姿になる（バトル場に出す決定など）ときは、対戦を止めます（`Phase.HALTED`。コードは当たった問い）。ワザの途中の決定でどの答えでも
  止まるときも同じです（宣言の前の先読みは、決められない姿を確かめない）。
- 「最大HPを決まった数にする効果と大きくする特殊能力」の組（7.3）は RuntimeError のまま（到達しない）。

### 10.3 実装上の仮定

- 1 匹の［サイコリンク］で同じワザを 2 匹が供給するときは、出どころごとに選べる（同じワザとして使用禁止を当てはめる）。
- 「ばける」でのせたあとも、いちばん上のカード（タケシのキュウコン）の「ばける」を持つ（もどす・特殊状態でもどる説明を処理するため）。
- 「ばける」でのせたカードは、ベンチにもどっても、のせたまま（場所の条件は説明にない）。
- 思い出させるで使うワザは、ワザを使うときにバトル場にいるポケモンが記録のポケモン（番号といちばん上のカード）と同じときだけ選べる（RC3）。
- 決定の答えで止める・対戦を止めるかの判断（7.1）は、答えを 1 つずつ状態の複製の上で試して決める。
