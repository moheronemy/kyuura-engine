# v0.199: ミュウツーの［エナジーコントロール］で、場のレインボーエネルギーを選べるものから外す（0.199.0）

2026-11-27。ミュウツー（PR1-022）の［エナジーコントロール］で、相手の場についているレインボーエネルギーを、特殊エネルギーカードとして選べるものから外しました。通常のエンジンの処理として実装しています。

- **記録の区分:** カード文面とカード分類に基づく実装解釈。当時の直接裁定は未確認。
- **根拠:** ワザの文面「相手の場のエネルギーカード(特殊エネルギー以外)を1枚選んではがす」と、レインボーエネルギーが特殊エネルギーのカード（kyuura のカードデータの `energy.kind` が `special`）であることです。
- **研究の論点:** 論点そのもの（kyuura の `UQ-SPECIAL-ENERGY-AS-TYPED-ENERGY`）は UNRESOLVED のままです。研究の記録・裁定の分類は変えていません。
- **ほかの処理:** 同じ停止コード `UNRESOLVED_RAINBOW_AS_BASIC_ENERGY_CARD`（RB3）を使うほかの処理には、この判断を当てはめていません。
- 経緯は [RB3 の停止の照合](tr8-rainbow-as-basic-energy-stop-analysis.md) を参照してください。
