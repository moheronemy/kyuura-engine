# v0.93: バトル場をはなれられない効果と続くワザの制限の 9 枚

v0.93 は、「バトル場をはなれられない」効果・続くワザの制限を持つポケモン 9 枚（キャタピー ES1-002・QSG-002、モンジャラ ES2-004、クサイハナ neo1-008、アリゲイツ neo1-030、

つなぎました。あわせて、v0.92 のくろいまなざしの短い論点名を ML1 から ML2 に直しました（2.2 節）。目的は模擬戦で使えるカードを増やすことで、強さ・勝率・釣り合いは評価していません。

## 4. 「バトル場をはなれられない」効果の共通の扱い

### 4.1 型と値

- 期間を明示した持続する効果に 2 つの型を加えました（`state.PERIOD_EFFECT_TYPES`。v0.92 の 3 つと同じ値の組）: `PeriodLeaveLock`（バトル場をはなれられない）・`PeriodAttackCoinCheck`
  （p.309 の手順 4 のコイン。かぶりつく。7.2 節）。どちらも相手に与える効果です。
- `PeriodLeaveLock` の値: v0.92 の `created_turn`・`active_turn`・`end_turn`・`source_card`・`source_player`・`source_pokemon`・`while_source_active`・`ends_on` に、
  `knockout_exception`（「(「きぜつ」した場合をのぞく)」）と `source_left`（くいつくの印。6.2 節）を加えました。`source_left` は「かぎり」で、発生源がはなれても消えない効果だけに
  付けられます（ほかは作るときに `ValueError`）。
- 問い合わせ（`persistent.leave_locks`・`leave_lock`）: 受けたポケモンがバトル場にいて、今の番が期間の中で、「かぎり」なら発生源がバトル場にいるときにはたらきます。`leave_lock` の
  `knock_out=True` は、きぜつの処理で問い合わせるときで、受けたすべての効果にきぜつの例外があれば、発生源を読まずに None です。
- 与える要素は v0.92 の `OpponentPeriodLock` に `lock="leave"` と `knockout_exception`・`gate`（ワザ全体のコインが決める。ねばるみつ）を加えたものです。

### 4.2 「にげる」の禁止との違い

- 「にげる」の禁止（v0.36 の `CannotRetreat`・v0.92 の `PeriodRetreatLock`）は「にげる」だけを止め、入れ替え（トレーナー・ワザ）は止めません（p.325）。「バトル場をはなれられない」
  効果は、受けたポケモンをバトル場からはなれさせるすべての移動を止めます。「にげる」の禁止に縮めていません（`LeaveLockTest.test_retreat_lock_only_still_allows_switching`）。
- 「にげる」の拒否は `LEAVE_ACTIVE_PREVENTED`（`IllegalActionError`）で、エネルギーのトラッシュ・こんらんのコインの前、`RETREAT_PREVENTED` より先に確かめます。

### 4.3 きぜつ（例外のある効果・ない効果）

- p.323: HP 以上のダメージを受けたポケモンは、きぜつしてトラッシュに置かれます。きぜつの例外を書いた効果（からみつく・くいつく・どくしばり）は、きぜつの処理を止めません。例外は
  きぜつの処理そのもの（`procedures.knock_out` の `require_can_leave(knock_out=True)`）で使い、「HP 以上」で読み替えません。HP 以上になったまま同じワザ・同じ手順の途中で効果が
  動かそうとするのは、きぜつの処理ではないので、例外の対象ではありません（効果ははたらく）。
- 例外を書いていない効果（からまるいと・ねばるみつ）を受けたポケモンが HP 以上になるとき、きぜつの処理でバトル場をはなれるのかは決まりません（AL1。10 章）。止める時点はきぜつの処理の
  前です: ワザの中なら、ワザのあとのきぜつの判定の窓の問い（`leave_lock_knockout`。先読みがワザの宣言の前に見つける）、ポケモンチェックなら、どく・やけどのダメージを与える前に
  対戦を止めます（`procedures._pokemon_check_plan` の `Halt`。v0.48 の MH1 と同じ形。`KnockOutTest`）。きぜつの処理に送る共通の処理（`flow._knock_out_all`）とマルマインの
  ［エネエネ］（`flow._knock_out_to_energy`）も、トラッシュに送る前に AL1 で止めます（呼ぶ側の確かめの漏れの安全網）。
- KD1（同じワザで HP 以上になったポケモンの［にげこむ］）は回り道していません: はなれられないポケモンには［にげこむ］の入れ替えが起こらないので聞かず（10 章）、はなれられるポケモンは
  今までどおり KD1 です。

移動の前（移動・ついているカードのトラッシュ・支払い・コイン・決定の前）に確かめます。`zones._left_active`（v0.92）は移動のあとの処理なので、確かめには使いません。

- `effects._switch_active_with_bench`・`zones.return_in_play_to_deck`・`return_basic_to_hand`・`return_in_play_to_hand`・`discard_from_play`・`hand_basic_to_active` は、移動の前に

### 4.5 移動が起こらないとき・はなれることではないもの

- 移動が起こらないときは、移動のログ（`switch`・`forced_switch`・`return_*`）・反応（［まきびし］・［やけのこり］・［いなびかり］など）・変わり身の術のトラッシュ・持続する効果の消去・
  発生源がはなれたときの解除を起こしません。起こらなかったことはログ `leave_prevented`（`player`・`pokemon`・`pokemon_id`・`cause`・`persistent_effect`・`source_card`・
  `created_turn` と、効果の出どころ）に書きます。`cause` は `switch`・`forced_switch`・`to_hand`・`to_deck`・`hand_to_active` のどれかです。
- 進化・退化・［ばける］・エネルギーや進化カードの移動・ベンチの中の移動は、バトル場をはなれることではありません（止めない）。受けたポケモンの進化・退化では、受けた効果は一般の規定
  （p.310・p.324）で消えます（`LeaveLockTest`・`MovePathTest.test_receiver_evolution_and_devolution_end_the_lock`）。

## 5. キャタピー・モンジャラ・クサイハナ

### 5.1 からまるいと（キャタピー）・からみつく（モンジャラ）

- 「おもて」なら、与えた番から次の相手の番の終わりまで、相手の対戦ポケモンはバトル場をはなれられません（`PeriodLeaveLock`。`active_turn` は与えた番、`end_turn` は与えた番 + 1）。
  「うら」なら何も与えず、ワザの失敗ではありません。期限で消えます（理由 `expired`）。
- 発生源がはなれたら消えるとは書かれていないので、発生源のキャタピー・モンジャラがベンチに移っても、受けたポケモンははなれられません（`test_source_leaving_does_not_end_tangle_or_constrict`）。
- からまるいとにはきぜつの例外がなく（AL1）、からみつくにはあります（4.3 節）。

### 5.2 へんなこな（クサイハナ）

- 1 枚のコインで、「おもて」ならこんらん、「うら」ならねむり（既存の型。3 章）。

### 5.3 ねばるみつ（クサイハナ）

- 要素は `Coin` → `Damage(OPP, 20 + おもてなら 10)` → `OpponentPeriodLock(leave, 0, 1, gate=おもて)`。1 枚のコインで、基本となるダメージ（p.321 の 1 段階）の +10 と、その場合の
  はなれられない効果の両方を決めます（要素ごとに投げ直さない）。きぜつの例外はありません（AL1）。
- このワザで相手が HP 以上になれば、効果の処理の対象がないので与えません（p.309）。「ダメージを受けない」相手でも、はなれられない効果は有効なのでコインを投げ、与えます。「ワザを
  うけない」相手はどちらの要素も無効なので、ワザ全体のコインを投げるかが決まらない HC3（v0.34 の `void_coin_question`）です（`StickyNectarTest`）。

## 6. アリゲイツ・わるいアリアドス

### 6.1 いやなおと（アリゲイツ）

- v0.92 のイワークと同じ全文で、同じ型・同じ期間（次の相手の番と次の自分の番の +20）です。

### 6.2 くいつく（アリゲイツ）

- コインなしで、次の相手の番、このカードがバトル場にいるかぎり、受けたポケモンはバトル場をはなれられません（`while_source_active`。きぜつの例外あり）。発生源がバトル場にいない
  あいだは、はたらきません。
- 発生源がはなれたら消えるとは書かれていないので、消しません。発生源がはなれた時点で印 `source_left` を付け（ログ `persistent_effect_source_left`）、もどってきたら、またはたらくかが
  決まらないので JC1 です（`JawClampTest.test_source_gusted_away_marks_and_returning_is_jc1`）。発生源の姿が与えたときと違う（進化・退化）なら JC2 です。
- 既存の問いとの関係: JC1 は v0.40 のすごむの SG1（`UNRESOLVED_ATTACK_LOCK_SOURCE_RETURNED`。ワザを使えない効果）、JC2 は v0.92 のくろいまなざしの ML2（「にげる」の禁止）と同じ形
  ですが、カードの文面・止める効果（バトル場をはなれられない）が違う別の問いなので、同じ ID にまとめていません。ML2 の確かめ（`source_bound_effects`）はくいつくに当てはめません。

### 6.3 からめとる（わるいアリアドス）

- 要素は `FailWithoutOpponentBench` → `ForceSwitch(chooser="attacker")` → `Status(PARALYSIS, おもて, after_switch)`。ワザを使ったプレイヤーが相手の控えを選んで入れ替え（決定
  `FORCED_SWITCH`。相手が選ぶかぜおこしにしない）、入れ替えのあとの反応を処理してから、コインの「おもて」で新しく出てきたポケモンをマヒにします。もとの対戦ポケモンはマヒにしません。
- 相手に控えがいないときは「このワザは失敗する」（p.323 のワザの失敗。宣言でき、コインを投げない。ログ `attack_failed` の理由 `no_opponent_bench`）。別のカードの「このワザは使えない」
  （使うための条件）とは違います。相手のワザとして使う（ゆびをふる）ときも、使えないワザにはしません（HC9 の「使えない」に数えない）。
- 入れ替わらなかった（相手の対戦ポケモンがはなれられない）なら、もとの相手を「新しく出てきたポケモン」にしません（コインを投げず、マヒにしない。決定も出さない）。

### 6.4 どくしばり（わるいアリアドス）

- 要素は `Damage(OPP)` → `Status(POISON)` → `OpponentPeriodLock(leave, 0, 1, この要素のコイン, きぜつの例外)`。どくはコインによらず、禁止だけをこの要素のコインで決めます。
  このワザで相手が HP 以上なら、どちらも与えず、コインも投げません（p.309。`PoisonBindTest`）。

## 7. イノムー・わるいアリゲイツ・オクタン

### 7.1 こおりつかせる・ふぶき（イノムー）

- こおりつかせるは「おもて」なら、与えた番から期限なしで、受けたポケモンはワザを使えません（`PeriodAttackLock`。`end_turn` は `None`）。次の相手の番だけで期限切れにしません。
  「(相手がバトル場をはなれたとき、この効果は消える)」は一般の規定と同じ内容（v0.92 のクモのすと同じ読み方）で、受けたポケモンがはなれる・進化・退化で消え、発生源のイノムーが
  はなれても消えません（`FreezeTest`）。
- ふぶきは既存の v0.52 の型です。

### 7.2 かぶりつく（わるいアリゲイツ）

- コインなしで、次の相手の番の「にげる」の禁止（`PeriodRetreatLock`）と、ワザを使うときのコイン（`PeriodAttackCoinCheck`。「うら」ならそのワザは失敗する）の 2 つを与えます。どちらも
  「このカード、またはこのワザを受けた相手がバトル場をはなれたとき」に消え（`SOURCE_LEAVES_ACTIVE`）、発生源がもどっても復活しません（`ClampingJawTest`）。
- 入れ替えは止めません（「にげる」の禁止だけ）。こんらんのポケモンがワザを使うときは、手順 4 と 5 の順番が決まらない既存の AC6、ほかの手順 4 のコインと重なるときは AC13 です。
- 発生源が退化して「このカード」を重なりからはがされたが、ポケモンはバトル場にいるとき、効果が消えるのかは決まらないので CJ1 です（効果を読むとき）。v0.92 のヨーギラスの進化
  （はなれていない）の読み方は、カードがはがれない進化だけに使います。
- 既存のワザを使うときのコインの型（えんまく・v0.45）の期間の値は変えていません（`test_old_attack_coin_checks_keep_their_terms`）。

### 7.3 からみつく・オクタンほう（オクタン）

- からみつくは既存の `ParalyzeOnHeads` です。
- オクタンほうは与えるコインの「おもて」で、期限なしに、受けたポケモンがワザを使うたびにコインを投げさせます（既存の `AttackCoinCheck` の `lasting`。1 回で消えない）。与えるコインと、
  ワザを使うときのコインは別です。始まりは「以後」（与えた番）ですが、受けた相手がワザを使えるのは次の相手の番からなので、既存の値（はたらく番は次の相手の番）で結果は変わりません
  （`OctazookaTest`）。
