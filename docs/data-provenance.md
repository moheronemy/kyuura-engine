# カードデータの由来と照合

## 正本と写し

- カードデータの正本は kyuura（https://github.com/moheronemy/kyuura）の `data/cards.json` です。
- このリポジトリの `kyuura_engine/data/kyuura_cards.json` は、対戦で使うカード（v0.1 のたねポケモン・基本エネルギー、v0.2b・v0.2c のトレーナー。`pool_v0_1`・`pool_v0_2b`・`pool_v0_2c`）と、分類のテストに使う参照カード（`reference_only`）の記録だけを抜き出した**写し**です。値は書き換えていません。独立したカード情報の正本として扱わないでください。
- 自動テストは、この写しだけで動きます（ネットワークや kyuura の clone は不要）。

| 項目 | 内容 |
|---|---|
| 元のリポジトリ | https://github.com/moheronemy/kyuura |
| 元のコミット | `ecb2d694e6280ec5dc9ddd2a8f709cea16a6b691`（kyuura docs/engine-readiness.md が「基準にする調査データ」とするコミット） |
| 元のファイル | `data/cards.json`（schema_version 2） |
| 生成 | `scripts/extract_kyuura_cards.py`（`git show <コミット>:data/cards.json` で読むので、kyuura の作業ツリーの状態に左右されない。kyuura は読むだけで変更しない） |
| 照合の記録 | `kyuura_engine/data/card_verification.json`（このリポジトリの作業記録） |

### 作り直し方

```sh
git clone https://github.com/moheronemy/kyuura.git ../kyuura
python3 scripts/extract_kyuura_cards.py --kyuura ../kyuura          # 書き出す
python3 scripts/extract_kyuura_cards.py --kyuura ../kyuura --check  # 同梱の写しと同じか確かめる
```

`../kyuura` があれば、`tests/test_cards.py` の `test_extract_matches_kyuura_commit` が `--check` を実行します（なければ飛ばします）。

参照するコミットを変えるときは、`scripts/extract_kyuura_cards.py` の `KYUURA_COMMIT` を変えて写しを作り直し、照合の記録とテストを見直してください。

## 利用した項目

写しには、各カードの次の項目をそのままコピーしています: `id`、`jp_set`、`category`、`name`、`name_ja_confidence`、`pokemon`、`trainer`、`energy`、`jp_en_differences`、`notes`、`source_ids`、`ja_text_source`、`jp_print`。

そのうち、エンジンが対戦の処理に使うのは次の項目です（それ以外は出典を確かめるためにコピーしています）。

| 項目 | 使い方 |
|---|---|
| `id` | カードの指定 |
| `category` | ポケモン・トレーナー・エネルギーの区別 |
| `name.ja` | 同じ名前のカードの枚数制限（p.308）、表示 |
| `pokemon.stage` | たねポケモンかどうか（進化・ベイビィは未対応） |
| `pokemon.hp`・`types`・`weaknesses`・`resistances`・`retreat_cost` | きぜつ、ダメージ計算、にげる |
| `pokemon.attacks[]` の `name`・`cost`・`damage`・`text` | ワザ。`text` があるワザ、`damage.modifier` があるワザは未対応に分類する |
| `pokemon.powers`・`pokemon.rules_text` | あれば未対応に分類する |
| `trainer.text`・`trainer.kinds` | トレーナーの効果の登録（カード id）と照合する（v0.2b）。登録したときの名前・文面と違えば未対応に分類する。処理の根拠ではない（処理は『オフィシャルブック2000』の最新の説明にしたがう。[trainers-v0.2b.md](trainers-v0.2b.md)） |
| `energy.kind`・`energy.provides` | 基本エネルギーかどうか、エネルギーのタイプ |

kyuura の転記の性質（日本語の文面はなぞのばしょ・ポケモンWiki の転記、数値は英語版データから入れて転記と比べたもの）は kyuura の docs/research-status.md と docs/data-schema.md を見てください。

## v0.1 の対戦で使うカード

段階 1 の候補（kyuura docs/engine-readiness.md 5章）のうち、効果のないワザだけを持つ第1弾のたねポケモン 10 種と、基本エネルギー 6 種です。きずぐすり・ポケモンいれかえ・マサキ（5章の候補）は v0.2b で加えました（[下の章](#v02b-で加えたトレーナー)）。プラスパワー（5章の候補）は v0.2c で加えました（[下の章](#v02c-で加えたプラスパワー)）。

- どのポケモンも、「ワザ」欄にはワザの名前だけがあり、説明文（効果）はありません。kyuura の記録でも `text` は日本語・英語とも `null` です。
- 1 匹が 2 つのワザを持つカード（ポニータ・ディグダ・エビワラー）も、両方のワザが効果のないワザです。v0.1 には、対応するワザと未対応のワザが混ざったカードを対戦用に入れていません。混ざったカードは、カードごとではなくワザごとに分類し、カード全体を未対応にします（下の参照カードのヒトカゲ）。

## v0.2b で加えたトレーナー

『オフィシャルブック2000』p.254（PDF p.256）のトレーナーカードのページを画像で読み、見出し・収録商品・図版の文面・カードの記述（最新の説明）・解説を照合しました（2026-10-12）。p.6「この本の使いかた」は、カードの記述を「カードの「最新の説明」」としています。照合の記録は `kyuura_engine/data/card_verification.json`（`card_image_text_ja`・`latest_description_ja`）、裁定の検討は [trainers-v0.2b.md](trainers-v0.2b.md) です。

| id | カード | kyuura の文面（第1弾の転記） | 最新の説明（p.254） | 照合 |
|---|---|---|---|---|
| PMCG1-074 | マサキ | 山札からカードを2枚引いて、手札に加える。 | 山札からカードを2枚引いて、手札に加える。 | 一致 |
| PMCG1-071 | きずぐすり | 自分の場のポケモンにのっているダメージカウンターを2個まで、とりのぞくことができる。 | あなたの場にいるポケモンを1匹選び、そのポケモンにのっているダメージカウンターを、2個とりのぞく。 | **不一致あり**（文面。上の表） |
| PMCG1-073 | ポケモンいれかえ | 自分の場の対戦ポケモンと控えポケモンを入れ替える。「にげる」ためのエネルギーを支払う必要はない。 | あなたの控えポケモンを1匹選び、あなたの対戦ポケモンと入れ替える。 | **不一致あり**（文面。意味は矛盾しない） |

- きずぐすり・ポケモンいれかえの図版には番号（⑦・⑲）があり、第1弾の版（番号なし）ではない可能性が高いです。どの版の文面かは確かめていません。
- エンジンの処理は最新の説明にしたがい、kyuura の文面は登録の照合（データが変わったら気づく）にだけ使います（`effects.TrainerEntry`）。

## v0.2c で加えたプラスパワー

『オフィシャルブック2000』p.257（PDF p.259）のトレーナーカードのページを画像で読み、見出し・収録商品・図版の文面・カードの記述（最新の説明）・解説を照合しました（2026-10-12）。公式ルール p.321 のダメージ計算の 5 段階にも、同じ最新の説明が引かれています（「(控えポケモンへのダメージは、そのまま)」はない）。照合の記録は `kyuura_engine/data/card_verification.json`、裁定の検討は [pluspower-v0.2c.md](pluspower-v0.2c.md) です。

| id | カード | kyuura の文面（第1弾の転記） | 最新の説明（p.257） | 照合 |
|---|---|---|---|---|
| PMCG1-081 | プラスパワー | 自分の対戦ポケモンの「ワザ」によって与えるダメージを「+10」できる。自分の対戦ポケモンにつけて使い、自分の番の終わりに、はがしてすてる。 | このカードはあなたの対戦ポケモンにつけて使い、あなたの番の終わりにトラッシュする。このカードをつけているポケモンのワザが、対戦ポケモンにダメージを与えるとき、そのダメージは「+10」される。(控えポケモンへのダメージは、そのまま) | **不一致あり**（版の違い） |

- kyuura の cards.json の文面は第1弾の印刷の転記です。kyuura は `ERR-PLUSPOWER`（data/rule_history.json）に、この最新の説明を `play_text` として別に記録しており、その値は p.257 の画像と一致しました（新しい食い違いではありません）。
- p.257 の図版は記号のある版で、文面はジム第2弾以降のものです（第1弾の版ではない）。
