# カードデータの由来と照合

## 正本と写し

- カードデータの正本は kyuura（https://github.com/moheronemy/kyuura）の `data/cards.json` です。
- このリポジトリの `kyuura_engine/data/kyuura_cards.json` は、v0.1 で使うカードの記録だけを抜き出した**写し**です。値は書き換えていません。独立したカード情報の正本として扱わないでください。
- 自動テストは、この写しだけで動きます（ネットワークや kyuura の clone は不要）。

| 項目 | 内容 |
|---|---|
| 元のリポジトリ | https://github.com/moheronemy/kyuura |
| 元のコミット | `ecb2d694e6280ec5dc9ddd2a8f709cea16a6b691`（kyuura docs/engine-readiness.md が「基準にする調査データ」とするコミット） |
| 元のファイル | `data/cards.json`（schema_version 2） |
| 生成 | `scripts/extract_kyuura_cards.py`（`git show <コミット>:data/cards.json` で読むので、kyuura の作業ツリーの状態に左右されない。kyuura は読むだけで変更しない） |
| 照合の記録 | `kyuura_engine/data/card_verification.json`（このリポジトリの作業記録） |

### 作り直し方

```sh
git clone https://github.com/moheronemy/kyuura.git ../kyuura
python3 scripts/extract_kyuura_cards.py --kyuura ../kyuura          # 書き出す
python3 scripts/extract_kyuura_cards.py --kyuura ../kyuura --check  # 同梱の写しと同じか確かめる
```

`../kyuura` があれば、`tests/test_cards.py` の `test_extract_matches_kyuura_commit` が `--check` を実行します（なければ飛ばします）。

参照するコミットを変えるときは、`scripts/extract_kyuura_cards.py` の `KYUURA_COMMIT` を変えて写しを作り直し、照合の記録とテストを見直してください。

## 利用した項目

写しには、各カードの次の項目をそのままコピーしています: `id`、`jp_set`、`category`、`name`、`name_ja_confidence`、`pokemon`、`trainer`、`energy`、`jp_en_differences`、`notes`、`source_ids`、`ja_text_source`、`jp_print`。

そのうち、エンジンが対戦の処理に使うのは次の項目です（それ以外は出典を確かめるためにコピーしています）。

| 項目 | 使い方 |
|---|---|
| `id` | カードの指定 |
| `category` | ポケモン・トレーナー・エネルギーの区別 |
| `name.ja` | 同じ名前のカードの枚数制限（p.308）、表示 |
| `pokemon.stage` | たねポケモンかどうか（進化・ベイビィは未対応） |
| `pokemon.hp`・`types`・`weaknesses`・`resistances`・`retreat_cost` | きぜつ、ダメージ計算、にげる |
| `pokemon.attacks[]` の `name`・`cost`・`damage`・`text` | ワザ。`text` があるワザ、`damage.modifier` があるワザは未対応に分類する |
| `pokemon.powers`・`pokemon.rules_text`・`trainer` | あれば未対応に分類する |
| `energy.kind`・`energy.provides` | 基本エネルギーかどうか、エネルギーのタイプ |

kyuura の転記の性質（日本語の文面はなぞのばしょ・ポケモンWiki の転記、数値は英語版データから入れて転記と比べたもの）は kyuura の docs/research-status.md と docs/data-schema.md を見てください。

## v0.1 の対戦で使うカード

段階 1 の候補（kyuura docs/engine-readiness.md 5章）のうち、効果のないワザだけを持つ第1弾のたねポケモン 10 種と、基本エネルギー 6 種です。きずぐすり・ポケモンいれかえ・マサキ・プラスパワー（5章の候補）は、トレーナーカードの効果を v0.1 で実装していないので入れていません。

- どのポケモンも、「ワザ」欄にはワザの名前だけがあり、説明文（効果）はありません。kyuura の記録でも `text` は日本語・英語とも `null` です。
- 1 匹が 2 つのワザを持つカード（ポニータ・ディグダ・エビワラー）も、両方のワザが効果のないワザです。v0.1 には、対応するワザと未対応のワザが混ざったカードを対戦用に入れていません。混ざったカードは、カードごとではなくワザごとに分類し、カード全体を未対応にします（下の参照カードのヒトカゲ）。

### 食い違い（kyuura への報告事項）

| id | 項目 | kyuura の値 | 『オフィシャルブック2000』 | エンジンでの扱い |
|---|---|---|---|---|
| PMCG1-016 | 1 つ目のワザの名前 | けりとばす（なぞのばしょの転記） | けとばす（p.75 のカードの図版、「ワザ」欄「●けとばす」、解説文「「けとばす」は、エネルギーの色を選ばないので」） | ワザの名前は処理に使わないので、kyuura の値のまま使う。kyuura 側で確かめて記録する必要がある |

同じ本の図版が第1弾の初版と同じ印刷かは確かめていません（刷による違いの可能性は残ります）。
