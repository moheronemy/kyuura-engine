# 進化のカード（v0.4a）: パラス → パラセクト、パウワウ → ジュゴン

v0.4a で対応した 1 進化ポケモン 2 枚と、その進化元のたねポケモンを、『ポケモンカードオフィシャルブック2000』のカードのページと照合した記録です。照合の記録は `kyuura_engine/data/card_verification.json`、進化のルールは [evolution-rules-v0.4a.md](evolution-rules-v0.4a.md) にあります。

- 照合の方法: Internet Archive のスキャン [J38] の PDF をページ画像（300dpi）にして目で読んだ（2026-10-12）。カードの図版（左上の進化の印・「○○から進化」・タイプ・ワザ・にげる・弱点・抵抗力）と、左の「ワザ」欄の「最新の説明」、右の解説を読んだ。
- kyuura の参照コミット: `ecb2d694e6280ec5dc9ddd2a8f709cea16a6b691`（data/cards.json）。写しは `python3 scripts/extract_kyuura_cards.py --kyuura ../kyuura` で作り直し、`pool_v0_4a` を加えた。

## 4. パラス・パウワウ（進化元）

- パラス（p.38）は v0.3b、パウワウ（p.101）は v0.1 で照合して対応にしたカードで、v0.4a で変えていません。進化元の名前（「パラス」「パウワウ」）は、kyuura の `name.ja` と、進化カードの `evolves_from.ja` が一致します（エンジンは日本語の名前で比べる）。
- 「エリカのパラス」「カスミのパウワウ」（ジム）は別の名前のポケモンなので、パラセクト・ジュゴンの進化元になりません（p.309 の「その「○○○○」という名前のポケモン」）。v0.4a のカードの写しにはありません。

## 5. 未対応の部分

- 同じ名前の別のカード（パラセクト LV.29（拡張シート）・neo3 のパラセクト（ポケモンパワー「アレルギーほうし」）、ジュゴン LV.24 など）は対応していません。カード id が違うので、登録表にない（デッキに入らない）。
- 2 進化・ベイビィポケモン・退化・ポケモンパワーは未対応です。
- v0.3d の調査（[evolution-readiness-v0.4.md](evolution-readiness-v0.4.md) 4 章）で、今の実装では処理できないとしたカード（トランセル・コクーン・ライチュウなど）は登録していません。
