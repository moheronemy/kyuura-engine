# サカキのワンリキー・ゴーリキー・カイリキーのワザの原典の照合と裁定（v0.11）

v0.11 でサカキのカイリキー（PMCG6-061）の系統を対戦で使えるようにするために、『ポケモンカードオフィシャルブック2000』[P43] で確かめた記録です。サカキのカイリキーの特殊能力「こんじょう」は [guts-v0.11.md](guts-v0.11.md)。照合の記録は kyuura_engine/data/card_verification.json の PMCG6-057・PMCG6-059・PMCG6-061。テストは tests/test_giovanni_machamp_line_v0_11.py（盤面を直接作る）と tests/test_giovanni_games_v0_11.py（自然な対戦）。

## 1. 確かめ方

- Internet Archive のスキャンの PDF からページを画像にし（300dpi。カードの図版は 600dpi で拡大）、目で読んだ。PDF のページ = 誌面のページ + 2。
- 照合したのは、p.189 の「たねポケモン サカキのワンリキー LV.18／HP50」、p.191 の「サカキのワンリキーから進化 サカキのゴーリキー LV.36／HP80」、p.193 の上の「サカキのゴーリキーから進化 サカキのカイリキー LV.50／HP100」。どれも収録「ジム拡張第2弾闇からの挑戦」。
- 第1弾のワンリキー（PMCG1-053。p.189）・ゴーリキー（PMCG1-055。p.190）・カイリキー（PMCG1-057。p.192）は名前が違う別のカード。進化元の名前が違うので、たがいに進化できない（p.310「進化カードの…「○○から進化」」）。
- 使わなかった資料: 英語版の文面（kyuura の `text.en`）。
