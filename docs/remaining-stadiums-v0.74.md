# v0.74: 拡張パック以外の商品のスタジアム 13 枚

拡張パック以外の商品（ポケモンカードゲーム拡張シート（ES）・プロモ・イントロパック★neo）のスタジアム 13 枚（4 つの名前・印刷の文面 6 組）を、kyuura データの採用で
登録して対応にしました。既存のスタジアムの仕組み（`StadiumEffect`・`UseStadium`・`push_stadium_decision`・`stadium_uses_this_turn`）と、選択・カードの移動・引く処理を使い、要る分だけ
共通の処理を広げ、既存のスタジアムの回数の確かめ（セキチクシティジムの FG1）の範囲を直しました。目的は対応するカードを増やすことで、カードの強さ・勝率・デッキの釣り合いは評価して
いません。

- 基準: v0.73（`8456dc01dffbd3ffffd23505f08ba56bc668c375`）。作業ブランチ `claude/v0.74-remaining-stadiums`（v0.73 から作った）。開始時に作業ツリーに変更はなく、`main`
  （`1b890ee`）は v0.73 の祖先（13 コミット前）で、取り込むものはありませんでした。
- カードの写しの元・研究の基準は、どちらも kyuura `7d3f4ca76c084774efb4ac6a1d3a943387e183c3` のまま。kyuura は変えていません。固定の参照データは作り直していません。
- ルールの基準は 2000.02.14 版のままです。2001 年に発売したイントロパック★neo のカード（NIP1X-009・NIP2X-009）も、この枠組みで扱います（のちのルールを持ち込まない）。
  英語版の文面（PRN-027 の日本語の欄の英語の併記を含む）・現代のルール・2002 年のサポーターの規定・2003 年以後のスタジアムの使用の制限（kyuura `MIX-ADV-RULES-2003`）で、
  日本語の不足を補っていません。
- 公式ガイドブック（『オフィシャルブック2000』）のキャプチャ・OCR・読み直しはしていません。pcg-search.com との新しい外部照合もしていません（13 枚とも kyuura の日本語の文面が
  pcg-search.com の転記（`ja_text_source`）で、同じサイトでの照合は独立した照合にならない）。読んでいない原典を確かめたことにする記録は作っていません。
- 書き出しの形式（22）・公開の API の呼び方・状態の項目は変えていません（使う記録は既存の `stadium_uses_this_turn` に持つ）。

## 2. 13 枚と処理

写しの組は `pool_v0_74`（並びは依頼の並び）。処理に使う文面は、どれも kyuura の印刷の文面です（採用の記録の `play_text` は `kyuura_printed_text`）。

| 処理（効果の型） | カード | 印刷の文面の要点 |
|---|---|---|
| `DiscardToHandSuppressionStadium` | ポケモンタワー ES3-036 | お互いの「ワザ・特殊能力・トレーナーカード」の効果のうち「トラッシュからカードを取り出して手札に加える」効果は、すべて消える（それ以外はそのまま） |
| `CoinBenchOwnerBasicFromDeckStadium` | キョウの忍者ジム PR1-067 | のぞむなら、自分の番ごとに 1 回、コイン。「おもて」なら自分の山札から「キョウのたねポケモン」を 1 枚ベンチへ。その場合、山札を切る |
| `CoinRetrieveBasicEnergyStadium` | エネルギースタジアム NIP1X-009 | のぞむなら、自分の番ごとに 1 回、コイン。「おもて」なら自分のトラッシュの「基本エネルギーカード」を 1 枚見せて手札へ |
| `CoinDrawStadium`（`once_stated`） | ラッキースタジアム NIP2X-009・PRN-015〜PRN-022 | のぞむなら、自分の番ごとに 1 回、コイン。「おもて」なら 1 枚引く |
| `CoinDrawStadium`（`once_stated` が偽） | ラッキースタジアム PRN-027 | その番のプレイヤーは（ワザを使う前に）コインを投げてもよい。「おもて」なら 1 枚引く（日本語に「自分の番ごとに1回」がない） |

- 印刷の文面は 6 組です: ポケモンタワー・キョウの忍者ジム・エネルギースタジアム・ラッキースタジアムの NIP2X 版（「自分の山札から」「投げてよい」）・PRN-015〜PRN-022 版
  （「山札から」「投げてもよい」）・PRN-027 版（日本語と英語の併記。置き方の段落も「このカードは、対戦が終わるまで場に出しておく。」）。

  v0.73 の `_with_shared_trainers`。値が違えば `RuntimeError`）。NIP2X-009・PRN-027 は文面が違うので、それぞれの登録・印刷の文面・出典を保ちます（まとめない）。
- 登録した 13 枚のほかの、名前が同じカード（neo 拡張パックのエネルギースタジアム・ラッキースタジアムなど）は加えていません。

## 3. 共通の土台

### 3.1 置き方の段落の受け付け

`StadiumEffect.check` は v0.57 から、置き方の文（「バトル場の横に出して使う」と、別のスタジアムが場に出たらこのカードをトラッシュする 3 通りの文）を確かめていました。v0.74 の
11 枚の置き方は書き方が違うので、次の 2 つの段落を、印刷の文面の最後の段落として全文で照らして受け付けます（`effects.STADIUM_PLACEMENT_PARAGRAPHS`）。

- イントロパック・プロモ: 「「スタジアムカード」は、バトル場の横に出して使う。別の「スタジアムカード」が場に出たとき、このカードをトラッシュする。」
- PRN-027: 「このカードは、対戦が終わるまで場に出しておく。別の「スタジアムカード」が場に出たとき、このカードをトラッシュする。(This card stays in play after being played. Discard
  this card if another Stadium card comes into play.)」（英語の併記は原データのまま照らし、英語で日本語の不足を補わない。英語の併記を除いた文面は受け付けない）

広い言い回しで受け付ける形にはしていません。新しい型（`CoinDrawStadium`・`CoinRetrieveBasicEnergyStadium`・`CoinBenchOwnerBasicFromDeckStadium`・`DiscardToHandSuppressionStadium`）の
`text_problems` は、版ごとの全文と登録の値（ラッキースタジアムの `once_stated`・忍者ジムの持ち主の名前）を照らします（`effects.LUCKY_STADIUM_TEXTS`）。写しの文面は書き換えていません。
手札から出せるスタジアムの枚数・同じ名前のスタジアムへの入れかえ・古いカードを持ち主のトラッシュに置くことは、2000.02.14 版の既存の実装（v0.57）のままです。

### 3.2 使った記録と回数（既存の修正を含む）

- 使った記録は既存の `GameState.stadium_uses_this_turn`（(使ったプレイヤー, スタジアムカードの uid)）だけに持ちます。記録を残すかは実装の `records_uses`（v0.74。既定は
  `once_per_turn`）で、「自分の番ごとに1回」のスタジアムと、PRN-027（回数が書かれていないが、同じ番の再使用を確かめるために記録する）が残します。不変条件
  （`engine._stadium_problems`）は記録と今の番のログ `stadium_used` を `records_uses` で照らします。
- 記録はスタジアムカードごとで、同じ名前のカードを同じ効果の系統として見ます（`effects.stadium_use_history` が (このカードで使った, 同じ名前の別のカードで使った) を返す）。
  名前の違うスタジアムの使用は数えません。
- **既存の処理の修正（意図した変更）**: v0.73 までのセキチクシティジム（`CoinReturnOwnerPokemonStadium.check_activation`）は、この番に「どの記録でも」1 件あれば FG1 で止めて
  いました（v0.73 までは、記録を残すのがセキチクシティジムだけだったので問題にならなかった）。v0.74 から、同じ名前（セキチクシティジム）の別のカードで使った記録があるときだけ
  FG1 で止めます。ラッキースタジアム → セキチクシティジム、セキチクシティジム → エネルギースタジアム、エネルギースタジアム → キョウの忍者ジムのような、名前の違うスタジアムへの
  入れかえのあとの使用は止めません。セキチクシティジム A → セキチクシティジム B の FG1 は解決していません（そのまま止める）。
- 同じカードの 2 回目（「自分の番ごとに1回」）は `STADIUM_ALREADY_USED`（`IllegalActionError`）。コインの「うら」でも使ったことになります。
- 同じ名前の別のカードに入れかわったあとの再使用（ラッキースタジアム・エネルギースタジアム・キョウの忍者ジム）は、回数をプレイヤー・名前で数えるかカードで数えるかが印刷の文面・
  kyuura の記録から決まらないので、RS1（`UNRESOLVED_STADIUM_REUSE_AFTER_REPLACEMENT`）で、コイン・状態の変更の前に止めます。セキチクシティジムの FG1 と同じ形の、別のカードの
  問いです（FG1 の答えを当てはめない。どちらも未解決）。
- PRN-027 は日本語の文面に「自分の番ごとに1回」がありません。ほかの版の条件・英語の併記・kyuura の data/curation/other_products.json の `kind: wording`（文面の分類で、回数の裁定
  ではない）で回数を決めず、この番の最初の 1 回は処理し、同じ番の再使用（このカード・同じ名前のほかのカードで使ったあと）は LK1（`UNRESOLVED_LUCKY_STADIUM_UNSTATED_REPEAT`）で止め
  ます。回数の制限があることにも、ないことにも決めていません。PRN-027 を使ったあとに「自分の番ごとに1回」の版に入れかわった場合は RS1 です。
- 確かめる順番は、選ばせるもの（`energy` を指定したら `STADIUM_CHOICE_NOT_USED`）→ 同じカードの 2 回目 → STB1（トレーナーの使用の禁止の下での使用。v0.57 のまま解決しない）→
  RS1・LK1 → 効果ごとの確かめ（EN1・NJ1・GG1）。どれも状態・乱数・ログを変える前です。番のプレイヤーでなければ `NOT_YOUR_TURN`。カードの持ち主でないプレイヤーも、自分の番に
  使えます。番が変われば記録は消え（`procedures.begin_turn`）、また使えます。

## 4. 起動する 3 種類の効果

どれも `UseStadium(player)`（`energy` は使わない）→ ログ `stadium_used` → 記録 → 使ったプレイヤーのコイン 1 枚（`flip_coins` の `source` は `"stadium"`、`effect` はスタジアムの
カード id）の順です。コインはワザの説明文のコインではないので、ナツメのESP（`AttackRun.flip`）のやり直しの対象ではありません。決定からの再開でコインを投げ直しません。

### 4.1 ラッキースタジアム（10 枚）

「おもて」なら使ったプレイヤーが 1 枚引きます（既存の効果で引く処理 `_draw_up_to` → `zones.draw_cards`。p.312。山札が足りなければ引けるだけ、0 枚でも負けではない）。引いた
カードは引いたプレイヤーだけが見て（ログ `draw`）、コインと枚数は公開です。「うら」なら何もしません。決定は出しません。

### 4.2 エネルギースタジアム

- 選べるものは、使ったプレイヤーのトラッシュの基本エネルギーカード（トラッシュにある間の印刷の定義。`CardFilter("basic_energy")`）。レインボーエネルギーなど特殊エネルギー
  カードは選べません（場の外の特殊エネルギーは基本エネルギーカードではない。v0.58 の記録の読み方）。山札・相手のトラッシュも選びません。同じ名前の別のカードは別のカードです。
- 「おもて」なら、候補が 1 枚でも決定を出します（決定 `RETRIEVE_ENERGY`。再開先 `"stadium"`。段階 `energy_stadium`。ちょうど 1 枚。v0.7 のじこさいせいの K2 と同じ方針）。
  選んだカードを見せて手札に加えます（`zones.return_discard_to_hand`。ログ `stadium_retrieve_energy` は公開）。
- トラッシュに基本エネルギーカードがないときに使えるか（コインだけを投げられるか）は、手札から使うトレーナーの使うための条件とは別の問いで、印刷の文面・kyuura の記録から
  決まらないので、EN1（`UNRESOLVED_ENERGY_STADIUM_WITHOUT_TARGET`）でコインの前に止めます（kyuura `UQ-CARD-USE-WITHOUT-TARGET` と同じ形の問い。答えのない決定・内部エラーを
  残さない）。

### 4.3 キョウの忍者ジム

- 選べるものは、使ったプレイヤーの山札の、名前が「キョウの」で始まるたねポケモンのカード（`CardFilter("basic_pokemon", name_prefix="キョウの")`。山札にある間の印刷の定義。
  キョウの進化カード・ほかの名前のたねポケモンは選べない。カード id の固定の一覧で決めない）。uid の小さい順で、山札の並びを決定に写しません。
- 任意なのはコインを投げることで、「おもて」で選べるカードがあれば、ちょうど 1 枚を選びます（決定 `BENCH_FROM_DECK`。段階 `ninja_gym`。0 枚の答えはない）。手札を通さずにベンチへ
  出し（v0.32 の `zones.bench_from_deck` → `enter_play`。場に出た番は今の番で、その番には進化できない。手札から出したことにしない。ログ `stadium_bench_from_deck` は公開）、
  そのあと山札を 1 回切ります（ログ `shuffle` の `stadium_card`）。「うら」なら何もせず、山札も切りません。
- ベンチの上限は `stadiums.bench_limit`（せまいジムとは同時に場にない）。山札に選べるカードがない・山札が 0 枚・ベンチに空きがないときに使えるかは、印刷の文面に「ベンチに空きが
  ない時、使えない」がなく（ほかのカードの使用の禁止を写さない）、kyuura の記録からも決まらないので、NJ1（`UNRESOLVED_NINJA_GYM_WITHOUT_TARGET`）でコインの前に止めます。
- まきちらせ!ベトベトガスのはたらく間の特殊能力を持つカードは、v0.59 の GG1（選べるが選ぶと止める。どれもそうならコインの前）。場に出たときの特殊能力を持つたねポケモンは写しに
  ないので、来たらエンジンの不具合（`placed_entry_power_guard`。コインの前）。

## 5. ポケモンタワー

### 5.1 共通の問い合わせ

ポケモンタワーは常にはたらくスタジアムで、使う効果はありません。消えるかは、効果がはたらく時点で場のスタジアムから問い合わせます（`effects.discard_to_hand_suppressor`。
印・一覧を状態に持たない）。両方のプレイヤーに同じに当てはまり、プレイヤー・カード id ごとの分岐を `engine.py`・`resolution/` に加えていません。かがくへんかガス・特殊状態では
消えません。別のスタジアムに入れかわる・ワザでスタジアムをトラッシュする（ばくれつ）などで場をはなれたら、そのあとの効果は通常にもどります。消えたら、ログ
`discard_to_hand_suppressed`（公開。出どころは `effect`・`power`・`trainer_card` のどれか）を残します。

### 5.2 経路の一覧

既存の処理から、トラッシュのカードを手札に加える処理（`zones.return_discard_to_hand` の呼び出し）を探し、すべての経路を扱いました。

| 種類 | 経路（効果の型・要素） | 登録 | タワーの下 |
|---|---|---|---|
| ワザ | `RecoverEnergy`（ゴースの「エナジーへんかん」。要素） | PMCG3-029 | 手札に加える要素だけが消える（決定を出さない）。自分への 10 ダメージは残る |
| ワザ | `RecoverTrainer`（化石の秘密のヤドンの「ゴミあさり」。要素） | PMCG3-027 | 超エネルギーのトラッシュ（使うための条件）は残り、取り消さない。手札に加える要素だけが消える |
| 特殊能力 | `ReturnToHandOnKnockOut`（R団のファイヤーの「ふしちょう」） | PMCG5-020 | 効果がすべて消える。使う機会を出さない（下） |
| 特殊能力 | `RecoverPokemonFromDiscardOnEntry`（わるいヤドランの［つりあげる］） | PMCG4-036 | 効果がすべて消える。使う機会を出さない |
| トレーナー | `DiscardFromHandThenRetrieveEnergy`（エネルギー回収と再録・超エネルギー回収） | PMCG1-076・GD1-014・GD4-014・GD6-014・QSG-047・PR1-009 | 効果がすべて消える。PT1 |
| トレーナー | `TakeFromDiscardTrainer` の手札へ（ダウジングマシーン） | PMCG1-087 | 効果がすべて消える。PT1 |
| トレーナー | `DiscardDeckTopThenReturnTypeEnergy`（熱血!） | GD5-021 | 山札の上 3 枚のトラッシュは残る。「炎」を手札に加える部分だけが消える |
| トレーナー | `SearchNamedFromDeckOrDiscard`（化石の発掘） | ES1-035 | トラッシュから手札に加える部分（選べるもの）が消える。山札から選ぶ部分・山札を切ることは残る |

行き先が手札でない、または出どころがトラッシュでない処理は消しません: 場 → 手札（スーパーポケモン回収・ポケモン回収・おくびょう・ようせいのきせき・ヤマブキシティジム）・
トラッシュ → ベンチ（元気のかけら・元気のかたまり・ポケモンの笛・よみがえらせる）・トラッシュ → 山札（夜の廃品回収）・トラッシュ → 山札の一番上（リサイクル・ポケモン再転送・
わるいいたずら）・トラッシュ → 場のポケモンにつける（プラズマ・たいでん）・トラッシュ → 使用中（ナツメのサイキックコントロール）。

- ワザの要素は解決の基盤の要素の並びの中で問い合わせる（`programs.suppressed_discard_to_hand`）ので、相手のワザとして使った（ゆびをふる・ちょうのうりょくでまねた）ワザ・
  再録の登録にも同じに当てはまり、宣言の前の先読み（状態の複製の上の処理）と実際の処理が同じ結果になります（先読みの方式 `derived`・`derived_full`・`legacy` で結果が同じことを
  テストで確かめた）。
- ふしちょう: このカードをトラッシュからとり出して手札に加える効果です（kyuura `CR-PHOENIX-TIMING`・`CR-PHOENIX-RETURN`。印刷の「もどす」だけで場 → 手札と読まない）。消えるのは
  手札に加える部分だけで、きぜつ・ついていたカードのトラッシュ・相手のサイドは変えません。使う機会（`capture_post_knockout` の候補）を出さないのは、効果がすべて消え、使っても
  使わなくても状態が同じだからです（実装上の正規化。「使えない」「使えるが何も起こらない」のどちらかを決めたのではない）。［つりあげる］も同じです（`applicable_entry_power`）。
  どちらも実装の `PowerEffect.discard_to_hand_only` で探します（カード id で分けない）。

### 5.3 部分の効果・使うための条件・使う前の確かめ

- 熱血!: ポケモンタワーの下では、レインボーエネルギーを「炎」エネルギーカードとして手札に加えるかを決める必要がないので、FV1（山札・サイドのレインボーエネルギー）で止めません。
  山札が 3 枚より少ない HC6 は別の問いなので、そのまま止めます。タワーのない場面の FV1 は変えていません。
- 化石の発掘: 選べるもの（`candidates`）がタワーの下では山札のカードだけになり、決定・不変条件・ログの出どころが合います（トラッシュのカードを選ぶ答えは `INVALID_CHOICE`）。
- 効果がすべて消えるトレーナー（エネルギー回収・再録・超エネルギー回収・ダウジングマシーン）を、使えるか（使うための条件だけを払って使い終われるか）は、効果の消滅とは別の
  使用の問いで、2000.02.14 版の公式ルール・印刷の文面・kyuura の記録（`UQ-CARD-USE-WITHOUT-TARGET` と同じ形。まだ決まっていない）から決まりません。PT1
  （`UNRESOLVED_POKEMON_TOWER_TRAINER_WITHOUT_EFFECT`）で、手札から出す前（使うための条件の `IllegalActionError` の確かめのあと）に状態を変えずに止めます。「使用禁止」にも
  「使えるが何も起こらない」にも決めていません。タワーのない場面のカード全体は対応のままです。ナツメのサイキックコントロール・錯乱ジムで借りて使う場面も、同じ確かめ
  （`check_playable`）で選ぶと止める選択になります。
- ワザは、効果が消えても宣言できます（必要なエネルギー・使うための条件は今までどおり。消えるのは手札に加える要素の効果）。
