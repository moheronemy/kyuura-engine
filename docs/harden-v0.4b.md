# 「かたまる」（v0.4b）: トランセル・コクーンの原典照合と実装

v0.4b で対応した 1 進化ポケモン 2 枚（トランセル・コクーン）と、そのワザ「かたまる」「しびれごな」「どくのこな」を、『ポケモンカードオフィシャルブック2000』のカードのページと照合した記録です。持続する効果の規定は [persistent-effects-v0.4b.md](persistent-effects-v0.4b.md)、ダメージ計算との関係は [persistent-damage-v0.4b.md](persistent-damage-v0.4b.md)、設計は [architecture-v0.4b.md](architecture-v0.4b.md) にあります。照合の記録は `kyuura_engine/data/card_verification.json`。

- 照合の方法: Internet Archive のスキャン [J38] の PDF をページ画像（300dpi）にして目で読んだ（2026-10-12）。カードの図版（左上の進化の印・「○○から進化」・タイプ・ワザ・にげる・弱点・抵抗力）と、左の「ワザ」欄の「最新の説明」、右の解説を読んだ。
- kyuura の参照コミット: `ecb2d694e6280ec5dc9ddd2a8f709cea16a6b691`（data/cards.json）。写しは `python3 scripts/extract_kyuura_cards.py --kyuura ../kyuura` で作り直し、`pool_v0_4b` を加えた。

## 4. 「かたまる」の文面（印刷の文面と最新の説明）

| | 文面 | 出典 |
|---|---|---|
| 印刷の文面（kyuura の写し `text.ja`。図版と同じ） | 「コインを投げて「おもて」なら、次の相手の番にうけるダメージが0になる。」 | kyuura `ecb2d694`（ja_text_source なぞのばしょ）、p.18・p.21 の図版（読点はこの画像では読み取れない） |
| 最新の説明（実装がしたがう `play_text_ja`） | 「コインを投げて「おもて」なら、次の相手の番、このカードはダメージを受けない。（ダメージ以外の効果は受ける）」 | p.18・p.21 の「ワザ」欄。p.236 のワザ解説の「まるまる」の説明と同じ文面 |

違い: 「ダメージが0になる」→「ダメージを受けない」、「（ダメージ以外の効果は受ける）」を加えた。p.6 の凡例により、処理は最新の説明にしたがう（v0.2b からの方針。ディフェンダー・プラスパワーと同じ）。

- 「ダメージを受けない」は、p.321 の「ダメージを受けない」状態（そのポケモンにダメージを与えるワザの要素は無効、ダメージ以外の効果の要素は有効）にあたる（[persistent-damage-v0.4b.md](persistent-damage-v0.4b.md) 3 章）。印刷の文面の「ダメージが0になる」を、計算した結果を 0 にする（ダメージ計算の 8 段階のどれか）と読む実装はしない。
- 「（ダメージ以外の効果は受ける）」は、p.321 の「ダメージ以外の効果をもたらす「ワザの要素」も有効」と同じ（CONFIRMED）。
- kyuura の記録には、印刷の文面と最新の説明を区別した記録（エラッタの記録）がない。kyuura 側で記録する事項として報告する（[data-provenance.md](data-provenance.md)。誤りとは決めない）。
- 英語版の文面（kyuura の `text.en`「prevent all damage done to Metapod during your opponent's next turn. (Any other effects of attacks still happen.)」）は、日本語版の処理を決める根拠にしない（CLAUDE.md）。

## 5. 「かたまる」の処理（`effects.PreventDamageOnHeads`）

p.309 のワザを使う手順にしたがう。

| 順 | 処理 | 根拠 | 実装 |
|---|---|---|---|
| 1 | ワザを使えなくする状態の確認（ねむり・マヒなら宣言できない） | p.309・p.311・p.322 | `POKEMON_ASLEEP`・`POKEMON_PARALYZED`（v0.3b。コインの前） |
| 2 | 必要なエネルギー（無色 2） | p.309 | `INSUFFICIENT_ENERGY`（コインの前） |
| 3 | 宣言（ログ `attack`） | p.309 | |
| 5 | こんらん状態なら、持ち主がこんらんのコインを投げる。「うら」ならワザがこんらんし、自分に 20（弱点・抵抗力だけ）。「かたまる」のコインは投げない | p.309 の手順 5・p.322 | `engine._confusion_check`（v0.3c） |
| 6 | 説明: コインを 1 枚投げる（`source: "attack"`）。「おもて」なら、次の相手の番（今の番 + 1）にはたらく `PreventDamage` を自分に与える（ログ `persistent_effect_added`）。「うら」なら何もしない | 最新の説明・p.236 | `PreventDamageOnHeads.resolve` |
| — | ワザを使ったことになり、番は終わる → 番の終わり → ポケモンチェック → 相手の番 | p.309・p.323 | `_finish_attack` → `_end_turn` |

- 「うら」はワザの「失敗」（p.323「12」）ではない（説明に「失敗」とは書かれていない）。どちらでもワザは使ったことになる。
- 「うら」でも、今ある持続する効果は消さない（説明にない。p.323）。ただし、「かたまる」の効果は使った番の次の番の終わりに消えるので、次に「かたまる」を使える自分の番には残っていない。
- ダメージの目安の数字がないワザ（`damage` が None）だけを登録できる（`check`）。ダメージの要素がないので、ダメージ計算もログ `damage` もない（v0.3b の「キノコのほうし」と同じ）。

## 6. 防御効果

効果がはたらく番（「次の相手の番」）の間、このポケモンにダメージを与えるワザの要素は無効（p.321）。

- 無効になるのは、このポケモンへのダメージの要素だけ。ほかのポケモンへのダメージの要素（ピカチュウの「でんげき」の自分への 10）・ダメージ以外の効果の要素（どく・マヒ・こんらん・ねむり）は有効（p.321・最新の説明）。
- ダメージを計算しない（弱点・抵抗力・プラスパワー・ディフェンダーも計算しない）。ログは `damage` ではなく `damage_prevented`（防いだ量は計算しないので書かない）。
- ポケモンチェックのどくのダメージは受ける（p.323・p.236）。
- 効果がはたらく番に勝敗が決まったら、番の終わりが来ないので、効果は終わった状態に残る（余計な処理・コインはない）。

## 7. 追加効果（ダメージ以外の効果は受ける）

| ワザ（相手） | 実装 | 「ダメージを受けない」ポケモンに使ったとき |
|---|---|---|
| どくばり（ビードル）・どくのこな（コクーン） | `PoisonOnHeads` | ダメージの要素は無効 → コイン → 「おもて」ならどく状態 |
| いとをはく（キャタピー）・しびれごな（トランセル）・れいとうビーム（ジュゴン） | `ParalyzeOnHeads` | ダメージの要素は無効 → コイン → 「おもて」ならマヒ状態 |
| あやしいひかり（ロコン） | `ConfuseOnHeads` | ダメージの要素は無効 → コイン → 「おもて」ならこんらん状態 |
| キノコのほうし（パラス・パラセクト） | `PutToSleep` | ダメージの要素がないので、ねむり状態になる |
| でんげき（ピカチュウ） | `SelfDamageOnTails` | 相手への要素は無効 → コイン → 「うら」なら自分に 10（有効） |
| みだれづき（ドードー） | `CoinFlipDamage` | **原典で決められない**ので、コインの前に止める（`UNRESOLVED_PREVENTED_COIN_DAMAGE`。[persistent-damage-v0.4b.md](persistent-damage-v0.4b.md) 5 章） |
| 説明のないワザ（かみつく など） | `DamageOnly` | ダメージの要素は無効。ほかに何も起こらない |

- 効果がなければ HP 以上のダメージできぜつする場合、v0.3a からの実装は、きぜつした相手への効果の要素を無視する（コインを投げない）。効果があればダメージの要素は無効で、きぜつしないので、コインを投げる（テスト `test_near_knock_out_coin_is_not_skipped`）。
- 「ダメージを与えたときだけ」起こる効果（バタフリーの「メガドレイン」など）は、ダメージの要素が無効なら起こらないと読めるが、そのワザは対応していない。加えるときは、効果の発生条件に「ダメージを与えた」が含まれるかを、カードごとに照合する（v0.4b の追加効果と同じ扱いにしない）。
