### 推奨する次の 1 単位: R1（［めいれい］）の限定提示

**提示の条件（すべて満たすとき）:**
- 番のプレイヤーの main で、本人のバトル場のポケモンがうら（呼び出し元の条件）。
- 本当のカード（`printed_def(active.card)`）が特殊能力を持たない（0.188.0 と同じ）。
- 自分の場のおもてのポケモンが `CommandBonusToNamedAttackers` の力を持つ（`group_attack_power_slot`。うらの持ち主は除く）。
- 本当のカードの印刷の名前が、その力の `names` のどれかと完全に同じ（型の値を使う。カード id の一覧を作らない）。
- 持ち主の力が消えていない・使えない効果を受けていない（`power_suppressed`・`powers_use_prevented`。どちらも状態を変えない既存の問い合わせ）。
- 使い手と持ち主が別のポケモン。

**対象外:** ［XXXXX］・［ANGER］・［すいりょくはつでん］、特殊能力を持つ本当のカード、うらの持ち主、持ち主の力が使えない場合。これらは今までどおり示さず、R-2 の residual に残します。

**段と選択肢:**
- 2 段目に、持ち主ごとに 1 つの選択肢を置きます。値と表示はおもての分岐の `_addon_specs` の `with_power` と同じ形で、`addon: with_power`・持ち主の場の表示・力の名前です。
- どのワザにも同じ選択肢を示します（［めいれい］はワザを選ばない）。
- クチバシティジムのコインと同じ段に並べ、並びは今の `_addon_specs` と同じです（コイン → 場の並び）。`count` は 0〜選択肢の数、`order: significant`（選んだ順に宣言）、`distinct`・`decline` は今の宣言の契約のままです。
- 同じ力（`exclusive_key` が同じ）の 2 匹は同時に選べない形の制約として、検査が拒否します（公開の値だけで決まる）。

**区分:**
- 選択肢・候補は `unverified`、理由は `face_down_reveal_not_evaluated` のままにします。
- `eligible` は条件を満たしたものだけに付けます（満たさないものは出さない）。

**check と submit:**
- check は形だけを確かめます（ワザの番号 1 つ、そのあとに示したものを重ねず、同じ力を 2 つ選ばない）。エンジンの確かめ（`check_use_attack`）は呼びません。valid でも受理・力の使用は保証しません。
- submit はエンジンの今の順のままです（公開 → たねでなければトラッシュして受理 → `check_use_attack`（`group_attack_powers_check`）→ 先読み → 処理）。拒否のときは状態・乱数・ログが変わりません。

**欠落・矛盾:**
- 印刷の名前が読めない（定義がない）・持ち主の力の型がこの型でない場合は示しません。
- 公開のあとに姿が変わりうるカードは、特殊能力の除外で対象外です。
- 保証の文（`GUARANTEE_FACE_DOWN_ATTACK`）と R-2 の note は、［めいれい］を示す場合に合わせて直します（固定値の更新は、原因を記録してから）。
