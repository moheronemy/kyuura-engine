# ベトベター・ベトベトンのワザの原典の照合と裁定（v0.8）

v0.8 でベトベトン（PMCG3-007）を対戦で使えるようにするために、進化元のベトベター（PMCG4-004。ポケモンカード第4弾ロケット団）と、2 枚のワザを『ポケモンカードオフィシャルブック2000』[P43] で確かめた記録です。ベトベトンのポケモンパワー「かがくへんかガス」は [chemical-gas-v0.8.md](chemical-gas-v0.8.md)、設計は [architecture-v0.8.md](architecture-v0.8.md)。照合の記録は kyuura_engine/data/card_verification.json の PMCG4-004・PMCG3-007・PMCG3-003。テストは tests/test_grimer_line_v0_8.py。

## 1. 確かめ方

- 300dpi の画像を目で読み、カードの図版の説明文は 600dpi で拡大した（OCR はページの位置を探すのに使っただけ）。
- kyuura の写しにあるベトベターは 2 枚（化石の秘密 PMCG3-003・ロケット団 PMCG4-004）。進化は名前で決まる（p.310「○○から進化」）ので、どちらからでもベトベトンに進化できる。v0.8 で対応にしたのはロケット団のベトベターだけ（2 章）。
- 照合したのは見出しの収録商品が合うカードだけ。同じページのキョウのベトベター（ジム拡張第2弾）・わるいベトベトン（ロケット団）、p.49 のキョウのベトベトンは別のカードで、代わりにしていない。
- 使わなかった資料: 英語版の文面（kyuura の `text.en`。ロケット団のベトベターの「どくガス」の英語の文面は「The Defending Pokémon is now Asleep.」で、日本語の文面（どく）と違う。報告事項）、後年の英語版の規定、現代のルール。

図版の説明文（印刷の文面）: ロケット団のベトベターは「ワザ」欄と同じ（kyuura と同じ）。ベトベトンの「ヘドロこうげき」は「コインを投げて「おもて」なら、相手を「どく」状態にする。」（読点はかすれている。kyuura と同じ）。化石の秘密のベトベターの「ちいさくなる」は「次の相手の番でこのカードが受けるダメージは20へる。（ダメージ以外の効果はそのまま）」で、最新の説明と違う（kyuura の写しは印刷の文面）。

解説（処理に関わる記述）: ロケット団のベトベター「「どくガス」は、コイントスなしで相手の対戦ポケモンを必ずどく状態にします。「ねばりつく」はコイントスで表を出せば相手をマヒ状態にします。」「…次の自分の番に草エネルギーを1個追加して「ねばりつく」。コイントスで表を出せて、相手の対戦ポケモンがどく状態を回復していなければ、どくとマヒ状態のまま、6個のダメージカウンターがのっている状態で、相手プレーヤーは3回目の番を迎えることになります。」（どくの 10 × 3 回と「おもて」のねばりつく 30 で 6 個。「おもて」なら 10 + 20 = 30 と合う）。ベトベトン「特殊能力を封じつつ、自らバトル場に立っても強い「ベトベトン」です。」。

kyuura の記録（段階・進化元・HP・タイプ・弱点・抵抗力・にげる・ワザの名前・エネルギー・ダメージ・LV）は、3 枚とも、この本と同じ。エラッタの記録はない。

化石の秘密のベトベターを対応にしなかった理由: 「ちいさくなる」は、ワザによって受けるダメージを次の相手の番に減らす持続する効果（p.322・p.323）で、p.321 の 8 段階（ワザを受けるポケモンのダメージを変える効果）にあたると考えられる。v0.8 では持続する効果の新しい型（期限・消える契機・書き出し・不変条件）を加えていない（v0.8 の範囲はかがくへんかガス）。カードの分類（cards.py）が「ちいさくなる」の実装がないことでデッキに入れない（`test_fossil_grimer_is_a_reference_card`）。

## 4. 印刷の文面と最新の説明の違い

- ロケット団のベトベター・ベトベトンのワザ: 印刷の文面と最新の説明は同じ。
- 化石の秘密のベトベターの「ちいさくなる」: 印刷の文面「次の相手の番でこのカードが受けるダメージは20へる。（ダメージ以外の効果はそのまま）」に、最新の説明は「ワザによって受けるダメージ」「「-20」される」と書く（実装していない）。

kyuura の記録に、印刷の文面と最新の説明を区別した記録がないこと、ロケット団のベトベターの英語の文面（`text.en`）の「どくガス」が日本語の文面と違うこと、ja_text_source の URL（nazonobasho の pmcg04-008・pmcg03-006）の番号が kyuura の id の番号（004・007）と違うことは、報告事項として [data-provenance.md](data-provenance.md) に書いた（誤りとは決めない。kyuura は変更していない）。
