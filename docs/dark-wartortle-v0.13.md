# わるいカメールと第4弾のゼニガメの照合（v0.13）

v0.13 で、次の 2 枚を対戦で使えるようにするために照合した記録です。

- わるいカメール（PMCG4-021）
- 第4弾のゼニガメ（PMCG4-018）

どちらも、ポケモンカード第4弾 ロケット団のカードです。

関連する文書:

- ワザ「こうらがえし」の裁定: [shell-attack-v0.13.md](shell-attack-v0.13.md)
- 仕組み: [variable-retaliation-v0.13.md](variable-retaliation-v0.13.md)
- 設計: [architecture-v0.13.md](architecture-v0.13.md)

## 1. 確かめ方

- 資料: 『ポケモンカードオフィシャルブック2000』[P43]（Internet Archive の PDF。J38）
- 方法: ページを 300dpi の画像にして読んだ。カードの図版と最新の説明は 600dpi で拡大した。
  - p.88（PDF 90）: 第4弾のゼニガメ
  - p.89（PDF 91）: わるいカメール
- OCR の文字は、ページの位置を探すのに使っただけです。印刷物の実物とは照合していません。
- カード id は kyuura の記録で確かめた（PMCG4-021・PMCG4-018）。
  - kyuura の id の番号は図鑑番号ではありません（PMCG4-021 の `pokemon.dex` は 8、PMCG4-018 は 7）。
  - PMCG4-008 はわるいアーボックで、別のカードです。
- 照合の対象外:
  - 第1弾のカメール（PMCG1-027）・ゼニガメ（PMCG1-023）: v0.6 で照合ずみ
  - 後年の同じ名前のカード
  - わるいカメックス（PMCG4-024。ワザは範囲外）

## 3. 第4弾のゼニガメ（PMCG4-018）

| 項目 | p.88（図版・見出し） | kyuura の写し | 一致 |
|---|---|---|---|
| 名前・段階 | 「たねポケモン ゼニガメ」 | ゼニガメ・basic | 同じ |
| LV・HP | LV.16／HP50 | 50 | 同じ |
| タイプ | 水 | water | 同じ |

| にげる | 無（1） | 1 | 同じ |
| ワザ | こうらアタック（無無）20 | 「こうらアタック」colorless×2・20・説明文なし | 同じ |
| 「ワザ」欄 | 「●こうらアタック」（説明文なし） | text なし | 同じ |
| 収録 | 「ポケモンカード第4弾ロケット団」 | PMCG4 | 同じ |

p.88 の解説:

- 「この「ゼニガメ」は、無色2個エネルギーカードと相性がぴったりです。」
- 「「カメール（第1弾）」に進化すれば、すぐに「かみつく」が使えますし、「ポケモン育て屋さん」で1進化をとばして「わるいカメックス（ロケット団）」に進化すれば、…」
- 「水タイプを入れた多色デッキにこの「ゼニガメ」を入れるときは、同時に第1弾の「カメール」も入れましょう。」

別の弾の同じ名前のカードに進化できることは、p.310 の規定（「○○から進化」は名前で決まる）どおりです（[shell-attack-v0.13.md](shell-attack-v0.13.md) の S44）。v0.4a からの進化の処理（名前の照合）は変えていません。

- 第4弾のゼニガメからは、わるいカメール（PMCG4-021）と第1弾のカメール（PMCG1-027）に進化できます。
- 第1弾のゼニガメからも、わるいカメールに進化できます。
- ポケモン育て屋さん・わるいカメックスは範囲外です。
- デッキの「ゼニガメ」は、合わせて 4 枚までです（p.308）。

## 4. ワザの文面（印刷の文面と最新の説明）

| ワザ | 図版（印刷の文面。kyuura の写し） | 「ワザ」欄（最新の説明。p.89） | 違い |
|---|---|---|---|
| おうふくびんた | 「コインを2枚投げて「おもて」の数×10のダメージ。」 | 「コインを2枚投げ、「おもて」の数×10のダメージ。」 | 書き方だけ（v0.2d のドードーの「みだれづき」と同じ最新の説明） |
| こうらがえし | 「次の相手の番で、このカードが相手のワザによってダメージを受けた時、(このカードが「きぜつ」するしないにかかわらず、)そのポケモンにも同じダメージを与える。(ダメージ以外の効果は与えない)」 | 「次の相手の番、このカードが相手のワザによってダメージを受けたとき、（それによってこのカードが「きぜつ」しても、）そのポケモンにも同じダメージを与える。（ダメージ以外の効果は与えない）」 | 「次の相手の番で／次の相手の番」「受けた時／受けたとき」「きぜつ」の書き方。意味は同じと読める |

処理は最新の説明にしたがいます（p.6。`AttackEntry.play_text_ja`）。kyuura の写しの値は、登録の照合（`AttackEntry.text_ja`）にだけ使います。

照合の記録は kyuura_engine/data/card_verification.json です。

- PMCG4-021: `status`「不一致あり」。印刷の文面と最新の説明の違いを `mismatches` に 2 件、`card_image_text_ja`・`latest_description_ja` をワザの位置ごとの辞書で書いた。
- PMCG4-018: `status`「一致」。

## 5. 登録

| ワザ | 登録（kyuura_engine/effects.py の `DEFAULT_EFFECTS`。id `kyuura-engine-0.13`） | 根拠 |
|---|---|---|
| 第4弾のゼニガメ「こうらアタック」 | `DAMAGE_ONLY`（`_damage_only` の一覧） | p.88（説明文なし） |
| わるいカメール「おうふくびんた」 | `CoinFlipDamage(coins=2, damage_per_heads=10)`（v0.2d からの実装。コインはワザを使ったプレイヤーが 2 枚。`damage_profile` は 0・10・20） | p.89（[shell-attack-v0.13.md](shell-attack-v0.13.md) の S42） |
| わるいカメール「こうらがえし」 | `ReturnReceivedDamage()`（v0.13 の新しい実装。ダメージなし・コインなし。自分に `Retaliation(basis=received_damage)` を与える） | p.89・p.321（S1〜S49） |

おうふくびんたは、相手が「ダメージを受けない」状態（かたまる・からにこもる）なら、v0.4b の `UNRESOLVED_PREVENTED_COIN_DAMAGE` で止めます（みだれづき・ダブルニードルと同じ。既存の未解決の裁定）。

抽出の対象は scripts/extract_kyuura_cards.py の `POOL_V0_13`（`["PMCG4-018", "PMCG4-021"]`）です。写しを作り直し、`--check` で確かめました。参照する kyuura のコミットは `ecb2d694e6280ec5dc9ddd2a8f709cea16a6b691` のままです。カードの組の名前 `pool_v0_13` は kyuura_engine/cards.py の `POOL_KEYS` に加えました。
