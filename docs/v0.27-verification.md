## 3. 変異（作業用のスクリプト。リポジトリには入れていない）

写しの木で誤りを 1 つずつ入れ、新しいテスト 2 ファイルを走らせました（元にもどして成功することも確かめた）。

最初の実行では、12 の変異のうち 2 つを見逃しました。

1. 「その数にする」を「2 倍にする」に変えたもの
   - 「きりさく」の 1 段階はいつも 30 なので、対戦の結果では区別できませんでした。
   - 1 段階が 10・20・40・50 のときの計算を確かめるテストを加えました。
2. 不変条件のはたらく番の確かめを外したもの
   - 違反の盤面が期限の確かめでも見つかっていたので、見逃しました。
   - 期限が過ぎていない盤面（はたらく番 = 与えた番 + 3）で、はたらく番の確かめの文を確かめるようにしました。

直したあと、12 のすべてでテストが失敗しました。

| 変異 | 結果 |
|---|---|
| 2 段階で 2 倍にする（印刷の文面） | 失敗（見つかった） |
| 2 段階で 60 を加える | 失敗 |
| 8 段階（最終ダメージ）で 60 にする | 失敗 |
| はたらく番を次の相手の番（+ 1）にする | 失敗 |
| ワザの位置を見ない（ほかのワザも変える） | 失敗 |
| 先読み（`preview_attack_damage`）に効果を数えない | 失敗 |
| にげても持続する効果を消さない | 失敗 |
| 期限で消さない | 失敗 |
| 同じ段階の重なりを止めない | 失敗 |
| 登録の位置を確かめない | 失敗 |
| 不変条件のはたらく番を見ない | 失敗 |
| 書き出しで量を落とす | 失敗 |

## 7. 走らせていない検証

次のものは今回走らせていません。

- 大規模な版の間の比較（v0.18 の 5 章と同じ大きさの `tools/engine_lockstep.py`・`tools/compare_engine_versions.py`）
- 全変異試験（`tools/run_mutants.py witness`・`full`）
- 性能の測定
- 複数の Python の版での反復

- 固定した v0.26 との比較（4 章。既存のカードの 290 対戦。2 回）
- 既存の変種と比べる道具の出力の比較
- 関連する回帰テスト
- 12 の変異（3 章）

ストレス実行・比較の駆動（tools/compat_driver.py）にストライクの組は加えていません。正式な対戦は seed 0〜9（席の入れかえで 60 局）だけで、構成・seed をそれ以上探していません。
