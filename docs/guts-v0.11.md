# サカキのカイリキーの「こんじょう」の原典の照合と裁定（v0.11）

v0.11 でサカキのカイリキー（PMCG6-061。ジム拡張第2弾 闇からの挑戦）のポケモンパワー「こんじょう」を対戦で使えるようにするために、『ポケモンカードオフィシャルブック2000』[P43] で確かめた記録です。進化元のサカキのワンリキー・サカキのゴーリキーとワザは [giovanni-machamp-line-v0.11.md](giovanni-machamp-line-v0.11.md)、きぜつの判定ときぜつの処理のあいだに特殊能力の使用を挟む仕組みは [ko-prevention-v0.11.md](ko-prevention-v0.11.md)、設計は [architecture-v0.11.md](architecture-v0.11.md)、確かめた結果は [v0.11-verification.md](v0.11-verification.md) です。照合の記録は kyuura_engine/data/card_verification.json の PMCG6-061（と PMCG6-057・PMCG6-059）。

## 1. 確かめ方と使わなかった資料

- Internet Archive のスキャンの PDF からページを画像にし（300dpi。カードの図版は 600dpi で拡大）、目で読んだ。PDF の文字（OCR）は、ページの位置を探すのに使っただけ（「こんじょう」「きぜつ」「残りHP」「きぜつしない」「ハチマキ」などの語）。PDF のページ = 誌面のページ + 2。
- 照合したのは p.193 の上の「サカキのゴーリキーから進化 サカキのカイリキー LV.50／HP100」「ジム拡張第2弾闇からの挑戦」のカード。第1弾のカイリキー（PMCG1-057。p.192。特殊能力［はんげき］）は名前が違う別のカードで、代わりにしていない。
- 「こんじょう」の解説は p.193 の解説と、p.285 の「サカキの切り札」の解説の一文だけ。公式ルール（p.323「14 ポケモンの特殊能力」）に［こんじょう］の例はない。使うかを決める一般規定は p.311「ポケモンの特殊能力を使う」。同じ形の発動条件・特殊能力の解説を探して使った: p.100（カスミのドククラゲの［にげこむ］。「…ダメージを受けたとき、使える」と、使うかを言ってから使う解説）、p.82（R団のファイヤーの［ふしちょう］。「きぜつ」したとき、使える）、p.188（タケシのオコリザルの［ずらかる］。「残りHPが「10」になったとき、かならずはたらく」）、p.192（カイリキーの［はんげき］。「はたらかない」）、p.309（ワザを使っている最中に特殊能力の使用を宣言してはいけない・処理の対象がいなくなった内容は無視）、p.319〜p.324。
- 当時の公式の Q&A・訂正は、ウェブの検索（「サカキのカイリキー こんじょう 裁定 旧裏 きぜつ コイン」「"こんじょう" "サカキのカイリキー" ポケモンカード Q&A」）では見つけられなかった（見つかったのは中古の販売ページと、名前に「こんじょう」を含む現代の別のカード「こんじょう!カイリキー」だけ）。この本の最新の説明と解説を当時の公式の説明として使った。
- 使わなかった資料: 英語版の文面（kyuura の `text.en`。「If Giovanni's Machamp would be Knocked Out by an opponent's attack, flip a coin. …」。日本語版の「使える」に当たる語がない）、後年の規定・現代の「特性」のルール、ポケモン本編の特性「こんじょう」（名前が同じだけで別のもの）、現代のカード「こんじょう!カイリキー」。

## 3. 印刷の文面と最新の説明の違い

印刷の文面（kyuura の写し）と最新の説明（p.193）の違いは「する時／するとき」「受ける時／受けるとき」「残りHPは／が」の表記だけで、意味は同じと読める。p.6 により最新の説明にしたがう（`PowerEntry.play_text_ja`）。kyuura の写しの値は登録の照合（`PowerEntry.text_ja`）にだけ使う。

v0.10 のカイリキー［はんげき］（印刷の文面「かならず…あたえる」、最新の説明「はたらかない」）・p.188 の［ずらかる］（「かならずはたらく」）と違い、［こんじょう］は印刷の文面も最新の説明も「使える」「使えない」と書く。

## 4. 裁定（G1〜G42）

分類は次のとおり（v0.10 と同じ）。

- CONFIRMED: 原文がそのまま決めている
- SUPPORTED: 原文と解説から強く支持される。ほかの読み方の余地が小さい
- UNRESOLVED: 原文で決められない（エンジンは推測で処理せず止める）

「実装上の仮定」は、規定ではなく実装の都合で決めたこと。「未到達」は、規定は確かめたが v0.11 の対応カードでは起こらないこと。テストは tests/test_guts_v0_11.py（盤面を直接作る）・tests/test_giovanni_games_v0_11.py（自然な対戦）・tests/test_unresolved_boundaries_v0_4e.py（G37 の止まる場合と隣の場合）。

### 4.7 A4〜A6 の論点

**A4 任意使用（最重要）。** 最新の説明は「…きぜつするとき、使える」で、使用を宣言する特殊能力の書き方をしている（G1）。宣言する特殊能力は、p.311 の一般規定で、宣言するかをプレイヤーが決める（G10）。同じ形の［にげこむ］（p.100）の解説が、ダメージを受けたときに使う特殊能力でも使うかどうかを選べることを書いている。したがって:

- プレイヤーが使うかを選べる（エンジンは選ばない。決定 `KO_PREVENTION` で持ち主が答える）。
- 条件を満たせば必ずコインを投げるのではない（使うと答えたときだけ投げる）。
- 使わないという選択が認められる（選ばない = 使わない。`ko_prevention_declined`）。
- 選ぶのは、ワザの要素をすべて処理したあとのきぜつの判定（G2・G12）。
- 選ぶ前に確定しているのは、ワザのダメージと効果・ワザのコイン・「はんげき」・HP 以上になったこと。コインの結果は確定していない（乱数を使っていない）。

**A5 きぜつ防止とダメージの無効化の違い。** こんじょうは「ダメージを受けた結果のきぜつを防ぎ、残り HP を 10 にする」（G21・G22）。「ダメージを受けない」状態（v0.4b の「かたまる」。p.321 でダメージの要素が無効）・「とうめい」（v0.9。ダメージと効果を受けない）とは違う:

| | こんじょう | 「ダメージを受けない」（かたまる） | とうめい |
|---|---|---|---|
| ダメージの要素 | 処理する（ダメージをのせる） | 無効（計算しない） | 受けない（のせない） |
| ログ `damage` | ある（最終ダメージ） | なく `damage_prevented` | なく `attack_evaded` |
| 与えたダメージ（メガドレイン） | 最終ダメージ | 0 | 0 |
| ダメージを受けたときの特殊能力（はんげき） | はたらく（こんじょうより前） | はたらかない | はたらかない |
| きぜつ | 防ぐ（残り HP 10） | ダメージがないので起こらない | 同左 |
| 時点 | ワザのあとのきぜつの判定 | ダメージの要素 | ダメージの要素 |

**A6 ほかのきぜつ防止の効果。** この本（2000.02.14 版のルールの範囲）の OCR で「ハチマキ」「きぜつせず」「残りHP」を探した。見つかったのは、こんじょう（p.193・p.285）と、きぜつを防ぐのではない効果（p.188 の［ずらかる］「残りHPが「10」になったとき、かならずはたらく」・p.206 のカブトアーマーの解説「残りHP10できぜつしなくてすみます」（ダメージを半分にする効果の結果））だけ。kyuura の写しの元データ（ecb2d694）には「きあいのハチマキ」（neo1-088。「金、銀、新世界へ...」）があり、文面は「相手のワザによるダメージで、このカードをつけているポケモンの残りHPがなくなったとき、コインを投げる。「おもて」なら、このカードをつけているポケモンは「きぜつ」せず、このカードをつけているポケモンの残りHPは「10」になる。その後、このカードをトラッシュする。」（「使える」がない。自動的にはたらく書き方）。ネオの商品はこの本・2000.02.14 版のルールの範囲の外で、照合していない。実装していない。将来の注意: 同じきぜつの判定で、こんじょう（任意・持ち主が宣言）ときあいのハチマキ（自動）が両方当てはまる場合の順番・片方で生き残ったあとにもう片方を使えるかは、原典で確かめるまで決めない（G16 と同じく宣言の前に止める）。ナツメのユンゲラー（PMCG6-047）の「ライフダウン」（残り HP が 10 になるようにカウンターをのせる）は、きぜつを防ぐ効果ではない。
