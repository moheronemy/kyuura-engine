# v0.96: アンノーン 7 枚と遺跡の石版 2 枚

v0.96 は、アンノーン 7 枚（アンノーン[E] PF2-002、アンノーン[O] PF2-003、アンノーン[R] PRN-035、アンノーンL neo4-050、アンノーンS neo4-051、アンノーンT neo4-052、アンノーンZ

評価していません。

## 2. 「アンノーン」の名前のグループとデッキの規定

- ルール文の読み方: ポケモンのルール文が「「G」はデッキにN枚までしか入れることができません。」の全文で、そのカードの名前が「G」と文字の書き方（「アンノーンT」の英字 1 文字・「アンノーン[O]」の
  角かっこの英字 1 文字）だけでできているときに、グループの名前（`CardDefinition.name_group`。「アンノーン」）・文字（`name_letter`。"T"・"O"）・グループの上限（`deck_group_limit`。4）を
  持ちます（`cards._deck_group_rule`・`_name_letter`）。名前・id・文面は書き換えません。ほかの書き方（全角の英字・2 文字・記号・グループの名前で始まらない名前）は文字と読まず、ほかの規定の
  ルール文のあるポケモンは今までどおり未対応です（ルール文の確かめを緩めない）。v0.82 の「このカード自身の名前の 1 枚まで」（ひかるポケモン）は別の欄（`deck_limit`）のままです。
- 同じ写しの後処理（`cards._with_name_groups`）: どれかのカードのルール文が上限を書くグループについて、名前がそのグループの書き方のポケモンのカードに、グループの名前と文字を加えます
  （ルール文のない文字のカードもグループのカードとして数えるため。今の写しにはない。上限はそのカード自身のルール文が書くときだけ）。テスト専用の写し（ルール文のない「アンノーンI」）で
  確かめました（`NameGroupTest.test_cards_without_the_rule_text_still_belong_but_do_not_declare`）。ルール文のないアンノーン（I・D・F など）を例外にする・対応にすることはしていません。
- デッキの検査（`deck.deck_problems`）: デッキのどれかのカードのルール文が書いた上限を、そのグループのカード（文字の違うカード・ルール文のないカードを含む）を合わせた枚数に当てはめます
  （`TOO_MANY_GROUP_COPIES`）。印刷の定義で数えるデッキの規定で、場のポケモンの数の制限ではありません。同じ名前の 4 枚（p.308）・ひかるポケモンの 1 枚・書き方の違う同じ名前（v0.71 の
  ポケモン図鑑 HANDY505）は今までどおり別に数えます。4 枚（E・O・L・Z）は通り、5 枚（E・O・R・L・Z）は拒否します（`DeckLimitTest`）。遺跡の石版は「アンノーン」ではありません。
- 2002-05-24 の Q&A の「ポケボディー」の一覧（kyuura data/rule_history.json の MIX-POWER-ERRATA。アンノーンZ を含む）と、P39・P40（2000年7月・9月の誌面の「アンノーンはデッキに4枚まで」）は、
  2000.02.14 版の根拠にしていません。上限の根拠は各カードの印刷のルール文です。

## 3. 場の「アンノーン」と今の姿

- 「自分の場の「アンノーン」」は、場のポケモンの今の姿のカードの定義（`effects.form_def`。「ばける」・［へんしん］）の名前のグループで決めます（`effects.in_name_group`）。［へんしん］のメタモンの
  相手のバトル場がアンノーンなら「アンノーン」として回復し（［REASSURE］）、「にげる」のエネルギーがなくなります（［ZOOM］）。デッキの検査ではメタモンのまま（数えない）です
  （`DeckLimitTest.test_field_uses_the_current_form`）。
- うらのカード（マチスの秘策）の名前のグループ・文字・上限は、名前と同じく読めません（`FACE_DOWN_HIDDEN_FIELDS`。読むと FD1）。見えない本当のカードの名前を読みません。
- 山札・手札のカードは印刷の定義で決めます（遺跡の石版の選べるカード。`CardFilter` の `name_group`。名前の完全一致 `name` では「アンノーンT」が入らないので使わない）。

## 4. 手札から場に出したときの特殊能力（［ENGAGE］・［REASSURE］）

- どちらも「このカードを手札から場に出したとき、1回だけ使える」（v0.43 の `EntryPower`。`from_hand_only`）。使う機会は、手札からベンチに出す操作と、トレーナーの効果で手札から場に出したとき
  （エリカの香水・マチス。v0.86 の経路）だけで、持ち主が使うかを決めます（決定 `entry_power`）。遺跡の石版で山札から出したとき・「ばける」・［へんしん］で姿が変わったときは機会がありません。
  機会が過ぎたあとに宣言しても `POWER_NOT_USABLE_NOW` です。かがくへんかガスなどで消えていれば機会はありません（共通の確かめ）。
- エリカの香水（番のプレイヤーが使う）で相手の手札から出させられたアンノーン[E] は、持ち主（番でないプレイヤー）に機会があり、使えば持ち主 → 番のプレイヤーの順に決めます。この経路の
  特殊能力の途中の決定を、持ち主の番でないまま続けられるように、決定の整合性の確かめ（`engine._power_decision_problems`）を、もとの事実がそのトレーナーの `trainer_bench_from_hand` で、
  最後の宣言がその機会の答えのときだけ広げました（`engine._opponent_entry_followup`。ほかの決定に広げない。OT1 は［おたけび］だけの問いのまま）。
- ［ENGAGE］: 使ったら、使ったプレイヤー → 相手プレイヤーの順に、それぞれのプレイヤーが自分で手札をもどすかを決めます（決定 `accept_request`。選べるものは 1。0〜1 個。`context` の
  `"stage"`。相手の分は相手が決め、1 つの答えを両方に当てはめない）。もどすなら、手札をすべて見せずに山札の一番下にもどし（`zones.return_hand_cards_to_deck` の `power`。もどす位置はこの
  あと切るので実装上の仮定）→ その山札を 1 回切る → 4 枚引きます（山札が足りなければ引けるだけ。p.312）。そのプレイヤーの処理を終えてから、次のプレイヤーに聞きます（v0.84 の［おくりもの］と
  同じ順番）。もどさないプレイヤーの手札・山札・乱数は変えません（ログ `hand_return_declined`）。手札が 0 枚のプレイヤーの「もどす」は EG1（9 章。選べるが選ぶと止める。「もどさない」は
  いつも答えになる。決定の整合性の確かめに、特殊能力の「のぞむなら」の決定の 0 個の答えを加えた）。再開で、もどす・切る・引くをくり返しません。
- ［REASSURE］: 対象は使ったプレイヤーの場（バトル場 → ベンチ。このカードも）のポケモンのうち、今の姿の名前のグループが「アンノーン」のもの。のっているダメージカウンターをすべてとりのぞき
  ます（のっていないポケモンは効果を受けない・ログを残さない。0 匹でも使える。v0.86 の［いやしのかぜ］と同じ）。特殊状態・マーカー・持続する効果は変えません。相手の場・ほかの名前は
  入りません。ダメージカウンターのないポケモンの名前は読まず、ダメージカウンターがのっているうらのカードがあれば FD1（使うを選ぶと止める。`accept_problem`）です。

## 5. 自分の番ごとに 1 回の特殊能力（［OBSERVE］・［SEARCH］・［LAUGH］・［TELL］）

- どれも宣言して使い、自分の番ごとに 1 回です（`once_per_turn`。宣言のときに記録する。コインの「うら」でも使ったことになる）。日本語の文面にねむり・マヒ・こんらんの条件はないので、
  特殊状態では止めません（`ObserveTest.test_status_does_not_block_but_chemical_gas_does`・`LaughTest.test_status_does_not_block_the_declared_powers`）。特殊能力を消す効果は共通の確かめ
  （`POWER_SUPPRESSED`）です。
- ［OBSERVE］: 相手の山札の上からちょうど 5 枚を見ます（ログ `look_at_deck_top` の `power`。`cards` は見たプレイヤーだけ。山札の持ち主・観戦者には見せない）。「まで」ではなく、並べかえ・
  切ることはしません（並び・乱数は変わらない）。v0.95 のみらいよちの並べかえの決定・［わるぢえ］のコイン・切るかの決定は使いません。相手の山札が 0 枚なら PW3（見るカードがない。v0.47 の
  ［スパイ］・v0.95 の［わるぢえ］と同じ）、1〜4 枚なら OB1（9 章。どちらも宣言の前。山札の枚数は公開の情報）。ちょうど 5 枚なら使えます。
- ［SEARCH］: 宣言のあと自分のサイドの位置を 1 つ選び（決定 `select_prize_card`。v0.47 の［わるふざけ］と同じ形）、そのカードを見ます（`zones.look_at_card` の `"prize"`・`power`。`card` は
  見たプレイヤーだけ）。サイドは動かしません（位置・枚数・並びは同じ）。サイドが 0 枚なら PW3（勝ちが決まっているので自分の番には起こらない）。
- ［LAUGH］: 「おもて」なら、使ったプレイヤーが相手の山札を切り、そのあと相手が使ったプレイヤーの山札を切ります（それぞれ 1 回。ログ `shuffle` の `player` は山札の持ち主、新しい項目
  `shuffled_by` は切ったプレイヤー。持ち主でないプレイヤーが切るときだけ書く）。順番は実装上の順番（説明は順番を書かない。乱数を使う順番だけが変わる）。「うら」なら何もしません。
- ［TELL］: 「おもて」なら、使ったプレイヤーが相手の手札を見て、そのあと相手が使ったプレイヤーの手札を見ます（`zones.look_at_hand` の `power`。それぞれ 1 回。`cards` は見たプレイヤーと
  持ち主だけ。観戦者には見せない。公開する「見せる」ではない）。手札が 0 枚でも見る処理をします。

## 6. ［ZOOM］と「にげる」

- 常にはたらく特殊能力（v0.46 の `ContinuousPower`。宣言しない・使った記録を持たない。`location` はベンチ。説明に特殊状態の条件はない）。このカードが自分のベンチにいるあいだ、自分の
  バトル場のポケモンの今の姿の名前のグループが「アンノーン」なら、「にげる」でトラッシュするエネルギーの数をなくします（`effects.retreat_cost` の新しい欄 `RetreatCost.power_zeroed`。
  (持つポケモンの番号, `PowerKey`)）。相手の場・ほかの名前・バトル場の［ZOOM］のカード自身には当てはめません。はたらいているかは「にげる」のたびに今の場から求めます（かがくへんかガス・
  場所・姿が変わったあとも同じ問い合わせ）。2 匹以上の［ZOOM］がはたらいても重なりません（どれも 0 にするだけ）。
- ふうせんのみ（v0.81。ついているどうぐ）と同じ「すべてなくなる」で、数の読み方（`RetreatCost.readings`。最後に当てはめる 0 と、先に当てはめて増やす・へらす数を当てはめる読み方）を同じに
  使います。ふうせんのみだけの処理には当てはめません: ［ZOOM］だけなら、ふうせんのみのトラッシュ・BB1（こんらんのコインの「うら」）はなく、こんらんのコインは今までどおり投げます。本当の
  ふうせんのみがついていれば、BB1・トラッシュはふうせんのみのものとして今までどおりです（［ZOOM］のカード・ほかのカードはトラッシュしない）。ログ `retreat` の新しい項目
  `retreat_cost_power_zeroed`（ふうせんのみの `retreat_cost_zeroed` とは別）。
- 決まって増やす効果（でこぼこジム・［ねんちゃくえき］・スタジアム・ベトベトマーカー）との重なりは、どちらを先に当てはめるかが記録から決まらない v0.46・v0.81 の CP2 です（読み方で答えが変わる
  数は宣言の前に止める。順番を推測しない）。少なくできる効果（［にげるサポート］）だけなら 0 のままです（`ZoomTest.test_increases_are_cp2`）。
- 払う数は「にげる」の宣言のときの場で決めます。［ZOOM］のアンノーンと入れ替わってバトル場に出ても、払い直しません（そのあとは［ZOOM］のカードがバトル場なので、はたらかない）。

## 7. 遺跡の石版

- ベンチに空きがない（`bench_has_space`）なら、手札から出す前に `BENCH_FULL`（説明の「(あなたのベンチに空きがないとき、このカードは使えない。)」）。
- 選べるのは山札の、印刷の定義の名前のグループが「アンノーン」のたねポケモンのカード（文字の違うアンノーンを含む。uid の小さい順）。ちょうど 1 枚（「選び出し、ベンチに出す」。選ばなくて
  よいとは書かれていない）。選べるカードがない（山札 0 枚を含む）ときは、v0.53 の ST1（説明が山札・トラッシュから決まったカードを 1 枚選ばせるトレーナーで、選べるカードがない）で、手札から
  出す前に止めます。PW3 は特殊能力の問い、NJ1 はスタジアム（キョウの忍者ジム）のコインの問いで、範囲が違うので当てはめていません。
- 決定 `bench_from_deck`（選べるものの数も使ったプレイヤーだけが見る。`HIDDEN_COUNT_KINDS`）→ 手札を通さずにベンチの最後へ（`zones.bench_from_deck`。場に出た番は今の番。ログ
  `trainer_bench_from_deck` は公開）→ 山札を 1 回切ります。手札から出していないので、［ENGAGE］・［REASSURE］の機会はありません。まきちらせ!ベトベトガスなどのはたらく間の特殊能力を持つ
  カードは GG1 など（選べるが選ぶと止める。どれもそうなら手札から出す前に止める。答えのない決定を残さない）。
