## 3. 条件・対象・順番・枚数・見せるか

### 3.1 使うための条件と、決められない場合（手札から出す前。拒否で状態・乱数・ログは変わらない）

- 16 枚とも、トレーナーの使用の禁止（［アレルギーかふん］・ずつう・こうしゅうは）が先（`TRAINER_PREVENTED`）。
- 「…ことによって」「…時だけ、使える」（文面が使うための条件として書いているもの）: 超エネルギーリムーブ・いいきずぐすりで、はがせる自分のエネルギーカードがない →
  `NO_ENERGY_TO_DISCARD`。礼儀作法で手札にたねポケモンがある → `BASIC_POKEMON_IN_HAND`（手札を見せる前）。
- 決められない場合（新しい停止コード。5 章）: カスミのいかりの山札 7 枚未満（MW1）・エネルギー・リムーブの相手のエネルギーカードなし（EM1）・いいきずぐすりのダメージのない対象
  （SP1。対象がどれもそうなら使う前、ほかに選べる対象があれば選ぶと止める）・なんでもなおしの対象（FH1）・サカキの切り札の対象なし（GL1）とダメージのない対象（GL2。SP1 と同じ形）・
  ナツメの「ナツメのポケモン」が 2 匹いない（SB1）とエネルギーカードのない対象（SB2。SP1 と同じ形）。
- 既存の停止コード: 超エネルギーリムーブの「1匹から2枚」で、エネルギーカードが 2 枚より少ない相手のポケモンは FC1（v0.44 の「説明が決まった枚数を選ばせるとき足りない」）。
  選べるが選ぶと止め、相手のどのポケモンも 2 枚より少なければ（0 枚を含む）使う前に止める。kyuura の MIX-SUPER-ENERGY-REMOVAL の「2 枚まで」（のちの版の要約）では決めない。
  ワープポイントの SG1（v0.40）は 3.2。
- 前の段階の取り消しはしない: 超エネルギーリムーブ・いいきずぐすりの自分のエネルギーカードのトラッシュ（使うための条件）は、そのあとの段階の不正な答え・止める答え（FC1・MH1）で
  取り消しません（その答えを拒否し、状態は答える前のまま）。

### 3.2 対象のプレイヤーと順番

- 選ぶのは、ワープポイントの段階 0 を除き、使ったプレイヤーです（相手のポケモン・相手の手札・相手のエネルギーカードを選ぶときも）。トレーナーの効果なので、「ワザをうけない」状態・
  「とうめい」などワザを防ぐ効果は当てはめません。
- ワープポイント: 相手プレイヤーが先に自分の控えを選んで入れ替え、そのあと使ったプレイヤー（説明のかっこ書き）。入れ替えるポケモンは持ち主が選ぶので、段階 0 の決定は相手プレイヤー
  が決めます（このカードの `decision_problems` だけが許す。ほかのトレーナーの「決めるのは使ったプレイヤー」の約束は変えていない）。控えがいないプレイヤーは入れ替えず
  （`trainer_switch_skipped`）、どちらにも控えがいなくても使えます（説明が書いているので、ポケモンいれかえの `UNRESOLVED_SWITCH_WITHOUT_BENCH`・突風の GW5 を当てはめない）。
- ワープポイントの SG1: 使ったプレイヤーの対戦ポケモンが「すごむ」を受けていて、その効果を与えたポケモンが相手のベンチにいるとき、相手がそれを選ぶと同じ番にバトル場にもどる
  （v0.40 の SG1 の問い）。ただし、使ったプレイヤーに控えがいれば、そのあと使ったプレイヤーの対戦ポケモンがベンチにもどり効果が消える（p.322）ので、問いになりません。使った
  プレイヤーに控えがいないときだけ、そのポケモンは選べるが選ぶと SG1、それしか選べなければ使う前に SG1（WP1。実装上の読み方）。
- エリカの親切: 使ったプレイヤー → 相手の順（実装上の順番。EK1。プレイヤーごとに別のポケモンなので結果は同じ。ログの並びだけを決めた）。
- ロケット団のおねーさん: 見る → 選ぶ → 相手の山札にもどす → 相手の山札を切る。トレーナーカードがなければ、もどさず切らない（「その後」は「あれば」の処理のあと。RS1。v0.53 の
  MB1 と同じ読み方）。相手の手札が 0 枚でも見る処理をして終わる。トレーナーカードは手札にある間の印刷の分類（なにかの化石・ピッピ人形・ロケット団秘密メカなどの種類のあるものも
  含む。v0.54 のミニスカートと同じ）。
- トラッシュ交換: 数えるのは使う時点のトラッシュ（使っているこのカードは数えない）。数える → もどす → 切る（0 枚でも切る）→ 上からトラッシュ（もどしたカードもトラッシュされうる。
  もどしたあとの山札は数えた枚数以上ある）。
- ポケモンセンター: ポケモンごとに、すべてとりのぞく → ついているエネルギーカードをすべてトラッシュ。ダメージカウンターののっていないポケモンのエネルギーカードはすてない。重なった
  進化カード・ついているトレーナーはそのまま。
- サカキの切り札: とりのぞく → 手札をすべてトラッシュ（「その後」の効果で、使うための条件ではない。手札が 0 枚なら 0 枚）。
- ナツメ: はがしたカードすべて（種類・タイプを限らない）を 1 回でつけなおす（1 枚ずつの途中の状態を作らない。SA1）。つけたあと、カードごとに `after_energy_attached`（つけたときに
  はたらく特殊能力。ワザの効果のつけかえと同じ扱い）。手札からつける通常の操作の回数・特殊能力でつけた枚数は変えない。エナジーバーンの「炎」は「そのポケモンについている間」なので、
  つけなおしたカードは印刷のタイプにもどる（今の対応カードでは起こらない）。
- いいきずぐすり: ポケモン → エネルギーカード（トラッシュ）→ とりのぞく数。はがすのは実際の処理の順番の一歩なので、はがして最大HPが下がり（［ガスのからだ］）のっているダメージ以下に
  なる答えは、エンジンの共通の確かめで MH1 です（その答えを受け付けない。それしかなければ前の段階・使う前で止める）。とりのぞく途中の状態を作って確かめる処理は加えていません
  （MH1 の範囲を広げない）。
- ねむれ!ねむれ!: 使ったプレイヤーがコインを 1 枚投げる（`coin_flip` の `source` は `"trainer"`）。「おもて」でねむりにしたあとの状態が受け付けられない場合（決められない姿・MH1）は、
  コインの結果で受け付けるかが変わらないよう、コインの前に止めます（`state_stop_after`）。［めんえき］は防ぐ（`special_condition_prevented`）。ねむり・マヒ・こんらんは重複せず、
  どくは残る（p.322）。

### 3.3 枚数（0 枚・のっている数より少ない）

- カスミのいかり: ちょうど 2 枚（「選んで手札に加え」に選ばなくてよい言い回しがない）。山札がちょうど 7 枚なら使え、山札は 0 枚になる。7 枚より少なければ MW1。
- 礼儀作法: 0〜1 枚（「手札に加えてよい」。v0.53 の SR1 と同じ）。選べるたねポケモンがなくても、見せて切って終わる（`trainer_take_none`）。
- 超エネルギーリムーブ: 相手のポケモン 1 匹から、ちょうど 2 枚。3 枚以上ついていれば 2 枚を選ぶ。
- いいきずぐすり: とりのぞく数は 0〜min(4, のっている数)（「4個まで…ことができる」）。0 個も選べる（エネルギーカードはすでにトラッシュしている）。
- エネルギーサーキュレート: 0〜すべて（「好きなだけ…戻してよい」。0 枚は戻さないこと。v0.31 の HC5 の「のぞむなら」のない「好きなだけ」とは別の言い回し）。選べるカードがなければ
  決定を出さない。基本エネルギーカードはカードの種類で決め、エナジーバーンで「炎」になっていても基本エネルギーカード。
- エリカの親切・タケシ: ポケモンごとにのっている数まで（1 個だけのっていれば 1 個）。ポケモンセンターはすべて。3 枚とも、全員ダメージカウンターがなければ何も起こらずに使い終わる
  （「全員から」の対象が 0 匹。選ばせるものがないので、「選ぶ」効果の対象がない問いとは別。HE1。実装上の読み方）。

### 3.5 なんでもなおしの範囲（FH1）

特殊状態（どく・ねむり・マヒ・こんらん）になるのはバトル場のポケモンだけです。説明の「特殊状態にあるポケモン」が、使ったプレイヤーの対戦ポケモンだけか・相手の対戦ポケモンも含むか・
どちらかを選ぶのかは、印刷の文面・kyuura の記録で決まりません（英語版の「Your Active Pokémon」を持ち込まない）。どの読み方でも結果が同じ場合（特殊状態のポケモンが、使った
プレイヤーの対戦ポケモンだけ）は回復し（ログ `special_conditions_removed` の `reason` `cured`・`trainer_card`。ダメージ・持続する効果・にげるの失敗の記録は変えない）、相手の対戦
ポケモンが特殊状態のとき・どちらも特殊状態でないときは、手札から出す前に FH1 で止めます。正式な開始からの対戦（9.1）では、なんでもなおしを使えた場面がありませんでした（手順は
受け付けるときだけ使う）。回復する処理は単体テスト（tests/test_instant_trainers_v0_55.py の `FullHealTest`）で確かめました。
