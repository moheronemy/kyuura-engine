## 0. 判断する問いと要約

**問い**: 相手に控え（ベンチのポケモン）がいないとき、突風を使えるか。

- 2000.02.14 版のルールとその本（『ポケモンカードオフィシャルブック2000』。以下 P43）の記録だけでは、使える・使えないのどちらも直接は決まりません。第1弾の印刷の文面にある「相手に控えがいない場合は使えない」は、処理に採用している p.255 の最新の説明にありません。その省略が何を意味するかは、記録に書かれていません。
- 選択肢は 3 つです。A は今の未裁定の停止を続ける案、B は使えないとする案、C は使えるが入れ替えないとする案です。B は印刷の文面と一部の再録の版に支えられます。ただし、エンジンが採用してきた「最新の説明にしたがい、印刷の文面で補わない」（p.6）という方針の例外になります。C は最新の説明の省略を「制限がなくなった」と読む解釈で、明示の記述はありません。
- 現時点の推奨は **A（現状維持）** と、5 章の追加資料を探すことです。理由は、B・C のどちらにも、この本の時点の明示の記述がないためです。推奨は判断の性質の説明で、採用はしていません。

## 2. 直接言えることと、解釈が要ること

**記録から直接言えること**

1. 第1弾の印刷の文面（S1）には、相手に控えがいないときの使用の制限がある。
2. 処理に採用している p.255 の最新の説明（S2）・図版・解説（S3）には、その制限も、控えがいないときの扱いもない。
3. 最新の説明は「相手の控えポケモンを1匹選び」と、選ぶことを求める。相手に控えがいなければ、その指示は行えない。
4. 突風の最新の説明に「使うための条件」は書かれていない。p.310 が使えないとするのは、使うための条件を満たせないときだけ（S5）。
5. 同じ本は、ふきとばし（S7）で、控えがいないときの扱いを括弧で書いている。突風の p.255 には、その形の記述がない。
6. 再録の版の写し（S8）では、括弧の制限がある版と、ない版がある。p.255 の図版の番号は、制限のない版の写し（イントロパック 028）と合う（版は確かめていない）。

**省略の意味について解釈が要ること**

- (i) p.6 の「最新の説明にしたがう」が、印刷の文面の制限を消す意味か。最新の説明は「あいまいな表現…について書き直したもの」なので、あいまいでない制限の文は書き直しの対象外で、なお有効だ、とも読めます。
- (ii) 制限の一文がない版（S8 の一部・p.255 の図版）は、制限がなくなったことを示すのか。それとも、文字の量の都合などで省いただけで、制限は変わらないのか。記録には、どちらの理由も書かれていません。
- (iii) 「1匹選び」が行えないことを、使えない（p.310・p.311 からの類推）と読むか、使えるが何も起こらない（ふきとばしの F4・p.309 のワザの対象がない場合からの類推）と読むか。どちらも、規定をトレーナーへ当てはめる類推です。
- (iv) 基準の版より後の版（2001 年）の印刷の文面は、制限が続いていたことの傍証になりうるか。`CLAUDE.md` は後年の資料で補わないとしているので、根拠には使えません。

## 4. 判定の順序と、ほかの未裁定との関係（コードから）

`engine.check_play_trainer`（手札から出す前。状態を変えない）の順序は次のとおりです。

1. 番・手札・トレーナーであること
2. トレーナーの使用の禁止（`TRAINER_PREVENTED`。`IllegalActionError`）
3. 効果の登録の有無
4. `check_playable`。突風では、(a) 相手のベンチが空なら GW5、(b) 相手の対戦ポケモンがはなれられないなら AL2、(c) 相手の控えがすべて「すごむ」の発生源なら SG1、(d) どの控えでも最大HPがダメージ以下に下がるなら MH1・MH2・TK1
5. スタジアムの追加の費用（手札が足りなければ `IllegalActionError`）
6. 錯乱ジムと相手の［ちえくらべ］が同時にあるなら MG1（`UNRESOLVED_MIND_GAMES_CHAOS_GYM_ORDER`）

そのあと `_start_trainer_use` で錯乱ジムのコインを投げます。「うら」なら相手がかわりに使えるかを聞き、その確かめに同じ `check_playable` を相手の立場で使います（`borrow_condition_stop`。`UnsupportedError` は「使う」を選ぶと止める選択になり、`IllegalActionError` は「使う」の答えを拒否します）。

- 相手のベンチが空なら、今は (a) で止まるので、AL2・SG1・MH1・スタジアムの費用・MG1 には届きません。GW5 を決めても、**ほかの条件が成り立てば止まり続けます**。
- C を採ると、(b) の AL2 が、相手のベンチが空でも、相手の対戦ポケモンがはなれられなければ止めます（「入れ替えが起こらないのに、はなれられないことで止めるか」という別の問いが出る）。(c) は控えがないので当たりません。(d) は `switch_max_hp_drop_check` が控えなしで何もしないので当たりません。6 の MG1 は今と同じく止めます。
- B を採ると (a) で拒否され、ほかの条件は確かめません。錯乱ジムでかわりに使う経路では、かわりに使う人から見た相手（元の持ち主）に控えがいなければ、「使う」の答えが拒否になります（今は、選ぶと止める選択）。
- x1 の 53 局面で、ほかの条件が同時に成り立っていたかは調べていません（[観測との対応づけ](prestop-observation-link-design.md) 8 章は主な条件だけ）。
