# 既存の効果の型で加えたポケモン 14 枚（v0.29）

既存の効果の型の登録とパラメーターの指定だけで、ポケモン 14 枚（ワザ 24）を加えました（版 0.29.0）。2026-10-15 からのカードデータの方針（[card-data-policy.md](card-data-policy.md)）で加えた最初のカードです。

- kyuura の `data/cards.json`（写しの元 `ecb2d694e6280ec5dc9ddd2a8f709cea16a6b691`）を基本データとして採用し、pcg-search.com の同じ版のページと照合しました。ガイドブック（『オフィシャルブック2000』）は読んでいません。
- 新しい型・要素・状態・決定・停止コード・ログのイベントの種類・書き出しの形式はありません。`engine.py`・`resolution/`・型の意味と `check` は変えていません。カード id での分岐もありません。
- 保留したカード・外したカードはありません（14 枚とも追加）。新しい未解決の裁定もありません（未解決の裁定 28 件・停止コード 22 件のまま）。
- 公開の固定のデッキ・固定した参照データ・研究の基準（`3f34908`）は変えていません。

## 2. 判断の記録

- **ニョロモのみずでっぽう**: 印刷の文面「「水」エネルギーを1つ追加すると、10ダメージ追加できる。(追加は2つまで)」は、カメックスのハイドロポンプの印刷の文面と同じです。kyuura はこの文面を、カメックスの最新の説明の記録 LD-PMCG1-032-ATK0 で「何に対して追加したエネルギーを数えるかを書かない」（`ambiguous_in_print`）としています。また、ニョロモのイントロパック（ゼニガメデッキ）の版の文面「ワザに必要なエネルギーよりも多く…」との違いを「書き方だけ」と分類しています（kyuura docs/cards/reprints.md）。これらの kyuura の記録にしたがい、既存の `ExtraEnergyDamage`（ワザに必要なエネルギーより多い「水」エネルギー 1 個につき 10、2 個ぶんまで）で登録しました。処理に使う文面はこのカードの印刷の文面のままです（LD-PMCG1-032-ATK0 はカメックスの記録で、このカードの記録ではないので、採用の記録の `kyuura_records` には入れず、`notes` に書いた）。新しい裁定にはしていません。
- **同じ名前の別のカード**: リーダーズスタジアムには、マチスのコイル（037/096。HP30・はかいでんぱ・こんらんでんぱ）とタケシのイシツブテ（049/096。HP40・たすけをよぶ・スパイラルショット）が 2 種類ずつあります。写しの HP・ワザと同じ 038/096・050/096 と照合しました。ロケット団のワンリキー・ビリリダマ・ミニリュウは、第1弾の同じ名前のカード（PMCG1-053・PMCG1-037・PMCG1-065）と別の id で、ワザも違います。
- **進化**: 14 枚はどれもたねポケモンです。第1弾のゴーリキー（「ワンリキーから進化」）は、進化の条件がカードの名前（p.310）なので、ロケット団のワンリキーにも重ねられます（v0.29 で進化の処理は変えていない。テストで確かめた）。
