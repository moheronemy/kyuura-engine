# v0.22 の検証（パソコン通信）

v0.22（版 0.22.0）で確かめたことの記録です。**この文書の数字は、どれも 2026-10-15 に v0.22 のコードで今回実行した結果**です。過去の版の結果は、その版の文書（[v0.21-verification.md](v0.21-verification.md) など）にあり、ここには含めません。規定と根拠は [computer-search-v0.22.md](computer-search-v0.22.md) です。

- 基準: kyuura-engine `36e3630`（ブランチ `claude/v0.21-gust`。版 0.21.0）から、ブランチ `claude/v0.22-computer-search` で作業した
- 研究の基準: kyuura `3f349085645f47d0649a6cacece3680caeae50bf`（変えていない）。カードの写しの元: `ecb2d694e6280ec5dc9ddd2a8f709cea16a6b691`（変えていない。写しは既存の生成の道具で作り直し、パソコン通信の 1 枚を加えた）
- 環境: Python 3.13.16（この環境の `python3`）
