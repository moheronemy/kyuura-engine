# ワンリキー・ゴーリキー・カイリキーのワザの原典の照合と裁定（v0.10）

v0.10 でカイリキー（PMCG1-057。ポケモンカード第1弾）を対戦で使えるようにするために、進化元のワンリキー（PMCG1-053）・ゴーリキー（PMCG1-055）と、3 枚のワザを『ポケモンカードオフィシャルブック2000』[P43] で確かめた記録です。カイリキーのポケモンパワー「はんげき」は [counterattack-v0.10.md](counterattack-v0.10.md)、ダメージを受けたあとに自動的にはたらく特殊能力の扱いは [post-damage-powers-v0.10.md](post-damage-powers-v0.10.md)、設計は [architecture-v0.10.md](architecture-v0.10.md)。照合の記録は kyuura_engine/data/card_verification.json の PMCG1-055・PMCG1-057・PMCG6-061（ワンリキーは v0.1 の照合のまま）。テストは tests/test_machamp_line_v0_10.py。

## 1. 確かめ方

- 300dpi の画像を目で読み、カードの図版の説明文は 600dpi で拡大した（OCR はページの位置を探すのに使っただけ）。PDF のページ = 誌面のページ + 2。
- 同じ名前の別のカードを混同しないように、見出しの収録商品と LV・HP で照合した。p.190 のゴーリキーは 3 枚（照合したのは下の LV.40／HP80「ポケモンカード第1弾」。上の LV.24／HP60（拡張シート第3弾緑版）・真ん中の LV.28／HP70（拡張シート第2弾赤版・クイックスターターギフトパック）は別のカード）。p.192 のカイリキーは 3 枚（照合したのは真ん中の LV.67／HP100「ポケモンカード第1弾」。上の LV.54／HP90（通信進化キャンペーンのスペシャルカード）・下のわるいカイリキー（PMCG4-044）は別のカード）。p.193 のサカキのカイリキー（PMCG6-061）は名前が違うカード。
- 進化は名前で決まる（p.310「○○から進化」）。第1弾のカイリキーは名前が「ゴーリキー」のカードから進化し、サカキのカイリキーは「サカキのゴーリキー」から進化する（ゴーリキーからは進化できない）。kyuura の写しの対戦で使えるゴーリキーは第1弾のゴーリキーだけ。
- 使わなかった資料: 英語版の文面（kyuura の `text.en`）、後年の英語版の規定、現代のルール・現代のカードの文面。

## 2. カードの値（画像で読んだもの）

図版の説明文（印刷の文面）: ゴーリキーの「からてチョップ」は「自分のダメージカウンター×10だけ、相手にあたえるダメージがへる。」、「じごくぐるま」は「自分にも20ダメージ」と読める（小さくかすれている。kyuura と同じと読める範囲だけ読んだ）。

解説（処理に関わる記述）:

- ゴーリキー（p.190）: 「「からてチョップ」は、自分のダメージカウンターぶん攻撃力が落ちてしまうので回復手段を用意しておくか、…」「自分の受けるダメージを「ディフェンダー」でなくしつつ、次の相手の攻撃も減らせますので、「からてチョップ」の威力もあまり落ちないまま…」（じごくぐるまの自分へのダメージはディフェンダーで減る）。
- タケシのマンキーの「からてチョップ」（p.186）も、同じ最新の説明。
- いいきずぐすりの解説（p.256）: 「「ゴーリキー（第1弾）」の「からてチョップ」のようにのっているダメージカウンターぶん、ワザのダメージが小さくなる」。
- カイリキー（p.192）: 「ワザは4個もエネルギーが必要な「ちきゅうなげ」のみですが、なんのマイナス要素もなく60ダメージも相手に与えられるので、…」。

kyuura の記録（段階・進化元・HP・タイプ・弱点・抵抗力・にげる・ワザの名前・エネルギー・ダメージ・LV）は、ゴーリキー・カイリキーとも、この本の見出し・図版と同じ。エラッタの記録はない。

サカキのカイリキーを対応にしなかった理由: 第1弾のカイリキーとは別のカードで「はんげき」を持たない。［こんじょう］（ワザのダメージできぜつするときにコインを投げ、「おもて」ならきぜつせず残り HP 10）は、きぜつを取り消す特殊能力で、未実装。進化元のサカキのゴーリキーも写しにない。カードの分類（cards.py）がデッキに入れない（`test_other_machamp_is_not_strikes_back`）。

からてチョップ・じごくぐるま・ちきゅうなげ・けたぐりは、どれもコインを投げず、特殊状態を与えない。だから v0.9 の T19b（`UNRESOLVED_EVADED_EFFECT_COIN`）・v0.4b の `UNRESOLVED_PREVENTED_COIN_DAMAGE` には届かない（ワザの宣言の前の `AttackEffect.problem` は既定の None）。からてチョップ・じごくぐるま・ちきゅうなげを受けたカイリキーが「はんげき」でワザを使ったポケモンをきぜつさせる場合の C18 は、ワザの実装ではなくエンジン（`counterattack_double_knockout_problem`）が止める。3 つのワザは tests/test_effect_preflight_v0_3d.py の `ATTACKS` に加え、受け付けるかがコインの結果で変わらないことを確かめた。

## 4. 印刷の文面と最新の説明の違い

| ワザ | 印刷の文面（kyuura の写し） | 最新の説明（p.190） | 実装への影響 |
|---|---|---|---|
| からてチョップ | 「自分のダメージカウンター×10だけ、相手にあたえるダメージがへる。」 | 「このワザのダメージは、自分にのっているダメージカウンターの数×10だけ、小さくなる。」 | どちらも、目安の数字から自分のダメージカウンターの数 × 10 を引いた数（意味は同じ）。最新の説明にしたがう（`AttackEntry.play_text_ja`）。引いた数を p.321 の 1 段階とする（M4） |
| じごくぐるま | 「自分にも20ダメージ。」 | 「自分にも20ダメージ。」 | 同じ |

kyuura の記録に、印刷の文面と最新の説明を区別した記録がないことを報告事項とする（誤りとは決めない。[data-provenance.md](data-provenance.md)）。
