# ポケモンパワー（特殊能力）の一般の規定（v0.5。B1）

v0.5 でポケモンパワー（2000.02.14 版の公式ルールの用語では「特殊能力」）の基盤を加えるにあたって、一般の規定を『ポケモンカードオフィシャルブック2000』[P43]（kyuura の `NEO-2000-OFFICIAL-RULES`）の公式ルール pp.306〜326 で確かめた記録です。カードごとの規定（エナジートランス）は [venusaur-v0.5.md](venusaur-v0.5.md)・[energy-transfer-v0.5.md](energy-transfer-v0.5.md)、設計は [architecture-v0.5.md](architecture-v0.5.md) です。

## 1. 確かめ方と使わなかった資料

- Internet Archive の PDF（J38）からページを画像にし（p.309・p.310・p.311・p.320・p.322・p.323。150〜300dpi）、画像を目で読んだ。OCR の文字はページの位置を探すのに使っただけ。PDF のページ = 誌面のページ + 2。
- kyuura（`ecb2d694`）の data/rule_history.json・data/rule_differences.json のポケモンパワーの記録は第4版の冊子（ed4）のもので、2000.02.14 版の記録はない。**第4版の記録を 2000.02.14 版の規定として使っていない。**
- 英語版の後年の規定（`EN-2002-STATUS-POWERS`。特殊状態のポケモンはパワーを使えない、など）・英語版の文面（「before your attack」など）・現代の「特性」のルールは使っていない。どれも日本の 2000 年 2 月 14 日時点の規定ではない。
- 2000.02.14 版の公式ルールの用語は「特殊能力」。kyuura のデータの `kind` は `pokemon_power`。この文書とコードでは「ポケモンパワー（特殊能力）」と書く。

## 3. 原典で決められないこと（v0.5 の範囲）

v0.5 の対応カード（フシギバナ）の処理で、原典で決められない場合は見つからなかった。新しい `UNRESOLVED_…` のコードは加えていない（v0.4e までの 11 のコードは変えていない。[unresolved-rulings-v0.3d.md](unresolved-rulings-v0.3d.md)・[unresolved-audit-v0.4e.md](unresolved-audit-v0.4e.md)）。

カードの説明の範囲で決めたことのうち、規定ではなく実装の都合のもの:

- 1 回の使用で 1 枚をつけかえる（説明は枚数を書かない。「何度でも使える」ので、何枚まとめて移しても 1 枚ずつ移した結果と同じ。[energy-transfer-v0.5.md](energy-transfer-v0.5.md) 3 章）
- 使えない使用は、宣言もなかったものとして拒否する（P12）

## 4. kyuura の記録との違い（報告事項）

- kyuura の rule_history.json・rule_differences.json に、2000.02.14 版のポケモンパワー（特殊能力）の規定の記録がない（第4版の冊子の記録だけ）。p.311・p.323 の規定（P1〜P14）は 2000.02.14 版の誌面で確かめた。
- kyuura の cards.json の `pokemon.powers[].text.ja` は印刷の文面で、『オフィシャルブック2000』の「最新の説明」と区別した記録がない（フシギバナ。[venusaur-v0.5.md](venusaur-v0.5.md)）。

これらは kyuura 側の作業として扱う（このリポジトリの作業で kyuura を変更していない）。
