# v0.46: 常にはたらく特殊能力を持つポケモン 8 枚と関連する 3 枚

常にはたらく特殊能力（どれも使用を宣言しない）を持つポケモン 8 枚と、その系統・同じ作業で対応させる 3 枚を、どのワザも・どの特殊能力も登録して対応にしました。
常にはたらく特殊能力のための共通の処理（はたらいているかの判定・ダメージの変更効果の収集・「にげる」のエネルギーの数・トレーナーを使えなくする効果・特殊状態に
ならない効果）を整えました。

- 対象: バリヤード（PMCG2-027）・エリカのミニリュウ（PMCG5-063）・エリカのフシギソウ（PMCG6-010）・わるいオコリザル（PMCG4-041）・ドードリオ（PMCG2-040）・
  わるいベトベトン（PMCG4-007）・わるいラフレシア（PMCG4-010）・カビゴン（PMCG2-047）と、エリカのフシギバナ（PMCG6-017）・エリカのタマタマ（PMCG5-012）・
  エリカのナッシー（PMCG5-013）。
- 根拠: kyuura の `data/cards.json`（写しの元のコミット `ecb2d69`）の採用の記録（`kyuura_engine/data/card_sources.json`。11 件・2026-10-17）と、pcg-search.com の同じ版の

  一般の規定は kyuura の研究の基準のコミット（`3f34908`）の記録 GR-2000-P321-DAMAGE-ORDER（p.321 のダメージの計算の段階）・GR-2000-P321-ATTACK-DAMAGE・

## 2. 常にはたらく特殊能力の共通の処理

`effects.ContinuousPower`（`PowerEffect` の部分型。`declared = False`）を基底にしました。

- 宣言しない（p.311・p.323）ので、`UsePokemonPower` は今までどおり `POWER_NOT_DECLARABLE`（`check_usable`・`resolve` を呼ばない）。
- はたらいているかは、問い合わせのたびに `effects.continuous_powers(state, 型)` が、場のポケモン・いちばん上のカード（p.310。進化前のカードの特殊能力は使えない）・
  場所（`location`: `in_play`（場のどこでも）・`active`（「バトル場にいる限り」）・`bench`（「ベンチでしか使えない」））・特殊状態・かがくへんかガス
  （`continuous.suppressors_of`。抑止の判定を複製しない）から求めます。「はたらいている」の印・一覧を状態に持たず、ログからも決めません（進化・入れ替え・きぜつ・
  場をはなれる・特殊状態の変化・保存と復元のあとも、その時点の場から同じ答え）。
- 特殊状態の条件は説明ごとです（一律に「ねむり・マヒ・こんらんで消える」にしない）:
  - `blocked_by_status`（既定）: ねむり・マヒ・こんらんで消える・使えない（なぞのかべ・ふしぎなバリアー・ねんちゃくえき・アレルギーかふん・めんえき）。
  - `requires_confusion`: こんらん状態の時だけはたらく（きょうぼう）。
  - `status_at_attack`: 「ワザが使われた時、すでに…」。ワザの宣言の時点の特殊状態で決める（くつろぐかおり。4.3）。
  - 条件なし（にげるサポート。ベンチのポケモンは特殊状態にならない）。どくは、どの説明にも挙げられていないので関係しません。
- 問い合わせる場所（どれも型で探し、カード id で分けない。`engine.py`・`resolution/` にカード id の分岐はない）:
  - ワザのダメージの計算: `effects.attack_damage_modifiers` が `continuous_attack_damage_modifiers` を加える（解決の基盤の `kernel.deal_damage` と宣言の前の
    `preview_attack_damage` が同じ関数を使う）。
  - 特殊能力のダメージ（はんげき・わるいねぞう・こっそりかみつく）: `effects.received_power_damage`（受けるダメージ全体を書く説明だけ。4.1・4.2）。
  - こんらんの 20: `procedures.confusion_damage_problem` が `confusion_power_modifiers` を聞く（4.3・4.4）。
  - 「にげる」: `effects.retreat_cost`（公開の問い合わせ。`engine._retreat`）。
  - トレーナー: `effects.trainer_lock_sources`（公開の問い合わせ。`engine._play_trainer`）。
  - 特殊状態にする処理: `conditions` の付ける関数の共通の入口（`effects.status_immunity`）。
- 効果の定義の対応表（`resolution/catalog.py`）には入れていません。解決の基盤の窓（ワザ・きぜつ・番の終わり）の中ではたらく反応ではなく、上の処理がその時点の場から
  問い合わせるからです（v0.31 のほのおでかいふくと同じ扱い。tests/test_event_kernel_v0_14.py）。

## 3. ダメージの計算の操作

p.321 の段階の中の変更効果（`damage.DamageModifier`）に、次の計算を加えました（`operation`）。どれも、その段階のダメージだけを見て、記録はログ `damage` に、
当てはめたときだけ書きます（v0.45 までのログの形は変えない）。

| 計算 | 意味 | 使うもの | ログの項目 |
| --- | --- | --- | --- |
| `ZERO_IF_AT_LEAST` | しきい値以上なら 0、より小さければそのまま | なぞのかべ（8 段階） | `damage_zero_at_least`（(段階, 発生源のカード, しきい値)） |
| `SET_IF_AT_LEAST` | しきい値以上ならその数、より小さければそのまま（`threshold` が要る） | ふしぎなバリアー（8 段階） | `damage_set_if_at_least`（(段階, 発生源, しきい値, その数)） |
| `HALVE_UP` | 半分（切り上げ） | くつろぐかおり（2・6・8 段階） | `damage_halved`（(段階, 発生源, `up`)） |
| `HALVE_DOWN` | 半分（切りすて） | リフレクター（8 段階） | `damage_halved`（(段階, 発生源, `down`)） |

- しきい値は、その段階の直前のダメージと比べます（なぞのかべは「受けるダメージ」なので、プラスパワー（5 段階）・ディフェンダー（7 段階）のあと）。v0.45 の
  `ZERO_IF_BELOW`（かたくなる。より小さければ 0）とは比べる向きが逆で、発生源も持続する効果ではなく特殊能力です。
- 半分の丸めは、ダメージカウンターの単位（10）で行います（30 の半分の切り上げは 20、切りすては 10）。v0.4d のメガドレインの「半分（切り上げ）」と同じ単位です。
  0 以下はそのまま（途中の段階で 0 以下になったら計算を終える。p.321）。
- 同じ段階に加算でない効果を含む 2 つ以上の効果があり、順番で結果が変わるときは、v0.35 の決定 `damage_step_order`（2・5・6 段階はワザを使うプレイヤー、7・8 段階は
  ワザを受けるプレイヤー。GR-2000-P321-DAMAGE-ORDER）で選ばせます。例: なきつく（2 段階の −20）を受けたエリカのフシギソウがカラカラにワザを使う（2 段階に
  加算と半分）。順番で結果が変わらなければ決定を出しません。新しい決定の種類は作っていません。
- リフレクターは、ワザによる持続する効果 `state.HalvedDamage`（自分自身。はたらく番は次の相手の番。消える契機は v0.4b と同じ）で、`persistent.halved_damage` で
  探します。不変条件（`engine._halved_damage_problems`）は、効果を与えたワザの登録の `halved_terms()` と照らします。くつろぐかおりとは段階・丸め・発生源が違い、
  計算の部品（`HALVE_*`）だけを共通にしました。

## 4. 規定と根拠（特殊能力ごと）

### 4.1 ［なぞのかべ］（バリヤード）

- 受ける 30 以上のダメージは 0、30 より小さいダメージはそのまま（説明の「(30より小さいダメージはそのまま受ける。)」）。p.321 の 8 段階（ワザを受けるポケモンの持っている
  効果。GR-2000-P321-DAMAGE-ORDER の 8 段階の例が「なぞのかべ」）。計算の結果が 0 なら「ダメージを受けなかった」（p.321）だけで、ダメージ以外の効果（どく・こんらん
  など）は受けます（ワザの要素を無効にする処理にしない）。
- 場（バトル場・ベンチ）のどこでもはたらきます（控えへのダメージも 8 段階）。ねむり・マヒ・こんらんの時は使えず、かがくへんかガスで消えます。
- ワザでない特殊能力のダメージ（はんげき・わるいねぞう・こっそりかみつく）も「受けるダメージ」なので当てはめます（今の対応カードではどれも 20 以下で結果は変わらない）。
  ポケモンチェックのどくのダメージ（10・特殊などくは 20）もしきい値より小さく結果が変わらないので、どくの処理は通していません（どくの量がしきい値以上のカードを加えるときに
  見直す）。ダメージカウンターをのせる・移す効果はダメージではありません（GR-2000-P320-COUNTER-MOVE）。
- ヨガのポーズ: 説明は「相手にのっているダメージカウンター」で、ルージュラ（PMCG1-048）の「相手のポケモンにのっている…」（CD4）とは書き方が違うので、相手の対戦ポケモンの
  カウンターだけを数えます（`DamagePlusDefenderCounters` の `scope_ambiguous=False`。型の `check` が書き方で分ける）。CD4 は解決したことにしていません。

### 4.2 ［ふしぎなバリアー］（エリカのミニリュウ）

- 「たねポケモン」から受ける 20 以上のダメージは 10（8 段階。`SET_IF_AT_LEAST`）。ダメージ以外の効果はそのまま。「たねポケモンから」は、ダメージを与えるポケモン
  （ワザを使ったポケモン・返す効果を持つポケモン・特殊能力でダメージを与えるポケモン）の、ダメージを受ける時のいちばん上のカードがたねポケモン（`is_basic_pokemon`）。
  進化したポケモンからのダメージは変えません。ポケモンチェックのどくは、ポケモンから受けるダメージではない（GR-2000-P319-HP-AND-DAMAGE）ので当てはめません。
- 「ダメージを受ける時、すでに…」の特殊状態は、ダメージを計算する時の特殊状態です。場のどこでもはたらきます。
- R団のカビゴン（たねポケモン）の［わるいねぞう］の 20 は 10 になります（ログ `counterattack` に `amount_before`・`received_modifiers`）。

### 4.3 ［くつろぐかおり］（エリカのフシギソウ）

- このカードがバトル場にいる限り、お互いの対戦ポケモンのワザのダメージは半分（切り上げ）。説明の「(自分や、控えへのダメージも半分になる)」のとおり、相手・自分・控えへの
  ダメージに当てはめます。1 つのダメージの要素に 1 回（二重に当てはめない）。
- 段階は GR-2000-P321-DAMAGE-ORDER の持ち主の区別で決めます: このカードがワザを使うポケモンなら 2 段階、ダメージを受けるポケモンなら 8 段階、どちらでもない（相手の
  控えへのダメージ・相手のワザの自分へのダメージで、このカードがバトル場にいる側）なら 6 段階（それ以外の効果）。このカードが同じワザでワザを使うポケモンとダメージを
  受けるポケモンの両方になる場合の段階は決まりませんが、このカードのワザに自分へのダメージはなく、相手のワザを使う効果もないので起こりません（起こったらエンジンの不具合と
  して止める）。
- 「ワザが使われた時、すでに…」は、ワザの宣言の時点の特殊状態です。解決の基盤がワザの宣言のときに写し（`Resolution.attack_status`。`effects.status_at_attack_blocked`）、
  決定をまたぐときは続きの情報（決定の `context` の `attack_status`。書くのは、ねむり・マヒ・こんらんのこのカードがいるときだけ）で運びます。ワザの途中でこのカードの
  特殊状態が変わっても、そのワザでは変わりません。場所（バトル場）・かがくへんかガスはダメージを計算する時の場で見ます。
- 返す効果のダメージ（ほのおのかべ・こうらがえし・クロスカウンター）はワザによるダメージ（GR-2000-P321-ATTACK-DAMAGE）ですが、「ワザが使われた時」が返す効果を与えた
  前の番のワザか、きっかけのこの番のワザかは決まらず、前の番のワザのときの特殊状態は記録していません。当てはめるかどうかで最終ダメージ（または順番の決定の要否）が
  変わるなら CP1 で止めます（5 章）。
- 特殊能力のダメージ（はんげき・わるいねぞう）はワザのダメージではないので当てはめません。こんらんの 20 にこのカードを当てはめるかは決まらない（v0.3c の
  「こんらんのダメージがワザによるダメージか」と同じ問い）ので、はたらいていれば、こんらんのコインの前に既存の `UNRESOLVED_CONFUSION_DAMAGE_MODIFIERS` で止めます。

### 4.4 ［きょうぼう］（わるいオコリザル）

- このカードがこんらん状態の時、このカードがポケモンに与えるダメージは +30（2 段階。ワザを使うポケモンの持っている効果）。こんらんで消える特殊能力ではなく、こんらんが
  はたらく条件です（`requires_confusion`）。ねむり・マヒとこんらんは重ならず、どくは関係しません。かがくへんかガスで消えます。
- こんらんの 20（このカードのワザがこんらんして自分が受ける）が「このカードがポケモンに与えるダメージ」かは決まらない（v0.3c）ので、こんらんのコインの前に既存の
  `UNRESOLVED_CONFUSION_DAMAGE_MODIFIERS` で止めます。この特殊能力がはたらくのはこんらん状態の時だけなので、**こんらん状態のわるいオコリザルのワザは、どの先読みの方法でも
  コインの前に止まり、受け付けません**。そのため +30 は対戦では起こりません（ダメージの計算の部品と変更効果の収集は単体のテストで確かめた。`FrenzyTest`）。
  これを避けるために、こんらんの 20 の扱いを決めることはしていません。
- あばれくるう: ダメージを与えた後、自分をこんらんにする（要素 `Damage` → `Status(CONFUSION, target=SELF, after_damage="damage")`）。なぞのかべで 0 になるなど
  ダメージを与えなかった場合は既存の Z23 で止めます。

### 4.5 ［にげるサポート］（ドードリオ）・［ねんちゃくえき］（わるいベトベトン）

- 「にげる」でトラッシュするエネルギーの数は `effects.retreat_cost(state, player)`（`RetreatCost`）です。印刷の数（バトル場のポケモンのいちばん上のカード）に、相手の
  はたらいている［ねんちゃくえき］（バトル場。決まって +2。「必要になる」なので選べない）と、自分のはたらいている［にげるサポート］（ベンチ。−1 ずつ。「少なくできる」
  なので、少なくするかは「にげる」のプレイヤーがトラッシュする数で決める）を当てはめ、最後に 0 で下限をつけた範囲です（`minimum`〜`maximum`）。複数の特殊能力
  （2 匹のドードリオ）は足し合わせます。範囲の外は `WRONG_RETREAT_COST`。
- 印刷の数だけを読む経路を残していません（`engine._retreat` は `retreat_cost` だけを使う）。特殊能力がなければ範囲は印刷の数ちょうどで、v0.45 と同じです。
- 少なくする数が印刷の数より多く、増やす数もある（にげる 0 のドードーのベンチにドードリオ、相手のバトル場にわるいベトベトン）ときは、先に少なくして 0 で止めてから
  増やす読み方（2）と、合わせてから 0 で止める読み方（1）で、トラッシュしてよい数が変わります。どちらかは記録から決まらないので、読み方で答えが変わる数の「にげる」は
  CP2 で止めます（エネルギーのトラッシュとコインの前。5 章）。どちらの読み方でも足りる数は受け付けます。
- バトル場のドードリオ自身には［にげるサポート］を当てはめません（ベンチでしか使えない）。ねんちゃくえきは、わるいベトベトンがねむり・マヒ・こんらん・ベンチのとき消えます。
- 「にげる」（p.311）のエネルギーだけで、ポケモンいれかえ・突風・ワザの入れ替えはエネルギーをトラッシュしないので関係しません。
- 数が特殊能力で変わったときだけ、ログ `retreat`・`retreat_failed` に `retreat_cost`（範囲）・`retreat_cost_printed`・`retreat_cost_increases`・

### 4.6 ［アレルギーかふん］（わるいラフレシア）

- このカードが場（バトル場・ベンチ）にいて、はたらいている限り、お互いのプレイヤーは手札のトレーナーカードを使えません。`engine._play_trainer` が、カードを手札から
  出す前に `TRAINER_PREVENTED`（`IllegalActionError`）で拒否します（状態・乱数・ログは変わらない）。ねむり・マヒ・こんらん・かがくへんかガスで消え、場をはなれれば
  使えます。
- すでについているトレーナー（プラスパワー・ディフェンダー）は使い終わっているので効果が続きます。使っている最中のトレーナー（ポケモン育て屋さんでこのカードを場に
  出した）も使い終えます。
- はなびらのうず: 同じ 3 枚のコイン（要素 `Coin("coin", count=3)`）の「おもて」の数 × 30、2 枚以上「おもて」なら自分がこんらん（`gate=("coin", AtLeast(2))`。
  投げ直さない）。

### 4.7 ［めんえき］（カビゴン）

- このカードは、どく・ねむり・マヒ・こんらんにならない。特殊状態にする処理の共通の入口（`conditions` の `poison`・`put_to_sleep`・`paralyze`・`confuse` が最初に呼ぶ
  `_prevented`）で防ぎ、状態を変えずにログ `special_condition_prevented`（`condition`・`effect`・`power`）を残します。ワザ・特殊能力のどれで付けようとしても同じです。
- すでにある特殊状態を回復する効果ではありません（どくは残る）。なんらかの原因（かがくへんかガスで消えていた間など）でねむり・マヒ・こんらんならこの力は使えず、
  どく状態だけなら使えます。かがくへんかガスで消えます。
- 防がれる特殊状態について、原典で決められない場合の確かめ（マヒの再付与・特殊などくの上書き TP3・「ダメージを与えた後」の効果の Z23（コインのないとき））は、
  防がれて結果が変わらないので聞きません（`resolution.programs.Status`・`ReparalysisGuard`。不要な停止にしない）。効果を決めるコインは、効果の要素が無効なのでは
  なく効果を受けて特殊状態にならないので、今までどおり投げます。
