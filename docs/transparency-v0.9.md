# ゴーストの「とうめい」の原典の照合と裁定（v0.9）

v0.9 でゴースト（PMCG3-030。ポケモンカード第3弾化石の秘密）のポケモンパワー「とうめい」を対戦で使えるようにするために、『ポケモンカードオフィシャルブック2000』[P43] で確かめた記録です。進化元のゴースとワザは [haunter-line-v0.9.md](haunter-line-v0.9.md)、自動的にはたらく特殊能力の扱いは [automatic-powers-v0.9.md](automatic-powers-v0.9.md)、設計は [architecture-v0.9.md](architecture-v0.9.md)、確かめた結果は [v0.9-verification.md](v0.9-verification.md) です。照合の記録は kyuura_engine/data/card_verification.json の PMCG3-030。

## 1. 確かめ方と使わなかった資料

- Internet Archive のスキャンの PDF からページを画像にし（300dpi。カードの図版は 600dpi で拡大）、目で読んだ。PDF の文字（OCR）は、ページの位置を探すのに使っただけ（「とうめい」の語で p.8 目次・p.159・p.160・p.323 を見つけた）。
- 照合したのは p.160 の真ん中の「ゴースから進化 ゴースト LV.17／HP50」「ポケモンカード第3弾化石の秘密」のカード。同じページの下の「ゴースト LV.22／HP60 ポケモンカード第1弾」（PMCG1-047。さいみんじゅつ・ゆめくい。特殊能力なし）、上の「ナツメのゴース」（ポケモンジム第3弾）は別のカードで、代わりにしていない。
- p.159 は「特殊能力解説」の見開きの 1 ページで、［とうめい］だけを説明している（ポッポの「ふきとばし」、レアコイルの「じばく」、わるいマルマインの「エナジーボム」を受けた場合の例を含む）。この本で［とうめい］の処理をいちばん詳しく書いたページで、裁定の主な根拠にした。
- 当時の公式の Q&A・訂正をウェブで探すことはしなかった（v0.8 で 2000.02.14 版の時期の日本語の資料が見つからなかったため。この本の p.159 の解説を当時の公式の説明として使った）。
- 使わなかった資料: 英語版の文面（kyuura の `text.en`。「Whenever an attack does anything to Haunter, flip a coin. If heads, prevent all effects of that attack, including damage, done to Haunter.」）、後年の規定（kyuura の rule_history.json の `card_lists.poke_body` など）、現代の「特性」「ポケボディー」のルール。英語版の文面は 1 枚のコインを示唆するが、根拠にしていない（T4 は日本語の最新の説明と p.159 で決めた）。

## 3. 裁定（T1〜T42）

分類: CONFIRMED（原文がそのまま決めている）・SUPPORTED（原文と解説から強く支持される。ほかの読み方の余地が小さい）・UNRESOLVED（原文で決められない）。「実装上の仮定」は規定ではなく実装の都合で決めたこと。「未到達」は規定は確かめたが、v0.9 の対応カードでは起こらないこと。テストは tests/test_transparency_v0_9.py（盤面を直接作る）と tests/test_haunter_games_v0_9.py（自然な対戦）。

### 3.5 A4 の 3 つの論点

**A4-1（1 つのワザで何回コインを投げるか）**: 1 回（T4。SUPPORTED）。10 ダメージとどくを同時に与えるワザ（例: フシギソウの「どくのこな」はダメージ 20 とどく）を受けると、ダメージの要素を受けるときに 1 回投げ、「おもて」ならダメージもどくも受けない、「うら」ならダメージもどくも受ける。ダメージが 0（ディフェンダーなど）なら、どくを受けるときに 1 回投げる。どくにするかをワザを使う側のコインで決めるワザ（「どくばり」）で、ダメージの要素で「おもて」になった場合だけは、そのコインを投げるかが決められない（T19b。UNRESOLVED）。

**A4-2（ワザの成立と「とうめい」）**: ワザは成り立つ（T17・T18）。必要なエネルギーはついたまま、ワザを使ったことになり番は終わる。ワザを使う側への要素（「でんげき」の自分へのダメージ、「じこさいせい」のトラッシュ）はそのまま処理する。「ダメージを与えたら」の回復は、受けなかったら起こらない（T41）。

**A4-3（ベトベトンとの関係）**: かがくへんかガスがはたらいていれば、「とうめい」の力は消える（T14。コインを投げない）。v0.8 の抑止の判定（`continuous.suppressors_of`）は、宣言する特殊能力の受け付け（`engine._use_pokemon_power`）だけで聞かれていたので、v0.9 で「とうめい」を評価する境界でも同じ関数を聞く（v0.8 の G7 の約束）。抑止の判定を複製していない。
