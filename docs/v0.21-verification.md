# v0.21 の検証（突風）

v0.21（版 0.21.0）で確かめたことの記録です。**この文書の数字は、どれも 2026-10-15 に v0.21 のコードで今回実行した結果**です。過去の版の結果は、その版の文書（[v0.20-verification.md](v0.20-verification.md) など）にあり、ここには含めません。規定と根拠は [gust-v0.21.md](gust-v0.21.md) です。

- 基準: kyuura-engine `99fd5e1`（ブランチ `claude/v0.20-first-playable-decks`。版 0.20.0）から、ブランチ `claude/v0.21-gust` で作業した
- 研究の基準: kyuura `3f349085645f47d0649a6cacece3680caeae50bf`（変えていない）。カードの写しの元: `ecb2d694e6280ec5dc9ddd2a8f709cea16a6b691`（変えていない。写しは既存の生成の道具で作り直し、突風の 1 枚を加えた）
- 環境: Python 3.13.16（この環境の `python3`）

## 5. 組み合わせの対戦（tools/preset_deck_games.py の `--variant gust`）

v0.20 の 2 つの固定のデッキのディフェンダー 4 枚のうち 3 枚を突風 3 枚に置き換えた一時的な 60 枚どうし（公開の固定のデッキは変えていない）。先攻・後攻は seed の偶奇で、席は局ごとに入れかえる（どの実行も、先攻はそれぞれのデッキがちょうど半分）。手順は決まったもので、強い AI ではありません。勝率でカードの強さ・釣り合いを判断していません。

- 例（40 局の seed 1、エビワラー・ジュゴンがプレイヤー 0 の席。先攻はフシギバナ・パラセクト）: 17 番に、フシギバナ・パラセクトのプレイヤーが突風でジュゴン（PMCG1-030）をベンチにもどしてコラッタ（PMCG1-060）を呼び、同じ番のフシギバナのソーラービームできぜつさせた。
- 既知の未解決の裁定による停止は、v0.1 からの `UNRESOLVED_MULLIGAN_COMPENSATION`（対戦準備）だけでした。ルールによる拒否（手順が試して拒否された操作。どれも `IllegalActionError`）は 40 局で 236 回、200 局で 1,096 回で、内訳はねむり・マヒのときのワザ・にげる・特殊能力と、進化の時期でした（突風の拒否はない）。
- 相手に控えがいないときの突風（GW5）は手順が使わないので、対戦の中では起こりません。止まること・状態が変わらないことは単体テスト（`UsableTest`）で確かめています。
