# v0.192: R-2 のアンノーンの自己持ち主の限定提示（うらのバトル場のアンノーンX・A 自身の［XXXXX］・［ANGER］）

2026-11-18。設計は [r2-unown-self-holder-design.md](r2-unown-self-holder-design.md)（10 章に採用と結果）。基点は `claude/r2-unown-self-holder-design`（`de935d7`。0.191.0）。

この版は **自己持ち主の 2 能力だけ** の限定対応です。R-2 全体の解消ではありません。
- 別の持ち主の 2 能力（0.191.0）は、今までどおり示します。
- 変身の経路と［すいりょくはつでん］には対応していません。
- 示す選択肢は、実行を保証しない入力の提示です。
- ［ANGER］の自己は追加が 0 になりますが、選べるようにしました。効果は保証しません。
- GUI の表示・送信と、通常の対戦（new_game から）でこの場面に来るかは確かめていません。

## 2. 変えたこと

`kyuura_engine/legal_actions.py` だけを変えました。エンジンのゲーム処理・裁定・規約・judge・検証用 AI の方策・GUI は変えていません。

**提示:** 新しい `_face_down_self_group_power` が、使い手自身の力を 2 段目の先頭に示します。示すのは次のすべてを満たすときです。
- 番のプレイヤーの main で、本人のバトル場のポケモンがうら（呼び出し元の条件）。
- 本当のカード（`printed_def`）がたねでベイビィでなく、特殊能力の型がすべて分類済みの 22 型（`_classified_group_attacker`）。
- 本当のカードの印刷の特殊能力のうち、最初のワザといっしょに使う力（登録の `power_effect` が `AttackDeclaredPower`）が［XXXXX］か［ANGER］。その `group` が本当のカードの名前のグループで、印刷のワザに `attack_name`（めざめるパワー）のワザがある。
  - この選び方は、公開のあとの `group_attack_power_slot` と同じ「仮の力」です。
  - ゲームの状態に力を加えたり、うらのカードを公開したりはしません。
- 使い手が持続する効果で力を止められていない・使えない（`powers_stopped`・`powers_use_prevented`）。うらの間は持続する効果を受けない不変条件で必ず成り立ちますが、念のため確かめます。
- 仮の力が場の効果で消えていない（`power_suppressed` に持ち主のプレイヤーを渡す）。かがくへんかガス・まきちらせ!ベトベトガス・ふしぎなガス・やみのはどうが対象です。
- この番に、ほかの個体の使用の記録がない（`other_use_problem`。［XXXXX］だけ意味がある）。

**値・表示・区分・note:**
- **値・表示:** 値は使い手の場の番号（`with_power`）です。表示は v0.191 の `with_power` と同じ形で、`addon`・`pokemon`・`card`・`zone: "active"`・`face_down: true`・`power` です（`card_id` は出しません）。新しい語彙はありません。
- **並び:** 自己持ち主を先にし、そのあとに v0.191 の別の持ち主を場の並びで示します。本当のカードが X・A のときだけ、別の持ち主の選択肢の番号が 1 つ後ろにずれます。
- **区分:** `unverified`・`face_down_reveal_not_evaluated` のままです。
- **note:** 自己持ち主を示すときだけ、新しい `NOTE_FACE_DOWN_SELF_GROUP_POWERS` を使います。量（［ANGER］が 0 であること）は予告しません。別の持ち主だけ・コイン・［めいれい］のときの文は変えていません。

**check:**
- `_face_down_verify` は、自己持ち主の `exclusive_key` を本当のカードの登録から読みます（場から読むと、うらの持ち主で例外になるため）。
- `CANDIDATE_INPUT_INVALID` になる組:
  - 自己 X ＋ 別の X、自己 A ＋ 別の A（同じ力の組）。
  - 同じ選択肢の重複、組にない選択、ワザのない選択、不正な番号（今までの形の検査）。
- 自己 X ＋ 別の A などの違う力の組は valid です。check はエンジンを呼ばず、受理・力の使用・効果を保証しません。

**保証の文（`GUARANTEE_FACE_DOWN_ATTACK`）:**
- preconditions に v0.192 の条件の 1 文と、「v0.192: 使い手自身の力は本当のカードの登録で読む」を加えました。acceptance・after_acceptance・supported_scope は同じです。
- F-1 の固定の sha256 は `28f68001…` から `cee8fc93…` になりました。
  - 実装の途中の文（`20b7aa61…`）は「たねポケモン」の語を含んでいました。既存の文の検査（公開のあとの結果を予告しない）に拒否されたので、「印刷の段階がたね（stage が basic。ベイビィでない）」に直しました（テストは変えていません）。
  - 旧値と途中の値は、テストの説明に残しました。

**対象外のまま:**
- 変身・コピーの経路（メタモン 2 種）。
- ［すいりょくはつでん］。
- 分類にない新しい効果型と、対象外のワザ・カード・能力。

**変えていないこと:**
- submit の順（おもてにする → 確かめ → 先読み → 処理）と、拒否のときの巻き戻し（公開を含む）。
- XP1・NT1・v0.4b の未裁定の停止。候補で予測して外しません。

## 4. テスト

**新しいテスト:** `tests/test_legal_actions_r2_unown_self_v0_192.py`（31 件）。
- 修正の前は 22 件が失敗しました（提示・送信・check・保証に関わる期待）。示さない側の 9 件は、修正の前から成功しました。
- 修正のあとは全件が成功しました。

範囲は次のとおりです。
- **提示:** 自己 X・自己 A（counters 0）・自己と別の持ち主の並び。
- **check:** 同じ力の組・重複・組にない選択・形だけ。
- **示さない:**
  - かがくへんかガス（自分・相手）、注入した場の効果 4 種、この番のほかの X の記録。
  - 人工のもの: 使えない効果・ベイビィ・1 進化・分類の範囲から型を除く・示す型を狭める・名前のグループ。
  - アンノーン N・アンノーンでない使い手・メタモン。
- **送信:**
  - 自己・併存で、U7 と直接のコマンドの結果が一致すること。
  - XP1・NT1・v0.4b の拒否は、状態・乱数・ログ・決定と使い手のうらが不変で、ほかの人に知らせないこと。拒否のあと、同じ版で力なしに答え直して受理されること。自己 A は止まらないこと。
  - エネルギー不足で公開ごと巻き戻ること。
  - 同じ力の組が、check とエンジンの両方で拒否されること。
- **情報境界:**
  - 相手の秘密だけを変えても、本人の応答と check が同じ（双子）。
  - 本人の本当のカードだけを変えても、相手・観戦者の観測・応答・更新が同じ。
  - 候補・入力・check で状態・乱数・ログ・更新が変わらない。
  - 公開・エンジンの確かめ（力・使い手の条件・ワザ）を呼ばない。
- **登録:** 持ち主の型のカードは、たね・ベイビィでない・分類済み。人工のベイビィの持ち主は、検査が見つけます。
- **回帰:** 別の持ち主だけの note・保証が本当のカードによらないこと・おもての宣言。

人工の登録・状態は名前に `artificial`、到達できる状態の直接の注入は `injected` として、実在のカードのケースと分けました。

**意図して変えた既存の期待:**
